### Execution and Temporary File Management
OpenFold integrates external bioinformatics tools by wrapping their command-line binaries in Python classes. This approach involves executing these external programs as subprocesses, managing their input and output, and handling temporary files to ensure efficient and clean operation.

For example, tools like [`HHblits`](https://github.com/aqlaboratory/openfold/docs/source/index.md#L51), [`HHsearch`](https://github.com/aqlaboratory/openfold/docs/source/original_readme.md#L390), [`hmmbuild`](https://github.com/aqlaboratory/openfold/openfold/data/tools/hmmbuild.py#L25), [`hmmsearch`](https://github.com/aqlaboratory/openfold/openfold/data/tools/hmmsearch.py#L27), [`jackhmmer`](https://github.com/aqlaboratory/openfold/openfold/data/tools/jackhmmer.py#L30), and [`Kalign`](https://github.com/aqlaboratory/openfold/openfold/data/tools/kalign.py#L36) are invoked using [`subprocess.Popen`](https://github.com/aqlaboratory/openfold/openfold/data/tools/kalign.py#L93) in their respective wrapper classes within the [`/aqlaboratory/openfold/openfold/data/tools`](https://github.com/aqlaboratory/openfold/openfold/data/tools) directory. These wrappers construct the necessary command-line arguments based on method parameters, pass input data (often via temporary files), and capture the standard output and error streams. This allows for programmatic control over these tools and facilitates error handling by checking process return codes and logging diagnostics.

A key aspect of this integration is the systematic management of temporary files and directories. A [`tmpdir_manager`](https://github.com/aqlaboratory/openfold/openfold/data/tools/utils.py#L27) context manager, defined in [`/aqlaboratory/openfold/openfold/data/tools/utils.py`](https://github.com/aqlaboratory/openfold/openfold/data/tools/utils.py), is widely used across these wrappers. This manager creates a temporary directory for each tool execution, writes input files to it, directs tool output to files within it, and ensures that the entire directory is automatically cleaned up once the operation is complete, even if errors occur. This design prevents accumulation of intermediate files and maintains a clean filesystem.

Some tools also feature advanced handling for large datasets. For instance, the [`Jackhmmer`](https://github.com/aqlaboratory/openfold/openfold/data/tools/jackhmmer.py#L30) wrapper in [`/aqlaboratory/openfold/openfold/data/tools/jackhmmer.py`](https://github.com/aqlaboratory/openfold/openfold/data/tools/jackhmmer.py) can stream large database chunks, downloading them concurrently and processing them sequentially to manage memory and disk usage effectively. This minimizes I/O wait times and enables the system to work with databases that might otherwise be too large to fit in local storage. Parsing the diverse output formats from these tools (e.g., A3M, Stockholm, HHR) is handled separately; see [Parsing Tool Outputs and MSA File Handling](#bioinformatics-tool-wrappers-parsing-tool-outputs-and-msa-file-handling).
