### Auxiliary Prediction Heads
Auxiliary prediction heads within OpenFold are responsible for generating various intermediate and final predictions that contribute to model training and evaluation. These heads transform the refined embeddings produced by the core model into specific outputs, such as residue-level quality estimates, inter-residue distance distributions, and masked sequence reconstructions.

The [`AuxiliaryHeads`](https://github.com/aqlaboratory/openfold/openfold/model/heads.py#L28) class in [`/aqlaboratory/openfold/openfold/model/heads.py`](https://github.com/aqlaboratory/openfold/openfold/model/heads.py) consolidates these different prediction tasks. It contains several specialized modules:
*   The [`PerResidueLDDTCaPredictor`](https://github.com/aqlaboratory/openfold/openfold/model/heads.py#L100) estimates the local quality of the predicted structure at each residue by outputting logits for lDDT-Ca scores. These logits are then converted into predicted Local Distance Difference Test (pLDDT) scores, which indicate the confidence of the model in the local accuracy of its prediction.
*   The [`DistogramHead`](https://github.com/aqlaboratory/openfold/openfold/model/heads.py#L127) predicts the probability distribution of distances between all pairs of residues. This distogram prediction is a key intermediate target during training, guiding the model to learn correct spatial relationships between residues.
*   The [`MaskedMSAHead`](https://github.com/aqlaboratory/openfold/openfold/model/heads.py#L203) is used for a self-supervised learning objective where the model attempts to reconstruct masked tokens in the Multiple Sequence Alignment (MSA). This helps the model learn rich representations of protein sequences and their evolutionary conservation.
*   The [`ExperimentallyResolvedHead`](https://github.com/aqlaboratory/openfold/openfold/model/heads.py#L236) predicts whether a residue is experimentally resolved. This can be used to compare predictions against experimental data and potentially guide model training.

Additionally, the [`AuxiliaryHeads`](https://github.com/aqlaboratory/openfold/openfold/model/heads.py#L28) can include a [`TMScoreHead`](https://github.com/aqlaboratory/openfold/openfold/model/heads.py#L170) for predicting TM-score related information, which is a metric for structural similarity. These heads convert intermediate single, pair, and MSA embeddings into logits or scores for their respective tasks. The outputs from these auxiliary heads are crucial for computing the various loss functions that guide the model's learning process. For more details on how these predictions are used in training, refer to [Advanced Loss Functions for Structure Prediction](#core-utility-functions-and-performance-optimization-advanced-loss-functions-for-structure-prediction).
