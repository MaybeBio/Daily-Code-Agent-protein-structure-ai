### Atomistic Structure Generation and Optimization
The [`torch-sim`](https://github.com/torchsim/torch-sim/README.md#L3) repository includes methods for generating and optimizing atomic structures, which are central to various computational materials science workflows, particularly crystallization. These methods leverage PyTorch tensors for underlying computations, allowing for GPU acceleration.

A foundational aspect of structure generation involves minimizing atomic overlaps. This is achieved using a soft-sphere potential, implemented through [`SoftSphereModel`](https://github.com/torchsim/torch-sim/torch_sim/models/soft_sphere.py#L175) and [`SoftSphereMultiModel`](https://github.com/torchsim/torch-sim/torch_sim/models/soft_sphere.py#L248). These models describe repulsive interactions between atoms, preventing them from occupying the same space. The parameters for these potentials, such as atomic diameters, are estimated dynamically based on elemental properties derived from [`Pymatgen`](https://github.com/torchsim/torch-sim/README.md#L24)'s [`Composition`](https://github.com/torchsim/torch-sim/torch_sim/workflows/a2c.py#L16) class, considering factors like metallic, atomic, and ionic radii.

For instance, initial atomic configurations can be created using functions like [`random_packed_structure`](https://github.com/torchsim/torch-sim/torch_sim/workflows/a2c.py#L210) (for single-species systems) and [`random_packed_structure_multi`](https://github.com/torchsim/torch-sim/torch_sim/workflows/a2c.py#L315) (for multi-species systems) found in [`/torchsim/torch-sim/torch_sim/workflows/a2c.py`](https://github.com/torchsim/torch-sim/torch_sim/workflows/a2c.py). These functions randomly place atoms within a simulation cell and then use an optimization algorithm to relieve overlaps by minimizing the soft-sphere potential energy.

The primary algorithm employed for geometry optimization across various scenarios is the Fast Inertial Relaxation Engine (FIRE). This algorithm is known for its efficiency in finding local energy minima. Within [`torch-sim`](https://github.com/torchsim/torch-sim/README.md#L3), FIRE is integrated through functions such as [`ts.fire_init`](https://github.com/torchsim/torch-sim/torch_sim/workflows/a2c.py#L298) and [`ts.fire_step`](https://github.com/torchsim/torch-sim/torch_sim/workflows/a2c.py#L308) (as utilized in [`/torchsim/torch-sim/torch_sim/workflows/a2c.py`](https://github.com/torchsim/torch-sim/torch_sim/workflows/a2c.py)).

The framework supports different types of structural relaxation depending on whether the unit cell parameters are allowed to change:
*   **Fixed Cell Relaxation**: Atomic positions are optimized while the unit cell dimensions remain constant.
*   **Unit Cell Relaxation**: Both atomic positions and the unit cell parameters are optimized, allowing the cell shape and volume to adapt to the minimum energy configuration.
*   **Frechet Cell Relaxation**: Similar to unit cell relaxation, but specifically uses the Frechet metric to guide cell parameter changes.

These relaxation capabilities, found in functions like [`get_relaxed_structure`](https://github.com/torchsim/torch-sim/torch_sim/workflows/a2c.py#L829), [`get_unit_cell_relaxed_structure`](https://github.com/torchsim/torch-sim/torch_sim/workflows/a2c.py#L684), and [`get_frechet_cell_relaxed_structure`](https://github.com/torchsim/torch-sim/torch_sim/workflows/a2c.py#L756) in [`/torchsim/torch-sim/torch_sim/workflows/a2c.py`](https://github.com/torchsim/torch-sim/torch_sim/workflows/a2c.py), use a [`ModelInterface`](https://github.com/torchsim/torch-sim/torch_sim/models/interface.py#L71) to compute forces and stresses. The choice between these relaxation types is managed through the [`cell_filter`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py#L431) parameter in the [`ts.fire_init`](https://github.com/torchsim/torch-sim/torch_sim/workflows/a2c.py#L298) function. For a deeper understanding of these optimizers, refer to [Geometry Optimization Algorithms](#geometry-optimization-algorithms).
