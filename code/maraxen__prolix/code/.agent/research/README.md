# Research

> Investigation documents and design explorations.

## What Goes Here

Deep-dive analysis, design explorations, and investigation notes. Created during task planning or problem-solving phases.

## How to Use

1. **Create during planning**: Document findings during investigation
2. **Link in matrix**: Reference in Research column of DEVELOPMENT_MATRIX
3. **Name descriptively**: Use topic-based names like `auth-architecture.md`
