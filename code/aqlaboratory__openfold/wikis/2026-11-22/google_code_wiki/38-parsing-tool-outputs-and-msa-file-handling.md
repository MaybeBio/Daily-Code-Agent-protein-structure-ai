### Parsing Tool Outputs and MSA File Handling
OpenFold includes utilities for parsing various bioinformatics output formats, such as FASTA, Stockholm, A3M, and HHR, which are crucial for processing sequence alignments and template search results. These parsing functions convert raw text outputs from tools like HHblits, Jackhmmer, and HMMsearch into structured Python objects for further processing.

The [`Msa`](https://github.com/aqlaboratory/openfold/openfold/data/parsers.py#L29) dataclass, defined in [`/aqlaboratory/openfold/openfold/data/parsers.py`](https://github.com/aqlaboratory/openfold/openfold/data/parsers.py), represents multiple sequence alignments, storing sequences, deletion matrices, and descriptions. It provides methods for validation and truncation. Similarly, the [`TemplateHit`](https://github.com/aqlaboratory/openfold/openfold/data/parsers.py#L57) dataclass in the same file structures information about hits from template searches, including alignment details and residue indices.

Specific parsing functions handle different formats:
*   [`parse_fasta`](https://github.com/aqlaboratory/openfold/openfold/data/parsers.py#L70) processes FASTA strings into sequences and descriptions.
*   [`parse_stockholm`](https://github.com/aqlaboratory/openfold/openfold/data/parsers.py#L101) and [`parse_a3m`](https://github.com/aqlaboratory/openfold/openfold/data/parsers.py#L163) convert Stockholm and A3M formatted MSAs into [`Msa`](https://github.com/aqlaboratory/openfold/openfold/data/parsers.py#L29) objects, calculating deletion matrices and handling insertions. Utilities like [`convert_stockholm_to_a3m`](https://github.com/aqlaboratory/openfold/openfold/data/parsers.py#L211) and [`truncate_stockholm_msa`](https://github.com/aqlaboratory/openfold/openfold/data/parsers.py#L293) facilitate format conversion and size management of MSAs.
*   [`parse_hhr`](https://github.com/aqlaboratory/openfold/openfold/data/parsers.py#L519) processes HHR files from tools like HHsearch and HHblits into a list of [`TemplateHit`](https://github.com/aqlaboratory/openfold/openfold/data/parsers.py#L57) objects, extracting aligned sequences and residue indices.
*   [`parse_e_values_from_tblout`](https://github.com/aqlaboratory/openfold/openfold/data/parsers.py#L539) extracts E-values from Jackhmmer's tabular output.
*   [`parse_hmmsearch_a3m`](https://github.com/aqlaboratory/openfold/openfold/data/parsers.py#L603) and [`parse_hmmsearch_sto`](https://github.com/aqlaboratory/openfold/openfold/data/parsers.py#L649) parse HMMsearch outputs, extracting [`TemplateHit`](https://github.com/aqlaboratory/openfold/openfold/data/parsers.py#L57) objects and associated metadata like PDB IDs and chain information.

For efficiency, the system supports parallel parsing of multiple MSA files. The [`run_parse_all_msa_files_multiprocessing`](https://github.com/aqlaboratory/openfold/openfold/data/tools/parse_msa_files.py#L24) function in [`/aqlaboratory/openfold/openfold/data/tools/parse_msa_files.py`](https://github.com/aqlaboratory/openfold/openfold/data/tools/parse_msa_files.py) uses a process pool to concurrently parse Stockholm and A3M files from a specified directory, collecting the results and handling any parsing errors. This allows for faster data preparation when dealing with large datasets of alignment files. The [`main`](https://github.com/aqlaboratory/openfold/train_openfold.py#L284) function in the same file orchestrates this parallel parsing and serializes the processed MSA data into a pickle file for persistent storage and subsequent use.

The various bioinformatics tool wrappers, as described in [Bioinformatics Tool Wrappers](#bioinformatics-tool-wrappers), rely on these parsing utilities to interpret the output of external binaries and integrate the information into OpenFold's data processing pipeline.
