## MD Simulation Data Lifecycle and Analysis
The [`mddb-workflow`](https://github.com/mmb-irb/mddb-workflow/README.md#L4) package manages the lifecycle of Molecular Dynamics (MD) simulation projects, from initial setup to data analysis and reporting. It orchestrates the standardization, validation, and analysis of MD simulation projects by converting raw simulation outputs into normalized files, performing automated Quality Assurance (QA) and analysis pipelines, and packaging results and metadata.

The workflow's command-line interface (CLI) is defined by [`/mmb-irb/mddb-workflow/mddb_workflow/__main__.py`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/__main__.py) and [`/mmb-irb/mddb-workflow/mddb_workflow/console.py`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/console.py). This CLI provides various subcommands, enabling users to execute the main workflow, set up input files, convert data formats, filter and subset trajectories, modify structural chains, run Nucleic Acid Structural Statistical Analysis (NASSA), manage datasets, and update references. The [`main`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/console.py#L199) function in [`/mmb-irb/mddb-workflow/mddb_workflow/__main__.py`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/__main__.py) serves as the primary entry point for executing the package as a script.

Core workflow management is handled by the [`MD`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/mwf.py#L99) and [`Project`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/mwf.py#L1333) classes, detailed in [`/mmb-irb/mddb-workflow/mddb_workflow/mwf.py`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/mwf.py). The [`MD`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/mwf.py#L99) class represents a single MD simulation, managing its input files, handling remote data retrieval, and integrating various analyses as [`Task`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/utils/tasks.py#L24) instances. The [`Project`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/mwf.py#L1333) class manages collections of [`MD`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/mwf.py#L99) instances, overseeing project-level configurations and input management. Both classes employ lazy loading for properties and integrate remote data downloading capabilities.

Data management and input validation are central to the workflow, implemented in the [`/mmb-irb/mddb-workflow/mddb_workflow/core`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/core) directory. This includes tracking project and MD status in an SQLite database, ensuring data integrity with distributed filesystem locking, and generating configurations. Input validation is performed using Pydantic schemas, which ensure that input configurations are well-formed and consistent. For a detailed discussion of data management, refer to [Project and MD Dataset Management](#project-and-md-dataset-management).

The workflow offers a comprehensive suite of MD analysis tools, found in the [`/mmb-irb/mddb-workflow/mddb_workflow/analyses`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/analyses) directory. This suite covers diverse calculations such as area per lipid, channel analysis, clustering, density profiling, dihedral energies, interaction energies, helical parameters, hydrogen bonds, lipid interactions, and principal component analysis. These analyses often leverage external tools and libraries, with results consistently saved in JSON format.

General utilities and external tool integration, located in [`/mmb-irb/mddb-workflow/mddb_workflow/utils`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/utils), underpin the workflow. These utilities include persistent caching mechanisms for performance optimization, robust file and path management, error handling, reproducible argument checksums, and managed interactions with remote MDDB servers. The workflow also provides seamless integration with external tools and libraries such as GROMACS, MDAnalysis, and Pytraj through specialized wrappers. For more information, see [Workflow Utilities and Data Processing](#workflow-utilities-and-data-processing).

The [`mddb-workflow`](https://github.com/mmb-irb/mddb-workflow/README.md#L4) is designed for consistent and reproducible execution across different environments through containerization using Docker, as described in [Containerized Workflow Execution](#containerized-workflow-execution). The [`/mmb-irb/mddb-workflow/docker/Dockerfile`](https://github.com/mmb-irb/mddb-workflow/docker/Dockerfile) encapsulates the Miniconda3 environment, dependencies, and the software itself, ensuring portability. Installation details, including for High-Performance Computing (HPC) environments, are outlined in [`/mmb-irb/mddb-workflow/README.md`](https://github.com/mmb-irb/mddb-workflow/README.md).
