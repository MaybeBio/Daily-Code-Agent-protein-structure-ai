### Crystallization Workflow with A2C Method
The [`A2C`](https://github.com/torchsim/torch-sim/torch_sim/workflows/readme.md#L3) (Atomistic to Continuum) method provides a complete workflow for crystallization, enabling the generation, optimization, and validation of atomic structures within [`torch-sim`](https://github.com/torchsim/torch-sim/README.md#L3). This workflow is primarily implemented in [`/torchsim/torch-sim/torch_sim/workflows/a2c.py`](https://github.com/torchsim/torch-sim/torch_sim/workflows/a2c.py) and is designed to be a reproducible research showcase as detailed in [`/torchsim/torch-sim/torch_sim/workflows/readme.md`](https://github.com/torchsim/torch-sim/torch_sim/workflows/readme.md).

The process begins with generating initial atomic structures. For single-species systems, [`random_packed_structure`](https://github.com/torchsim/torch-sim/torch_sim/workflows/a2c.py#L210) generates random atomic positions, minimizing overlaps using a [Classical Pair Potentials](#model-implementations-and-integration-classical-pair-potentials) and the [Optimizer Implementations](#geometry-optimization-algorithms-optimizer-implementations). This functionality is extended to multi-species systems by [`random_packed_structure_multi`](https://github.com/torchsim/torch-sim/torch_sim/workflows/a2c.py#L315), which utilizes a [`SoftSphereMultiModel`](https://github.com/torchsim/torch-sim/torch_sim/models/soft_sphere.py#L248) and a diameter matrix to handle species-specific interactions. The [`min_distance`](https://github.com/torchsim/torch-sim/torch_sim/workflows/a2c.py#L26) function, which leverages [`transforms.get_pair_displacements`](https://github.com/torchsim/torch-sim/torch_sim/workflows/a2c.py#L56) to calculate pairwise distances under periodic boundary conditions, plays a crucial role in detecting atomic overlaps. Atomic diameters for soft-sphere potentials are estimated using [`get_diameter`](https://github.com/torchsim/torch-sim/torch_sim/workflows/a2c.py#L73) and [`get_diameter_matrix`](https://github.com/torchsim/torch-sim/torch_sim/workflows/a2c.py#L140), drawing on elemental properties from [`Pymatgen`](https://github.com/torchsim/torch-sim/README.md#L24)'s [`Composition`](https://github.com/torchsim/torch-sim/torch_sim/workflows/a2c.py#L16) class.

Once initial structures are generated, the workflow proceeds to subcell extraction and conversion. [`get_subcells_to_crystallize`](https://github.com/torchsim/torch-sim/torch_sim/workflows/a2c.py#L504) systematically extracts smaller subcells from a larger structure using a grid-based approach. This function supports compositional and atom count restrictions, allowing the workflow to focus on chemically relevant stoichiometries. The extracted subcell indices are then converted into distinct structure tuples by [`subcells_to_structures`](https://github.com/torchsim/torch-sim/torch_sim/workflows/a2c.py#L616) for further processing.

Structural relaxation is a key component, employing the [Optimizer Implementations](#geometry-optimization-algorithms-optimizer-implementations) for all geometry optimizations due to its efficiency. [`get_relaxed_structure`](https://github.com/torchsim/torch-sim/torch_sim/workflows/a2c.py#L829) performs atomic position relaxation with fixed cell parameters. For scenarios requiring cell changes, [`get_unit_cell_relaxed_structure`](https://github.com/torchsim/torch-sim/torch_sim/workflows/a2c.py#L684) relaxes both atomic positions and unit cell parameters while preserving the overall unit cell shape, while [`get_frechet_cell_relaxed_structure`](https://github.com/torchsim/torch-sim/torch_sim/workflows/a2c.py#L756) uses the Frechet metric for cell changes. These functions demonstrate how different [Cell Optimization and Filter-Based Design](#geometry-optimization-algorithms-cell-optimization-and-filter-based-design) can be applied.

Finally, structure validation is performed by [`valid_subcell`](https://github.com/torchsim/torch-sim/torch_sim/workflows/a2c.py#L434), which checks relaxed structures against criteria such as physically reasonable formation energy, successful energy reduction during optimization, and the absence of atomic fusion. The [`get_target_temperature`](https://github.com/torchsim/torch-sim/torch_sim/workflows/a2c.py#L660) function provides a temperature profile for melt-quench simulations, completing the crystallization workflow.
