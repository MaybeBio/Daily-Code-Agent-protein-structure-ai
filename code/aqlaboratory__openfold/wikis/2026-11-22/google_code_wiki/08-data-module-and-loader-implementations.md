### Data Module and Loader Implementations
Data loading for OpenFold models is managed through specialized PyTorch [`Dataset`](https://github.com/aqlaboratory/openfold/openfold/data/data_modules.py#L26) and [`DataLoader`](https://github.com/aqlaboratory/openfold/openfold/data/data_modules.py#L762) implementations, integrated with Lightning DataModules for orchestrating data flow across training, evaluation, and prediction. This modular approach ensures that raw protein data is efficiently transformed into model-ready features, supporting both single-chain and multimer protein prediction scenarios.

The fundamental [`torch.utils.data.Dataset`](https://github.com/aqlaboratory/openfold/openfold/data/data_modules.py#L26) subclasses are [`OpenFoldSingleDataset`](https://github.com/aqlaboratory/openfold/openfold/data/data_modules.py#L26) for single protein chains and [`OpenFoldSingleMultimerDataset`](https://github.com/aqlaboratory/openfold/openfold/data/data_modules.py#L292) for multimer complexes. These datasets, defined in [`/aqlaboratory/openfold/openfold/data/data_modules.py`](https://github.com/aqlaboratory/openfold/openfold/data/data_modules.py), are responsible for processing various input formats, such as mmCIF, PDB, or FASTA files, along with associated alignment data and template information. They integrate with the [Data Processing and Feature Generation Pipeline](#protein-structure-prediction-core-data-processing-and-feature-generation-pipeline) to convert raw input into structured feature dictionaries, utilizing external modules for template featurization, as discussed in [Template Feature Extraction and Processing](#protein-data-handling-and-preprocessing-template-feature-extraction-and-processing).

To handle large-scale training, [`OpenFoldDataset`](https://github.com/aqlaboratory/openfold/openfold/data/data_modules.py#L535) and [`OpenFoldMultimerDataset`](https://github.com/aqlaboratory/openfold/openfold/data/data_modules.py#L664), also found in [`/aqlaboratory/openfold/openfold/data/data_modules.py`](https://github.com/aqlaboratory/openfold/openfold/data/data_modules.py), implement AlphaFold's stochastic and deterministic filtering strategies. These filters enable dynamic sampling from diverse datasets, helping to regularize training and focus on relevant data distributions. The filtering logic considers factors like protein resolution, amino acid composition, and cluster size.

Batching of processed features is handled by [`OpenFoldBatchCollator`](https://github.com/aqlaboratory/openfold/openfold/data/data_modules.py#L756), which stacks individual feature dictionaries into a single batch. This is further extended by [`OpenFoldDataLoader`](https://github.com/aqlaboratory/openfold/openfold/data/data_modules.py#L762), both defined in [`/aqlaboratory/openfold/openfold/data/data_modules.py`](https://github.com/aqlaboratory/openfold/openfold/data/data_modules.py), which can dynamically inject batch-specific properties, such as the number of recycling iterations, allowing for flexible control over model behavior during training.

The overall data orchestration for training, validation, and prediction is managed by [`OpenFoldDataModule`](https://github.com/aqlaboratory/openfold/openfold/data/data_modules.py#L848) and [`OpenFoldMultimerDataModule`](https://github.com/aqlaboratory/openfold/openfold/data/data_modules.py#L1062), implemented in [`/aqlaboratory/openfold/openfold/data/data_modules.py`](https://github.com/aqlaboratory/openfold/openfold/data/data_modules.py). These modules configure and provide the necessary datasets and data loaders, ensuring a consistent data pipeline for different operational modes. They also leverage caching mechanisms for efficient access to protein entries. For more details on the transformation steps, refer to [Advanced Data Transformations and Augmentations](#protein-data-handling-and-preprocessing-advanced-data-transformations-and-augmentations).
