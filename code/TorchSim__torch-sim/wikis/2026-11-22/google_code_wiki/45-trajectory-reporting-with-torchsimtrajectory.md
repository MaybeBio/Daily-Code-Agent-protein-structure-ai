### Trajectory Reporting with `TorchSimTrajectory`
The [`TorchSimTrajectory`](https://github.com/torchsim/torch-sim/torch_sim/trajectory.py#L561) format facilitates the storage and retrieval of simulation data. Built upon [`HDF5`](https://github.com/torchsim/torch-sim/docs/user/overview.md#L24), this format efficiently captures trajectory information by natively integrating with batched states within TorchSim. It supports binary encoding of properties and on-the-fly compression for various data points, such as positions, velocities, temperatures, forces, and per-atom energies, as described in [`/torchsim/torch-sim/docs/user/overview.md`](https://github.com/torchsim/torch-sim/docs/user/overview.md). This system enables efficient tracking of simulation progress and detailed post-analysis, complementing the [High-Level Simulation Runners](#atomistic-simulation-engine-core-high-level-simulation-runners) that orchestrate the simulations.
