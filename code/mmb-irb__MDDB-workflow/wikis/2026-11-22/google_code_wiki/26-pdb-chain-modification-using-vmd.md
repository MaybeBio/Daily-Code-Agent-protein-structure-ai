### PDB Chain Modification using VMD
The [`chainer.py`](https://github.com/mmb-irb/mddb-workflow/manual_tools/chainer.py#L16) script, located at [`/mmb-irb/mddb-workflow/manual_tools/chainer.py`](https://github.com/mmb-irb/mddb-workflow/manual_tools/chainer.py), facilitates the modification of PDB chain identifiers for specific atom selections within a PDB file. This is achieved through programmatic interaction with VMD (Visual Molecular Dynamics), an external molecular visualization and analysis program.

The script operates by dynamically generating a Tcl script that VMD then executes. This generated script contains commands to select a subset of atoms based on a user-defined selection string (following VMD's atom selection syntax) and to assign a new chain letter to these selected atoms. After the modification, VMD writes the updated PDB file to a specified output path. The script manages the lifecycle of this process, including creating the temporary VMD command script and subsequently removing it once VMD has completed its execution. This approach allows for automated, precise manipulation of PDB chain information without direct manual intervention within the VMD graphical interface.
