## RFdiffusion3 (RFD3) for De Novo Design
RFdiffusion3 (RFD3) is a diffusion-based model for *de novo* biomolecular interaction design, capable of generating novel proteins, nucleic acids, and small molecules. It supports various design tasks such as sequence prediction, inverse folding, and sidechain design.

To get started with RFD3, installation typically involves [`pip install rc-foundry[rfd3]`](https://github.com/rosettacommons/foundry/models/rfd3/README.md#L143) and downloading model checkpoints using [`foundry install rfd3`](https://github.com/rosettacommons/foundry/README.md#L1). A key advanced feature for biomolecular design is hydrogen bond conditioning, which requires a separate installation of [`HBPLUS`](https://github.com/rosettacommons/foundry/models/rfd3/README.md#L143) and updating its path in the Foundry environment file. Detailed installation instructions are available in [`/rosettacommons/foundry/models/rfd3/docs/tutorials/RFdiffusion3_installation_tutorial.md`](https://github.com/rosettacommons/foundry/models/rfd3/docs/tutorials/RFdiffusion3_installation_tutorial.md).

Inference with RFD3 is performed using the [`rfd3 design`](https://github.com/rosettacommons/foundry/README.md#L1) command, which takes an output directory and an [`inputs`](https://github.com/rosettacommons/foundry/examples/all.ipynb#L102) JSON/YAML file specifying design constraints. The [`RFD3InferenceEngine`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/engine.py#L140) in [`/rosettacommons/foundry/models/rfd3/src/rfd3/engine.py`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/engine.py) handles input processing, batching, and output generation. The core diffusion process is managed by the [`RFD3DiffusionModule`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/model/RFD3_diffusion_module.py#L32) in [`/rosettacommons/foundry/models/rfd3/src/rfd3/model/RFD3_diffusion_module.py`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/model/RFD3_diffusion_module.py) and the [`ConditionalDiffusionSampler`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/model/inference_sampler.py#L582) in [`/rosettacommons/foundry/models/rfd3/src/rfd3/model/inference_sampler.py`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/model/inference_sampler.py), which iteratively denoises structures with conditional diffusion and classifier-free guidance. Output structures are saved as [`.cif.gz`](https://github.com/rosettacommons/foundry/models/rf3/README.md#L620) files, with design metrics in accompanying [`.json`](https://github.com/rosettacommons/foundry/models/rfd3/README.md#L67) files. For detailed examples, including enzyme design, nucleic acid binder design, and protein binder design, refer to the [`/rosettacommons/foundry/models/rfd3/docs/examples`](https://github.com/rosettacommons/foundry/models/rfd3/docs/examples) directory. Users can also control the trade-off between designability and diversity in generated outputs using parameters like [`inference_sampler.step_scale`](https://github.com/rosettacommons/foundry/models/rfd3/docs/input.md#L69) and [`inference_sampler.gamma_0`](https://github.com/rosettacommons/foundry/models/rfd3/docs/designability_vs_diversity.md#L8), or by setting [`is_non_loopy`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L191) in the input configuration, as discussed in [Controlling Designability vs. Diversity](#rfdiffusion3-rfd3-for-de-novo-design-rfd3-inference-and-design-examples-controlling-designability-vs-diversity).

The training infrastructure for RFD3 is built on [`lightning.fabric`](https://github.com/rosettacommons/foundry/examples/all.ipynb#L84) for distributed training and leverages Hydra for configuration management. The [`AADesignTrainer`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/trainer/rfd3.py#L33) in [`/rosettacommons/foundry/models/rfd3/src/rfd3/trainer/rfd3.py`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/trainer/rfd3.py) implements the protein design-specific training logic. A key aspect of RFD3 training is its sophisticated conditioning strategy, which creates random design problems by fixing atoms, sequences, or coordinates. This is primarily controlled via [`training_conditions`](https://github.com/rosettacommons/foundry/models/rfd3/README.md#L171) within the configuration files, as detailed in [RFD3 Training and Advanced Conditioning](#introduction-to-foundry-models-rfd3-training-and-advanced-conditioning). The system supports logging with Weights & Biases or CSV for tracking training progress. The framework also includes various [`Transform`](https://github.com/rosettacommons/foundry/models/rf3/README.md#L453) classes for preparing [`AtomArray`](https://github.com/rosettacommons/foundry/examples/all.ipynb#L20) data, managing conditioning, generating design features, and calculating hydrogen bonds, which are crucial for guiding the model during both training and inference. These are located within [`/rosettacommons/foundry/models/rfd3/src/rfd3/transforms`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/transforms).
