### Comprehensive Database Download and Preparation
The OpenFold codebase includes a suite of scripts designed to download, extract, and prepare various biological sequence and structure databases essential for protein structure prediction. These databases range from those originally used by AlphaFold to specialized resources for OpenFold's specific requirements. The primary entry point for managing these downloads is the [`/aqlaboratory/openfold/scripts`](https://github.com/aqlaboratory/openfold/scripts) directory, which contains shell scripts and Python utilities for orchestrating the entire data preparation pipeline.

A core script, [`/aqlaboratory/openfold/scripts/download_alphafold_dbs.sh`](https://github.com/aqlaboratory/openfold/scripts/download_alphafold_dbs.sh), acts as an orchestrator for downloading most AlphaFold-related databases. It allows users to choose between a full or reduced set of databases and subsequently calls dedicated sub-scripts for each resource. For instance, [`/aqlaboratory/openfold/scripts/download_bfd.sh`](https://github.com/aqlaboratory/openfold/scripts/download_bfd.sh) and [`/aqlaboratory/openfold/scripts/download_small_bfd.sh`](https://github.com/aqlaboratory/openfold/scripts/download_small_bfd.sh) handle the acquisition of the BFD database (Big Fantastic Database) in its full or smaller version, respectively. Similarly, [`/aqlaboratory/openfold/scripts/download_mgnify.sh`](https://github.com/aqlaboratory/openfold/scripts/download_mgnify.sh) fetches the MGnify database, and [`/aqlaboratory/openfold/scripts/download_pdb70.sh`](https://github.com/aqlaboratory/openfold/scripts/download_pdb70.sh) is responsible for the PDB70 database.

For protein structure data, [`/aqlaboratory/openfold/scripts/download_pdb_mmcif.sh`](https://github.com/aqlaboratory/openfold/scripts/download_pdb_mmcif.sh) downloads and processes the entire PDB mmCIF archive, flattening its directory structure for easier access. The script also handles the acquisition of the [`obsolete.dat`](https://github.com/aqlaboratory/openfold/train_openfold.py#L537) file, which tracks obsolete PDB entries. A related utility, [`/aqlaboratory/openfold/scripts/download_pdb_seqres.sh`](https://github.com/aqlaboratory/openfold/scripts/download_pdb_seqres.sh), specifically downloads and filters the PDB SeqRes database to include only protein sequences.

Beyond AlphaFold's original data, OpenFold also leverages and provides scripts for its own model parameters and specialized resources. For instance, [`/aqlaboratory/openfold/scripts/download_openfold_params.sh`](https://github.com/aqlaboratory/openfold/scripts/download_openfold_params.sh) and its alternatives, [`/aqlaboratory/openfold/scripts/download_openfold_params_gdrive.sh`](https://github.com/aqlaboratory/openfold/scripts/download_openfold_params_gdrive.sh) and [`/aqlaboratory/openfold/scripts/download_openfold_params_huggingface.sh`](https://github.com/aqlaboratory/openfold/scripts/download_openfold_params_huggingface.sh), are used to obtain pre-trained OpenFold model weights from various sources. The SoloSeq model parameters and corresponding ESM-1b embeddings are downloaded via [`/aqlaboratory/openfold/scripts/download_openfold_soloseq_params.sh`](https://github.com/aqlaboratory/openfold/scripts/download_openfold_soloseq_params.sh) and [`/aqlaboratory/openfold/scripts/download_soloseq_embeddings.sh`](https://github.com/aqlaboratory/openfold/scripts/download_soloseq_embeddings.sh), respectively.

Databases crucial for sequence alignment, such as Uniref and Uniclust, are managed through scripts like [`/aqlaboratory/openfold/scripts/download_uniref30.sh`](https://github.com/aqlaboratory/openfold/scripts/download_uniref30.sh), [`/aqlaboratory/openfold/scripts/download_uniref90.sh`](https://github.com/aqlaboratory/openfold/scripts/download_uniref90.sh), and [`/aqlaboratory/openfold/scripts/download_uniclust30.sh`](https://github.com/aqlaboratory/openfold/scripts/download_uniclust30.sh). For multimer predictions, [`/aqlaboratory/openfold/scripts/download_uniprot.sh`](https://github.com/aqlaboratory/openfold/scripts/download_uniprot.sh) downloads and merges the UniProt TrEMBL and SwissProt databases into a single FASTA file.

The system also integrates specific resources like the ColabFold environmental database, downloaded by [`/aqlaboratory/openfold/scripts/download_colabfold_envdb.sh`](https://github.com/aqlaboratory/openfold/scripts/download_colabfold_envdb.sh), which is part of a larger MMseqs2-related download process initiated by [`/aqlaboratory/openfold/scripts/download_mmseqs_dbs.sh`](https://github.com/aqlaboratory/openfold/scripts/download_mmseqs_dbs.sh).

Beyond mere downloading, the scripts also include utilities for transforming data. For example, [`/aqlaboratory/openfold/scripts/data_dir_to_fasta.py`](https://github.com/aqlaboratory/openfold/scripts/data_dir_to_fasta.py) converts directories of protein structure files (CIF, PDB, or ProteinNet [`.core`](https://github.com/aqlaboratory/openfold/scripts/unpack_proteinnet.py#L8)) into a single FASTA file, extracting amino acid sequences and handling chain identification. [`/aqlaboratory/openfold/scripts/download_cameo.py`](https://github.com/aqlaboratory/openfold/scripts/download_cameo.py) specifically downloads CAMEO protein data, including CIF files and FASTA sequences, with options for filtering by sequence length. The [`/aqlaboratory/openfold/scripts/download_roda_pdbs.sh`](https://github.com/aqlaboratory/openfold/scripts/download_roda_pdbs.sh) script downloads CIF files relevant to RODA alignments and reports any missing files. These scripts collectively ensure that the OpenFold environment has access to the necessary data in appropriate formats for both training and inference pipelines.
