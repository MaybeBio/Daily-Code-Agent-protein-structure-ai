### Template Information Integration
Template structural information is integrated into the model to enrich its representations through a multi-stage process involving specialized embedders, template pair stacks, and pointwise attention mechanisms. This integration provides the model with prior structural knowledge from homologous proteins, which is then refined and combined with sequence-derived features.

The process begins with the [`TemplateEmbedder`](https://github.com/aqlaboratory/openfold/openfold/model/embedders.py#L635) or [`TemplateEmbedderMultimer`](https://github.com/aqlaboratory/openfold/openfold/model/embedders.py#L878) modules in [`/aqlaboratory/openfold/openfold/model/embedders.py`](https://github.com/aqlaboratory/openfold/openfold/model/embedders.py), which are responsible for extracting and initializing template features. These modules leverage utility functions from [`/aqlaboratory/openfold/openfold/utils/feats.py`](https://github.com/aqlaboratory/openfold/openfold/utils/feats.py) to build initial template pair and angle features from raw template data. The [`TemplateSingleEmbedder`](https://github.com/aqlaboratory/openfold/openfold/model/embedders.py#L509) and [`TemplatePairEmbedder`](https://github.com/aqlaboratory/openfold/openfold/model/embedders.py#L552) further process these features, transforming them into suitable embeddings for single and pairwise representations, respectively. Multimer-specific template embedders, [`TemplatePairEmbedderMultimer`](https://github.com/aqlaboratory/openfold/openfold/model/embedders.py#L761) and [`TemplateSingleEmbedderMultimer`](https://github.com/aqlaboratory/openfold/openfold/model/embedders.py#L822), handle the complexities of multichain templates, incorporating features like distance grams, amino acid types, and backbone information.

Once embedded, the template pair features are passed through a [`TemplatePairStack`](https://github.com/aqlaboratory/openfold/openfold/model/template.py#L358) defined in [`/aqlaboratory/openfold/openfold/model/template.py`](https://github.com/aqlaboratory/openfold/openfold/model/template.py). This stack consists of multiple [`TemplatePairStackBlock`](https://github.com/aqlaboratory/openfold/openfold/model/template.py#L150) instances, which iteratively refine the template pair embedding. Each block applies a sequence of operations, including row-wise and column-wise dropout for regularization, [Detailed Breakdown of the Evoformer Stack](#alphafold2-model-architecture-implementation-detailed-breakdown-of-the-evoformer-stack) (specifically [`TriangleAttentionStartingNode`](https://github.com/aqlaboratory/openfold/openfold/model/triangular_attention.py#L166) and [`TriangleAttentionEndingNode`](https://github.com/aqlaboratory/openfold/openfold/model/triangular_attention.py#L169)), and triangular multiplicative updates ([`TriangleMultiplicationOutgoing`](https://github.com/aqlaboratory/openfold/openfold/model/triangular_multiplicative_update.py#L561), [`TriangleMultiplicationIncoming`](https://github.com/aqlaboratory/openfold/openfold/model/triangular_multiplicative_update.py#L568)). These operations facilitate the propagation of information within the 2D template representation, enabling the model to capture complex relationships. A [`PairTransition`](https://github.com/aqlaboratory/openfold/openfold/model/pair_transition.py#L24) further refines the representation through a feed-forward network. The [`TemplatePairStack`](https://github.com/aqlaboratory/openfold/openfold/model/template.py#L358) supports activation checkpointing and dynamic chunk sizing during inference to manage memory efficiently, which is crucial given the potentially large number of templates.

Finally, the refined template pair embeddings are integrated into the main model's pairwise representation using [`TemplatePointwiseAttention`](https://github.com/aqlaboratory/openfold/openfold/model/template.py#L56) from [`/aqlaboratory/openfold/openfold/model/template.py`](https://github.com/aqlaboratory/openfold/openfold/model/template.py). This module applies attention between the model's current pair embedding and the processed template embeddings. This pointwise attention mechanism allows the model to selectively incorporate relevant structural information from templates, effectively enriching its internal representation of inter-residue relationships. For memory optimization during inference, functions like [`embed_templates_offload`](https://github.com/aqlaboratory/openfold/openfold/model/template.py#L490) and [`embed_templates_average`](https://github.com/aqlaboratory/openfold/openfold/model/template.py#L603) are employed to process templates individually or in groups, offloading intermediate results to the CPU or averaging contributions to manage GPU memory. These methods are critical for handling a large number of templates or very long sequences.
