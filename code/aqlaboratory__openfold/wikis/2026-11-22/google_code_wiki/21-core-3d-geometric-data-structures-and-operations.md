### Core 3D Geometric Data Structures and Operations
OpenFold utilizes a set of PyTorch-based data structures for efficient handling of 3D geometric operations, essential for representing and manipulating protein structures. These structures are designed to support batched tensor computations, allowing for parallel processing of multiple geometric entities.

The primary data structures are:
*   [`Vec3Array`](https://github.com/aqlaboratory/openfold/openfold/utils/geometry/vector.py#L25): Represents 3D vectors, detailed in [`/aqlaboratory/openfold/openfold/utils/geometry/vector.py`](https://github.com/aqlaboratory/openfold/openfold/utils/geometry/vector.py). This data structure supports standard vector arithmetic operations such as addition, subtraction, multiplication, and division, along with dot products, cross products, and norm calculations. It provides a flexible way to manage single vectors or batches of vectors.
*   [`Rot3Array`](https://github.com/aqlaboratory/openfold/openfold/utils/geometry/rotation_matrix.py#L30): Represents 3x3 rotation matrices, detailed in [`/aqlaboratory/openfold/openfold/utils/geometry/rotation_matrix.py`](https://github.com/aqlaboratory/openfold/openfold/utils/geometry/rotation_matrix.py). This structure facilitates operations such as matrix multiplication for composing rotations, inversion, and applying rotations to 3D points. It also supports conversions from and to quaternions and the construction of rotation matrices from two vectors, which is useful for defining coordinate frames.
*   [`Rigid3Array`](https://github.com/aqlaboratory/openfold/openfold/utils/geometry/rigid_matrix_vector.py#L30): Combines [`Rot3Array`](https://github.com/aqlaboratory/openfold/openfold/utils/geometry/rotation_matrix.py#L30) for rotation and [`Vec3Array`](https://github.com/aqlaboratory/openfold/openfold/utils/geometry/vector.py#L25) for translation to represent 3D rigid transformations, detailed in [`/aqlaboratory/openfold/openfold/utils/geometry/rigid_matrix_vector.py`](https://github.com/aqlaboratory/openfold/openfold/utils/geometry/rigid_matrix_vector.py). This allows for complex operations like transformation composition, inversion, and applying transformations to points. It also includes functionalities for converting to and from 4x4 homogeneous matrices, ensuring compatibility with various geometric computation frameworks.

These geometric data structures are housed in the [`/aqlaboratory/openfold/openfold/utils/geometry`](https://github.com/aqlaboratory/openfold/openfold/utils/geometry) directory. The [`QuatRigid`](https://github.com/aqlaboratory/openfold/openfold/utils/geometry/quat_rigid.py#L10) module, found in [`/aqlaboratory/openfold/openfold/utils/geometry/quat_rigid.py`](https://github.com/aqlaboratory/openfold/openfold/utils/geometry/quat_rigid.py), translates neural network activations into [`Rigid3Array`](https://github.com/aqlaboratory/openfold/openfold/utils/geometry/rigid_matrix_vector.py#L30) transformations using quaternion representations for rotation, providing a differentiable interface between model outputs and geometric transformations. Further details on this module can be found in [Quaternion-based Rigid Body Transformations](#protein-structure-representation-and-numerical-operations-quaternion-based-rigid-body-transformations). The [`/aqlaboratory/openfold/openfold/utils/geometry/__init__.py`](https://github.com/aqlaboratory/openfold/openfold/utils/geometry/__init__.py) file aggregates these types and related utility functions, providing a centralized access point.
