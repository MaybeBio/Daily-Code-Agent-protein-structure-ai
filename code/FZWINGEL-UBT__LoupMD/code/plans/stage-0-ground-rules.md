## Working rules for every step of Stages 0 and 1

- **Where.** Edit and commit in `D:\Margraf\LoupMD-release` with Windows git from Git Bash. Build and run in WSL
  under `/mnt/d/Margraf/LoupMD-release`. Nothing is edited, built or committed in `D:\Margraf\LoupMD`.
- **GPU.** One job at a time. Before each GPU job:
  1. `nvidia-smi --query-compute-apps=pid --format=csv,noheader` must be empty and no `mem_cmp`, `bench_md`,
     `bench_family`, `test_gate`, `pytest`, `nsys` or `ncu` process of the other session may run
     (`.tmp_o/gpu_state.sh` prints both; `.tmp_o/wait_gpu.sh` waits for an idle minute).
  2. The job runs under FastMACE's reservation, so FastMACE lanes see it:
     `python3 /mnt/d/Margraf/FastMACE/tools/ci/local_gpu.py run --quiet --purpose "loupmd release: <what>" -- <command>`.
- **Plan cache.** GPU runs of this worktree set `LOUP_CACHE_DIR=$HOME/.cache/loupmd-release`, so the GEMM plan
  files of `~/.cache/loupmd/` (the other session's) are never written. Bundles and gate references stay in
  `~/.cache/loupmd/`: they are keyed by content and only added to.
- **Library.** `make -j4 CUDA_ARCH=sm_120` installs `./libloupmd.so` of this worktree; no process of the other
  session loads it. While a job of this worktree runs, build to `build/sm_120/libloupmd.so`, copy to
  `libloupmd_cand.so` and select it with `LOUP_LIB`.
- **Python.** `/home/fzwin/environments/mace_cueq_latest/bin/python` with `TORCH_FORCE_NO_WEIGHTS_ONLY_LOAD=1`.
- **Commands used below.**
  - `PY=/home/fzwin/environments/mace_cueq_latest/bin/python`
  - `RUN="env TORCH_FORCE_NO_WEIGHTS_ONLY_LOAD=1 LOUP_CACHE_DIR=$HOME/.cache/loupmd-release"`
  - `GPU="python3 /mnt/d/Margraf/FastMACE/tools/ci/local_gpu.py run --quiet --purpose"`

Not started until the owner names the moment. Until then:

- New Python code goes to its final path under `loupmd/` (`PLAN.md` §4.2). Nothing is added to `python/`, and
  `python/*.py` are not edited.
- `loupmd/_legacy.py` loads `python/loupmd.py` by file path and re-exports the bundle cache
  (`ensure_loup_bundle`, `exporter_fingerprint`, `EXPORTER_SOURCES`, `_model_digest`), so tests import one
  package. `tests/conftest.py` puts the repository root before `python/` on `sys.path`.
