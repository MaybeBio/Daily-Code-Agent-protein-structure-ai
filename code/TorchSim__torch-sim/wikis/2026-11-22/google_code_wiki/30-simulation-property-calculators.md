## Simulation Property Calculators
The [`torch-sim`](https://github.com/torchsim/torch-sim/README.md#L3) repository provides tools for calculating correlation properties, which are essential for analyzing the dynamics and transport phenomena observed in atomistic simulations. These tools are primarily found in the [`/torchsim/torch-sim/torch_sim/properties`](https://github.com/torchsim/torch-sim/torch_sim/properties) directory. The core functionality centers around computing time correlation functions for various simulation properties, leveraging PyTorch for efficient, GPU-accelerated calculations using Fast Fourier Transforms (FFT).

The framework includes a general-purpose [`CorrelationCalculator`](https://github.com/torchsim/torch-sim/torch_sim/properties/correlations.py#L100) that can compute both auto- and cross-correlation functions for arbitrary time-dependent data extracted from simulation states. To manage the historical data required for these calculations, an efficient [`CircularBuffer`](https://github.com/torchsim/torch-sim/torch_sim/properties/correlations.py#L31) is employed, ensuring memory management is optimized during long simulations.

Building upon the [`CorrelationCalculator`](https://github.com/torchsim/torch-sim/torch_sim/properties/correlations.py#L100), specialized classes are provided for frequently used physical properties. The [`VelocityAutoCorrelation`](https://github.com/torchsim/torch-sim/torch_sim/properties/correlations.py#L392) class is designed to compute the Velocity AutoCorrelation Function (VACF), a key quantity for understanding atomic diffusion and vibrational dynamics. Similarly, the [`HeatFluxAutoCorrelation`](https://github.com/torchsim/torch-sim/torch_sim/properties/correlations.py#L479) class calculates the Heat Flux AutoCorrelation Function (HFACF), which is crucial for analyzing thermal conductivity. Both specialized calculators manage running averages of their respective correlation functions over multiple simulation windows, allowing for robust statistical analysis.
