### Comprehensive Training Progress Logging and Loss Monitoring
This section discusses the various callbacks that facilitate monitoring and reporting of key training metrics, loss breakdowns, and resource usage with structured console output. These callbacks are located in the [`/rosettacommons/foundry/src/foundry/callbacks/train_logging.py`](https://github.com/rosettacommons/foundry/src/foundry/callbacks/train_logging.py) file.

The [`LogModelParametersCallback`](https://github.com/rosettacommons/foundry/src/foundry/callbacks/train_logging.py#L26) records the total and trainable parameters of a model when training commences, providing a snapshot of the model's complexity. For debugging purposes, the [`PrintExampleIDBeforeForwardPassCallback`](https://github.com/rosettacommons/foundry/src/foundry/callbacks/train_logging.py#L33) can be used to output the unique identifier of each example processed in a batch, along with its rank, epoch, and batch information.

To understand dataset utilization, the [`LogDatasetSamplingRatiosCallback`](https://github.com/rosettacommons/foundry/src/foundry/callbacks/train_logging.py#L58) monitors and logs the proportions of data sampled from different datasets during an epoch. This is achieved by tracking [`example_id`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/engine.py#L95) information from incoming batches and summarizing the distribution at the end of each training epoch.

The [`LogLearningRateCallback`](https://github.com/rosettacommons/foundry/src/foundry/callbacks/train_logging.py#L93) tracks the learning rate of the optimizer, reporting its value at regular intervals throughout training. This allows monitoring of learning rate schedules and adjustments over time.

For a detailed view of training performance, the [`LogAF3TrainingLossesCallback`](https://github.com/rosettacommons/foundry/src/foundry/callbacks/train_logging.py#L116) provides comprehensive logging of various loss components. It tracks individual loss types using [`MeanMetric`](https://github.com/rosettacommons/foundry/src/foundry/callbacks/train_logging.py#L14) instances, records the start time of each epoch, and processes the outputs of each training batch to update these metrics. At specified intervals, it logs mean batch losses and can optionally log per-structure losses. At the end of each epoch, it summarizes the average losses, total optimizer steps, number of batches processed, and overall epoch duration. This callback leverages the [`rich`](https://github.com/rosettacommons/foundry/pyproject.toml#L31) library for enhanced console output, presenting information in structured panels and tables, improving readability and aiding in quick assessment of training progress.
