### Curated SARS-CoV-2 Variant Sequences
The [`/mmb-irb/mddb-workflow/mddb_workflow/resources/covid_variants.py`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/resources/covid_variants.py) module provides a curated collection of SARS-CoV-2 spike protein amino acid sequences for various variants. This resource supports research and analysis within the workflow by offering a centralized repository for these sequences. The module defines a dictionary, [`covid_spike_variants`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/resources/covid_variants.py#L4), which maps common variant names (e.g., "WT", "Alpha", "Delta", "Omicron/BA.1") to their corresponding full spike protein amino acid sequences. This structure allows for direct and unambiguous retrieval of specific variant sequences. The sequences are manually curated, ensuring their reliability for downstream applications. This resource is part of the broader [Biological Resources](#biological-resources) section, which includes tools for processing scientific output data.
