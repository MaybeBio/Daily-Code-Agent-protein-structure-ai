## OpenFold Management Scripts
The [`/aqlaboratory/openfold/scripts`](https://github.com/aqlaboratory/openfold/scripts) directory centralizes a collection of utilities for managing the OpenFold environment and its various workflows. These scripts facilitate tasks such as setting up the development environment, downloading necessary biological databases, generating protein sequence alignments, configuring DeepSpeed for optimized training and inference, and converting model checkpoints.

Environment setup and the installation of third-party dependencies are handled by scripts like [`/aqlaboratory/openfold/scripts/activate_conda_env.sh`](https://github.com/aqlaboratory/openfold/scripts/activate_conda_env.sh), [`/aqlaboratory/openfold/scripts/deactivate_conda_env.sh`](https://github.com/aqlaboratory/openfold/scripts/deactivate_conda_env.sh), and [`/aqlaboratory/openfold/scripts/install_third_party_dependencies.sh`](https://github.com/aqlaboratory/openfold/scripts/install_third_party_dependencies.sh). These scripts ensure the Conda environment is properly configured and essential bioinformatics tools, such as HH-suite, along with performance libraries like CUTLASS, are installed.

A comprehensive suite of scripts is dedicated to downloading and preparing various biological databases. This includes [`/aqlaboratory/openfold/scripts/download_alphafold_dbs.sh`](https://github.com/aqlaboratory/openfold/scripts/download_alphafold_dbs.sh), which orchestrates the download of multiple AlphaFold-related databases (BFD, MGnify, PDB70, PDB mmCIF, Uniref30, Uniref90, UniProt, PDB SeqRes) by invoking specialized sub-scripts. Model parameters for both AlphaFold and OpenFold are downloaded via [`/aqlaboratory/openfold/scripts/download_alphafold_params.sh`](https://github.com/aqlaboratory/openfold/scripts/download_alphafold_params.sh) and [`/aqlaboratory/openfold/scripts/download_openfold_params.sh`](https://github.com/aqlaboratory/openfold/scripts/download_openfold_params.sh) respectively. These scripts manage the acquisition of pre-trained weights and other essential data for model operation. Specific scripts such as [`/aqlaboratory/openfold/scripts/download_cameo.py`](https://github.com/aqlaboratory/openfold/scripts/download_cameo.py) also handle the acquisition of CAMEO protein data, including CIF files and FASTA sequences.

For generating protein sequence alignments, scripts like [`/aqlaboratory/openfold/scripts/precompute_alignments.py`](https://github.com/aqlaboratory/openfold/scripts/precompute_alignments.py) and [`/aqlaboratory/openfold/scripts/precompute_alignments_mmseqs.py`](https://github.com/aqlaboratory/openfold/scripts/precompute_alignments_mmseqs.py) are used. These orchestrate the execution of tools like JackHMMER, HHblits, HMMsearch, and MMseqs2 to create multiple sequence alignments (MSAs) and template information, which are crucial features for protein structure prediction. The output of these processes can then be converted to a FASTA format using [`/aqlaboratory/openfold/scripts/alignment_data_to_fasta.py`](https://github.com/aqlaboratory/openfold/scripts/alignment_data_to_fasta.py). For large-scale alignment generation, especially on HPC clusters, the specialized script [`/aqlaboratory/openfold/scripts/slurm_scripts/run_uniclust30_search.sh`](https://github.com/aqlaboratory/openfold/scripts/slurm_scripts/run_uniclust30_search.sh) facilitates Uniclust30 all-against-all alignments within a SLURM environment, managing data transfer, input splitting, and parallel execution.

The management of these alignment databases is further supported by scripts in the [`/aqlaboratory/openfold/scripts/alignment_db_scripts`](https://github.com/aqlaboratory/openfold/scripts/alignment_db_scripts) directory. These scripts, including [`/aqlaboratory/openfold/scripts/alignment_db_scripts/create_alignment_db.py`](https://github.com/aqlaboratory/openfold/scripts/alignment_db_scripts/create_alignment_db.py) and [`/aqlaboratory/openfold/scripts/alignment_db_scripts/create_alignment_db_sharded.py`](https://github.com/aqlaboratory/openfold/scripts/alignment_db_scripts/create_alignment_db_sharded.py), are responsible for creating, extending, and consolidating protein alignment databases. This includes handling sharding for performance and efficiently integrating non-unique protein chains, as described in [Protein Alignment Database Management](#openfold-management-scripts-protein-alignment-database-management).

DeepSpeed integration is managed through scripts such as [`/aqlaboratory/openfold/scripts/build_deepspeed_config.py`](https://github.com/aqlaboratory/openfold/scripts/build_deepspeed_config.py), which dynamically generates DeepSpeed configuration JSON files, and [`/aqlaboratory/openfold/scripts/deepspeed_inference_test.py`](https://github.com/aqlaboratory/openfold/scripts/deepspeed_inference_test.py), designed for testing DeepSpeed's inference capabilities.

Finally, model checkpoint conversion is handled by [`/aqlaboratory/openfold/scripts/convert_of_weights_to_jax.py`](https://github.com/aqlaboratory/openfold/scripts/convert_of_weights_to_jax.py) for converting OpenFold PyTorch weights to AlphaFold JAX-compatible [`.npz`](https://github.com/aqlaboratory/openfold/train_openfold.py#L584) format, and [`/aqlaboratory/openfold/scripts/convert_v1_to_v2_weights.py`](https://github.com/aqlaboratory/openfold/scripts/convert_v1_to_v2_weights.py) for updating OpenFold checkpoints from older V1 to newer V2 key formats, ensuring compatibility and interoperability.
