# rosettacommons/foundry Overview
The Foundry repository provides a collection of biomolecular design models. It offers tools for inverse folding, *de novo* design, and structure prediction across proteins, ligands, and nucleic acids. These models integrate into a common framework for efficient biomolecular engineering.

The framework includes Message Passing Neural Network (MPNN) models for inverse folding and sequence design. These models, including [`ProteinMPNN`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/mpnn.py#L21), [`LigandMPNN`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/mpnn.py#L2303), and [`SolubleMPNN`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/mpnn.py#L2173), generate amino acid sequences for protein backbones or sequences that bind to specific ligands. They utilize graph featurization, message passing layers, and decoding strategies to process structural information and predict optimal sequences. Further details are available in [Protein and Ligand Inverse Folding (MPNN)](#protein-and-ligand-inverse-folding-mpnn).

For structure prediction, Foundry incorporates RoseTTAFold3 (RF3). This model predicts three-dimensional protein structures from amino acid sequences. RF3 uses a diffusion-based generative approach and includes confidence estimation, providing Predicted Local Distance Difference Test (pLDDT) and Predicted Aligned Error (PAE) metrics for assessment. Learn more in [RoseTTAFold3 (RF3) for Structure Prediction](#rosettafold3-rf3-for-structure-prediction).

RFdiffusion3 (RFD3) supports *de novo* biomolecular interaction design. This generative diffusion model creates novel proteins, nucleic acids, and small molecules with desired binding properties. It employs iterative denoising and allows users to define design constraints through an [`InputSpecification`](https://github.com/rosettacommons/foundry/models/rfd3/docs/input.md#L112) for elements like [`contig`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L134) regions, [`ligand`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L142) specifications, and [`InputSelection`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/parsing.py#L26) methods. More information is in [RFdiffusion3 (RFD3) for De Novo Design](#rfdiffusion3-rfd3-for-de-novo-design).

An extension of RFD3, RFdiffusion3NA (RFD3NA), supports multipolymer design, handling complex protein-DNA-RNA systems. It offers specialized [`contig`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L134) specifications for nucleic acids and advanced [`InputSelection`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/parsing.py#L26) for detailed control over residue and atom selections. This includes constraints for nucleic acid secondary structure and base-pairing, and integration of symmetry operations. Details are available in [RFdiffusion3NA (RFD3NA) for Multipolymer Design](#rfdiffusion3na-rfd3na-for-multipolymer-design).

The Foundry core library provides the foundational infrastructure for machine learning workflows. It manages configuration, training harnesses, inference engines, evaluation metrics, and callback systems. These components ensure a structured approach to building and deploying biomolecular design models. Refer to [Foundry Core Library and ML Workflows](#foundry-core-library-and-ml-workflows) for additional details.

Command-line interface (CLI) tools simplify management of the Foundry ecosystem. They allow users to install, list, and clean model checkpoints. This ensures consistent and reproducible model usage. Additional information is available in [Command Line Interface (CLI) Utilities](#command-line-interface-cli-utilities).
