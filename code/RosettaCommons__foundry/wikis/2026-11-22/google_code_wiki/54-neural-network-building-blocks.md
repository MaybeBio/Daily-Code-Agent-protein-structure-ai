## Neural Network Building Blocks
Foundry provides foundational neural network components within the [`/rosettacommons/foundry/src/foundry/model`](https://github.com/rosettacommons/foundry/src/foundry/model) directory that serve as building blocks for more complex models. These components include specialized layers for handling scalar inputs and implementing flexible dropout mechanisms.

One such component is the [`FourierEmbedding`](https://github.com/rosettacommons/foundry/src/foundry/model/layers/blocks.py#L7) class, located in [`/rosettacommons/foundry/src/foundry/model/layers/blocks.py`](https://github.com/rosettacommons/foundry/src/foundry/model/layers/blocks.py). This class is designed to encode scalar inputs into a higher-dimensional feature space using Fourier features. This transformation helps models capture periodic patterns and improve their ability to learn complex relationships from simple scalar inputs by providing a richer representation.

Another key building block is the [`Dropout`](https://github.com/rosettacommons/foundry/src/foundry/model/layers/blocks.py#L32) class, also found in [`/rosettacommons/foundry/src/foundry/model/layers/blocks.py`](https://github.com/rosettacommons/foundry/src/foundry/model/layers/blocks.py). This implementation of dropout offers a broadcastable mechanism, allowing the system to drop entire rows or columns of a tensor, rather than individual elements. This flexibility is particularly useful for applying dropout consistently across specific dimensions of a data representation, contributing to model regularization and preventing overfitting during training.
