# Third-Party Automation Tools

Bundled external packages that automate GROMACS simulations and trajectory analysis.

## Included Tools

### [CHAPERON*g*](https://github.com/pritampanda15/Molecular-Dynamics/blob/HEAD/tools/CHAPERONg)
An automated GROMACS MD simulation and trajectory analysis suite by Abeeb A. Yekeen et al. (*Comput. Struct. Biotechnol. J.* 2023, 21: 4849–4858).

- **Directory:** [`CHAPERONg/`](https://github.com/pritampanda15/Molecular-Dynamics/blob/HEAD/tools/CHAPERONg)
- **Documentation:** [`CHAPERONg/README.md`](https://github.com/pritampanda15/Molecular-Dynamics/blob/HEAD/tools/CHAPERONg/README.md)
- **Quick install:**
  ```bash
  cd tools/CHAPERONg
  chmod +x install_CHAPERONg.sh && ./install_CHAPERONg.sh
  ```
- **License:** See [`CHAPERONg/LICENSE`](https://github.com/pritampanda15/Molecular-Dynamics/blob/HEAD/tools/CHAPERONg/LICENSE).
