### Practical Example Scripts and Their Applications
The [`torch-sim`](https://github.com/torchsim/torch-sim/README.md#L3) repository includes a collection of example scripts that demonstrate various applications of the simulation engine, ranging from fundamental setup to advanced workflows. These examples serve as practical guides for users to understand and implement different atomistic simulation tasks.

The foundational principles are introduced in the script located at [`/torchsim/torch-sim/examples/scripts/1_introduction.py`](https://github.com/torchsim/torch-sim/examples/scripts/1_introduction.py). This script illustrates how to set up [`SimState`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L121) objects for single-system and batched simulations and perform basic energy and force calculations using both classical [`LennardJonesModel`](https://github.com/torchsim/torch-sim/torch_sim/models/lennard_jones.py#L74) and machine learning-based [`MaceModel`](https://github.com/torchsim/torch-sim/torch_sim/models/mace.py#L22) potentials. It highlights how [`system_idx`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L182) is used to manage batched inputs, enabling efficient parallel processing of multiple atomic configurations.

For structural optimization, the script at [`/torchsim/torch-sim/examples/scripts/2_structural_optimization.py`](https://github.com/torchsim/torch-sim/examples/scripts/2_structural_optimization.py) showcases various algorithms like FIRE, Gradient Descent, L-BFGS, and BFGS. It demonstrates optimizing atomic positions only, as well as joint optimization of positions and the simulation cell using different [`cell_filter`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py#L431) options such as [`CellFilter.unit`](https://github.com/torchsim/torch-sim/torch_sim/workflows/a2c.py#L729) and [`CellFilter.frechet`](https://github.com/torchsim/torch-sim/README.md#L86). This allows for various relaxation scenarios, including those involving pressure control.

Molecular dynamics simulations across different thermodynamic ensembles are covered in [`/torchsim/torch-sim/examples/scripts/3_dynamics.py`](https://github.com/torchsim/torch-sim/examples/scripts/3_dynamics.py). This includes NVE (microcanonical), NVT (canonical with Langevin and Nose-Hoover thermostats), and NPT (isothermal-isobaric with a Nose-Hoover barostat) ensembles. The script illustrates how to set up initial conditions, manage simulation steps, and log thermodynamic properties like temperature and pressure. Further details on these integrators can be found in [Simulation Integrators](#simulation-integrators).

The [`torch-sim`](https://github.com/torchsim/torch-sim/README.md#L3) high-level API, designed for streamlined simulation workflows, is demonstrated in [`/torchsim/torch-sim/examples/scripts/4_high_level_api.py`](https://github.com/torchsim/torch-sim/examples/scripts/4_high_level_api.py). This script shows how to use convenience functions such as [`ts.integrate`](https://github.com/torchsim/torch-sim/README.md#L55) for MD simulations and [`ts.optimize`](https://github.com/torchsim/torch-sim/README.md#L81) for geometry optimizations. It also explains how to configure [`TrajectoryReporter`](https://github.com/torchsim/torch-sim/torch_sim/trajectory.py#L68) for logging simulation data and define custom convergence criteria for optimization tasks. For a broader understanding of how these high-level functions orchestrate simulations, refer to [High-Level Simulation Runners](#atomistic-simulation-engine-core-high-level-simulation-runners).

Advanced simulation workflows are presented in [`/torchsim/torch-sim/examples/scripts/5_workflow.py`](https://github.com/torchsim/torch-sim/examples/scripts/5_workflow.py). This includes in-flight autobatching for optimizing large sets of structures by dynamically managing batches based on resource availability, which is discussed further in [Autobatching Mechanisms](#atomistic-simulation-engine-core-autobatching-mechanisms). Additionally, it demonstrates how to calculate elastic constants, including identifying the Bravais lattice type and computing elastic moduli, showcasing advanced physical property calculations as described in [Advanced Physical Property Calculations](#atomistic-simulation-engine-core-advanced-physical-property-calculations).

Phonon calculations are detailed in [`/torchsim/torch-sim/examples/scripts/6_phonons.py`](https://github.com/torchsim/torch-sim/examples/scripts/6_phonons.py). This script outlines a complete workflow from structural relaxation using a [`MaceModel`](https://github.com/torchsim/torch-sim/torch_sim/models/mace.py#L22) to computing phonon density of states (DOS) and band structures using [`Phonopy`](https://github.com/torchsim/torch-sim/README.md#L24). It highlights the use of batched force constant calculations and the utility functions [`ts.io.state_to_phonopy`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L688) and [`ts.io.phonopy_to_state`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L1514) for interoperability with external libraries.

Finally, [`/torchsim/torch-sim/examples/scripts/7_others.py`](https://github.com/torchsim/torch-sim/examples/scripts/7_others.py) explores additional advanced features. This includes batched neighbor list calculations using both linked-cell ([`torch_nl_linked_cell`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/torch_nl.py#L156)) and N² ([`torch_nl_n2`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/torch_nl.py#L94)) methods, as described in [Neighbor List Algorithms](#neighbor-list-algorithms). It also demonstrates how to compute the Velocity Autocorrelation Function (VACF) during an NVE molecular dynamics simulation, further illustrating the capabilities described in [Simulation Property Calculators](#simulation-property-calculators).
