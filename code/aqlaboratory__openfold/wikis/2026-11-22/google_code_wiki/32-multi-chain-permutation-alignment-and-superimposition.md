### Multi-chain Permutation Alignment and Superimposition
Multi-chain protein predictions present a unique challenge due to the arbitrary ordering of chains in both predicted and ground truth structures. To accurately evaluate or utilize multi-chain predictions, it is necessary to align the predicted chains to their corresponding ground truth chains, minimizing the Root Mean Square Deviation (RMSD). This process involves identifying the optimal permutation of predicted chains to match ground truth chains and then applying a rigid body transformation to superimpose them.

The system addresses this by first parsing and organizing ground truth features by individual chains, often referred to as asymmetric units. An "anchor" chain, typically the least asymmetric or longest chain, is selected to provide a robust starting point for alignment. The core of the alignment process relies on the Kabsch algorithm, implemented in functions such as [`kabsch_rotation`](https://github.com/aqlaboratory/openfold/openfold/utils/multi_chain_permutation.py#L35) within [`/aqlaboratory/openfold/openfold/utils/multi_chain_permutation.py`](https://github.com/aqlaboratory/openfold/openfold/utils/multi_chain_permutation.py), which calculates the optimal rotation and translation to superimpose two sets of 3D points.

Following the initial anchoring, a greedy alignment approach is employed. This method iteratively matches predicted chains to ground truth chains by finding the pairing that minimizes RMSD. This iterative process ensures that the best possible match is found across all chains, accounting for potential misordering in the model's output. The [`greedy_align`](https://github.com/aqlaboratory/openfold/openfold/utils/multi_chain_permutation.py#L167) function in [`/aqlaboratory/openfold/openfold/utils/multi_chain_permutation.py`](https://github.com/aqlaboratory/openfold/openfold/utils/multi_chain_permutation.py) implements this strategy. Once the optimal permutation is determined, ground truth features are reordered, and padding is applied to ensure consistent tensor dimensions for downstream calculations, such as loss computation.

The structural superimposition itself can be performed on both NumPy arrays and batched PyTorch tensors, as seen in the [`/aqlaboratory/openfold/openfold/utils/superimposition.py`](https://github.com/aqlaboratory/openfold/openfold/utils/superimposition.py) module. This module provides functions that perform RMSD-minimizing structural superimposition of atomic coordinates using Singular Value Decomposition (SVD). It is capable of handling masks, allowing specific atoms to be included or excluded from the superimposition calculation. For batched operations, the system efficiently processes each sample independently, extracting unmasked coordinates, superimposing them using the Kabsch algorithm (via [`_superimpose_single`](https://github.com/aqlaboratory/openfold/openfold/utils/superimposition.py#L37) calling into [`_superimpose_np`](https://github.com/aqlaboratory/openfold/openfold/utils/superimposition.py#L19)), and then reconstructing the full-sized superimposed coordinates. This approach ensures that the model can accurately evaluate predictions against native structures, even when dealing with complex multi-chain protein assemblies.
