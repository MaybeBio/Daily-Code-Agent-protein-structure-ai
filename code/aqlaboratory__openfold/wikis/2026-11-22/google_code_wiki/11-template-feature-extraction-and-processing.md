### Template Feature Extraction and Processing
The template feature extraction and processing pipeline within OpenFold is designed to leverage known protein structures to aid in predicting novel ones. This involves identifying homologous proteins with solved structures, extracting relevant structural and sequence information from them, and preparing these data as features for the model.

The process begins by running external bioinformatics tools to search for homologous protein templates. For instance, [`HHsearch`](https://github.com/aqlaboratory/openfold/docs/source/original_readme.md#L390) (wrapped by [`/aqlaboratory/openfold/openfold/data/tools/hhsearch.py`](https://github.com/aqlaboratory/openfold/openfold/data/tools/hhsearch.py)) is used to identify templates based on sequence profiles. [`Hmmsearch`](https://github.com/aqlaboratory/openfold/openfold/data/tools/hmmsearch.py#L27) (wrapped by [`/aqlaboratory/openfold/openfold/data/tools/hmmsearch.py`](https://github.com/aqlaboratory/openfold/openfold/data/tools/hmmsearch.py)) serves a similar role, particularly for multimer data. These tools output results in formats like HHR (HHsearch output) or A3M/Stockholm (HMMsearch output), which are then parsed by functions such as [`parse_hhr`](https://github.com/aqlaboratory/openfold/openfold/data/parsers.py#L519), [`parse_hmmsearch_a3m`](https://github.com/aqlaboratory/openfold/openfold/data/parsers.py#L603), and [`parse_hmmsearch_sto`](https://github.com/aqlaboratory/openfold/openfold/data/parsers.py#L649) in [`/aqlaboratory/openfold/openfold/data/parsers.py`](https://github.com/aqlaboratory/openfold/openfold/data/parsers.py). These parsing functions convert raw text outputs into structured [`TemplateHit`](https://github.com/aqlaboratory/openfold/openfold/data/parsers.py#L57) objects, capturing aligned sequences and match statistics.

Once template hits are identified, they undergo a featurization process managed by classes like [`HhsearchHitFeaturizer`](https://github.com/aqlaboratory/openfold/openfold/data/templates.py#L1105) and [`HmmsearchHitFeaturizer`](https://github.com/aqlaboratory/openfold/openfold/data/templates.py#L1225) in [`/aqlaboratory/openfold/openfold/data/templates.py`](https://github.com/aqlaboratory/openfold/openfold/data/templates.py). This step involves several key operations:
*   **Template Filtering**: Initial hits are often prefiltered to ensure quality and relevance, assessing properties such as hit scores and coverage.
*   **mmCIF Parsing**: For promising templates, their corresponding mmCIF (Macromolecular Crystallographic Information File) entries are parsed using functionality in [`/aqlaboratory/openfold/openfold/data/mmcif_parsing.py`](https://github.com/aqlaboratory/openfold/openfold/data/mmcif_parsing.py) to extract detailed atomic coordinates and sequence information.
*   **Sequence Realignment**: The template's sequence is realigned to the query sequence to establish a precise residue-to-residue correspondence. This often involves tools like [`Kalign`](https://github.com/aqlaboratory/openfold/openfold/data/tools/kalign.py#L36) (wrapped by [`/aqlaboratory/openfold/openfold/data/tools/kalign.py`](https://github.com/aqlaboratory/openfold/openfold/data/tools/kalign.py)) to perform multiple sequence alignments.
*   **Feature Extraction**: From the parsed and realigned template structures, features such as [`template_aatype`](https://github.com/aqlaboratory/openfold/openfold/config.py#L384) (amino acid types), [`template_all_atom_positions`](https://github.com/aqlaboratory/openfold/openfold/config.py#L386), and [`template_all_atom_mask`](https://github.com/aqlaboratory/openfold/openfold/config.py#L385) are extracted. These features provide the model with geometric and evolutionary context from known structures.
*   **Obsolete PDB ID Handling**: The system accounts for obsolete PDB IDs, ensuring that templates are derived from current and valid structural data.

The [`make_template_features`](https://github.com/aqlaboratory/openfold/openfold/data/data_pipeline.py#L46) function in [`/aqlaboratory/openfold/openfold/data/data_pipeline.py`](https://github.com/aqlaboratory/openfold/openfold/data/data_pipeline.py) orchestrates the conversion of template hits into a [`FeatureDict`](https://github.com/aqlaboratory/openfold/openfold/np/protein.py#L35). In multimer scenarios, the [`unify_template_features`](https://github.com/aqlaboratory/openfold/openfold/data/data_pipeline.py#L66) function in the same file is used to combine template features from multiple chains, ensuring consistent dimensions through padding. These processed template features are then integrated into the overall data pipeline, feeding into the model's template information integration module for further processing [Template Information Integration](#alphafold2-model-architecture-implementation-template-information-integration).
