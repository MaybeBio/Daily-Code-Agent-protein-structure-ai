### Automated Workflow Input Generation
The generation of workflow input files is facilitated by utilities that automate the creation of configuration necessary for molecular dynamics simulations. This process is crucial for streamlining the setup of new projects, especially when dealing with large datasets or complex experimental designs.

One approach involves the batch creation of [`inputs.yaml`](https://github.com/mmb-irb/mddb-workflow/test/conftest.py#L90) files, which are derived from PDB structures. The script located at [`/mmb-irb/mddb-workflow/manual_tools/inputs_generator_by_pdb.py`](https://github.com/mmb-irb/mddb-workflow/manual_tools/inputs_generator_by_pdb.py) reads a reference [`inputs.yaml`](https://github.com/mmb-irb/mddb-workflow/test/conftest.py#L90) file and then generates customized [`inputs.yaml`](https://github.com/mmb-irb/mddb-workflow/test/conftest.py#L90) files for multiple target directories. For each directory, the script extracts a PDB ID from the directory name, integrates this ID into the new configuration, and saves the customized [`inputs.yaml`](https://github.com/mmb-irb/mddb-workflow/test/conftest.py#L90) file within that directory. This method ensures that each simulation run is correctly linked to its corresponding PDB structure.

Another utility, found at [`/mmb-irb/mddb-workflow/manual_tools/inputs_generator.py`](https://github.com/mmb-irb/mddb-workflow/manual_tools/inputs_generator.py), focuses on generating [`inputs.json`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/utils/constants.py#L67) files that incorporate specific mutation and ligand details. While this script is noted as deprecated, it demonstrates a mechanism for populating workflow inputs with predefined ligand information and dynamically constructing descriptive names based on mutation and ligand parameters provided at the command line. This allows for the systematic configuration of simulations involving specific molecular modifications and interactions.

Both utilities serve to reduce manual effort and potential errors in preparing simulation input, contributing to the reproducibility and scalability of molecular dynamics projects.
