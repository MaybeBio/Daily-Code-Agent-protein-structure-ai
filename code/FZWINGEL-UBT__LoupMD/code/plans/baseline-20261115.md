# Baseline record (plan task S0-T01)

Measured on 15 November 2026, 01:18 to 01:31, on the local RTX 5060 Ti (`sm_120`, WSL2, driver 621.14, CUDA 13.3
`nvcc` V13.3.33). Everything here is measured unless it says otherwise.

## What was measured

- **Code:** the tree of `bac354c` on `release/v1`: `round6-hardening` `11778cd` merged, plus `PLAN.md` and `docs/`.
  Its sources equal `11778cd`'s. The plan named `0336751`; the merge came first, so the baseline is what Stage 1
  starts from (`PLAN.md` §1.3 D10).
- **Tree:** exported with `git archive bac354c` to `~/loupmd-release-baseline` (WSL), so later commits of the
  worktree could not change it.
- **Library:** `make -j4 CUDA_ARCH=sm_120`; sha256 `df58a9bd2623a502...` (`libloupmd.so`, 8,104,176 bytes).
- **GEMM plan cache:** `LOUP_CACHE_DIR=$HOME/.cache/loupmd-release`, empty before the first run, so every plan was
  tuned fresh. `~/.cache/loupmd/` supplied bundles and gate references only.
- **GPU state:** each job started after the card had shown no compute process for two minutes and ran under
  FastMACE's `tools/ci/local_gpu.py run --quiet`. A sampler read `nvidia-smi --query-compute-apps` every 10 s
  during each job: only the job's own processes appear.

enter. Stage 1 compares against this record, not against the status file.
