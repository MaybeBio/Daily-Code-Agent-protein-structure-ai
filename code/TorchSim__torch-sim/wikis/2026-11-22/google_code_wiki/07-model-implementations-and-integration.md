## Model Implementations and Integration
The [`torch-sim`](https://github.com/torchsim/torch-sim/README.md#L3) framework provides a comprehensive set of models for calculating energies, forces, and stresses in atomistic simulations. These models can be categorized into classical potentials, dispersion and electrostatic models, and wrappers for external machine learning interatomic potentials (MLIPs). All models adhere to a common interface, facilitating their integration and composition.

The core abstraction for all models is the [`ModelInterface`](https://github.com/torchsim/torch-sim/torch_sim/models/interface.py#L71), defined in [`/torchsim/torch-sim/torch_sim/models/interface.py`](https://github.com/torchsim/torch-sim/torch_sim/models/interface.py). This abstract class establishes a contract that concrete model implementations must fulfill, ensuring a consistent API for computing energy, forces, and optionally stress for a given simulation state. This uniformity allows for generic utilities, such as [`validate_model_outputs`](https://github.com/torchsim/torch-sim/torch_sim/models/interface.py#L387) in [`/torchsim/torch-sim/torch_sim/models/interface.py`](https://github.com/torchsim/torch-sim/torch_sim/models/interface.py), which rigorously tests model implementations against the defined interface and physical principles, including correct handling of periodic boundary conditions.

Models can be combined using [`SumModel`](https://github.com/torchsim/torch-sim/torch_sim/models/interface.py#L204) and [`SerialSumModel`](https://github.com/torchsim/torch-sim/torch_sim/models/interface.py#L325), both found in [`/torchsim/torch-sim/torch_sim/models/interface.py`](https://github.com/torchsim/torch-sim/torch_sim/models/interface.py). [`SumModel`](https://github.com/torchsim/torch-sim/torch_sim/models/interface.py#L204) additively combines the outputs of multiple models, suitable for independent contributions. [`SerialSumModel`](https://github.com/torchsim/torch-sim/torch_sim/models/interface.py#L325) extends this by allowing subsequent models in a sequence to consume features or modified states produced by earlier models, enabling more complex, interdependent potential energy surfaces.

Classical potentials, such as Lennard-Jones, Morse, and Soft Sphere, are implemented within [`torch-sim`](https://github.com/torchsim/torch-sim/README.md#L3). These models often build upon the [`PairPotentialModel`](https://github.com/torchsim/torch-sim/torch_sim/models/pair_potential.py#L277) framework defined in [`/torchsim/torch-sim/torch_sim/models/pair_potential.py`](https://github.com/torchsim/torch-sim/torch_sim/models/pair_potential.py). This framework provides a generic way to define pairwise energy functions, automatically deriving forces via automatic differentiation and calculating virial stresses. For instance, the [`LennardJonesModel`](https://github.com/torchsim/torch-sim/torch_sim/models/lennard_jones.py#L74) in [`/torchsim/torch-sim/torch_sim/models/lennard_jones.py`](https://github.com/torchsim/torch-sim/torch_sim/models/lennard_jones.py) implements the 12-6 potential, while [`MorseModel`](https://github.com/torchsim/torch-sim/torch_sim/models/morse.py#L78) in [`/torchsim/torch-sim/torch_sim/models/morse.py`](https://github.com/torchsim/torch-sim/torch_sim/models/morse.py) implements the Morse potential. The [`SoftSphereModel`](https://github.com/torchsim/torch-sim/torch_sim/models/soft_sphere.py#L175) and [`SoftSphereMultiModel`](https://github.com/torchsim/torch-sim/torch_sim/models/soft_sphere.py#L248) in [`/torchsim/torch-sim/torch_sim/models/soft_sphere.py`](https://github.com/torchsim/torch-sim/torch_sim/models/soft_sphere.py) handle repulsive soft-sphere interactions for single and multiple species, respectively. A specialized [`ParticleLifeModel`](https://github.com/torchsim/torch-sim/torch_sim/models/particle_life.py#L57) in [`/torchsim/torch-sim/torch_sim/models/particle_life.py`](https://github.com/torchsim/torch-sim/torch_sim/models/particle_life.py) demonstrates an asymmetric force model, inheriting from [`PairForcesModel`](https://github.com/torchsim/torch-sim/torch_sim/models/pair_potential.py#L467) when an explicit energy function is not present.

For long-range interactions, [`torch-sim`](https://github.com/torchsim/torch-sim/README.md#L3) includes dispersion and electrostatic models. The [`D3DispersionModel`](https://github.com/torchsim/torch-sim/torch_sim/models/dispersion.py#L56) in [`/torchsim/torch-sim/torch_sim/models/dispersion.py`](https://github.com/torchsim/torch-sim/torch_sim/models/dispersion.py) provides DFT-D3(BJ) dispersion corrections, leveraging [`nvalchemiops`](https://github.com/torchsim/torch-sim/torch_sim/autobatching.py#L42) for accelerated computations. Electrostatic interactions are handled by models such as [`DSFCoulombModel`](https://github.com/torchsim/torch-sim/torch_sim/models/electrostatics.py#L51), [`EwaldModel`](https://github.com/torchsim/torch-sim/torch_sim/models/electrostatics.py#L156), and [`PMEModel`](https://github.com/torchsim/torch-sim/torch_sim/models/electrostatics.py#L270), all implemented in [`/torchsim/torch-sim/torch_sim/models/electrostatics.py`](https://github.com/torchsim/torch-sim/torch_sim/models/electrostatics.py). These models also rely on [`nvalchemiops`](https://github.com/torchsim/torch-sim/torch_sim/autobatching.py#L42) for efficient GPU-accelerated calculations, supporting various levels of accuracy for periodic systems.

[`torch-sim`](https://github.com/torchsim/torch-sim/README.md#L3) also offers extensive integration with external machine learning interatomic potentials (MLIPs). This is achieved through dedicated wrappers that conform to the [`ModelInterface`](https://github.com/torchsim/torch-sim/torch_sim/models/interface.py#L71), allowing users to seamlessly incorporate state-of-the-art MLIPs into their simulations. Examples include wrappers for MACE ([`/torchsim/torch-sim/torch_sim/models/mace.py`](https://github.com/torchsim/torch-sim/torch_sim/models/mace.py)), NequIP/Allegro ([`/torchsim/torch-sim/torch_sim/models/nequip_framework.py`](https://github.com/torchsim/torch-sim/torch_sim/models/nequip_framework.py)), Allegro via FairChem ([`/torchsim/torch-sim/torch_sim/models/fairchem.py`](https://github.com/torchsim/torch-sim/torch_sim/models/fairchem.py)), Mattersim ([`/torchsim/torch-sim/torch_sim/models/mattersim.py`](https://github.com/torchsim/torch-sim/torch_sim/models/mattersim.py)), Metatomic ([`/torchsim/torch-sim/torch_sim/models/metatomic.py`](https://github.com/torchsim/torch-sim/torch_sim/models/metatomic.py)), Nequix ([`/torchsim/torch-sim/torch_sim/models/nequix.py`](https://github.com/torchsim/torch-sim/torch_sim/models/nequix.py)), ORB ([`/torchsim/torch-sim/torch_sim/models/orb.py`](https://github.com/torchsim/torch-sim/torch_sim/models/orb.py)), and SevenNet ([`/torchsim/torch-sim/torch_sim/models/sevennet.py`](https://github.com/torchsim/torch-sim/torch_sim/models/sevennet.py)). These wrappers typically include mechanisms for handling [`ImportError`](https://github.com/torchsim/torch-sim/torch_sim/io.py#L60) gracefully if the external library is not installed, providing a dummy model that raises a clear error upon instantiation.

Finally, the framework provides polarization correction capabilities. The [`UniformPolarizationModel`](https://github.com/torchsim/torch-sim/torch_sim/models/polarization.py#L10) in [`/torchsim/torch-sim/torch_sim/models/polarization.py`](https://github.com/torchsim/torch-sim/torch_sim/models/polarization.py) calculates additive energy, force, and total polarization corrections under a constant external electric field, utilizing properties stored within the simulation state.
