### Project Accession Processing and Directory Uploads
The [`/mmb-irb/mddb-workflow/manual_tools/logger_and_loader.py`](https://github.com/mmb-irb/mddb-workflow/manual_tools/logger_and_loader.py) script automates the retrieval of project metadata and the subsequent uploading of associated directories. It streamlines the process of managing project accessions by reading them from a [`pending.txt`](https://github.com/mmb-irb/mddb-workflow/manual_tools/logger_and_loader.py#L7) file. For each accession, it constructs a URL to query a database API, fetching critical project information. This metadata, particularly the project title, is then used to determine the local directory corresponding to the project. The script then orchestrates an external Node.js utility to handle the actual directory upload, passing both the generated directory name and the project accession. This external execution is crucial for abstracting the complexities of file transfer and ensuring proper resource management. The script integrates [`urllib.request.urlopen`](https://github.com/mmb-irb/mddb-workflow/manual_tools/api_tools.py#L18) for API interaction and [`subprocess.run`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/core/dataset.py#L311) to execute the external upload tool.
