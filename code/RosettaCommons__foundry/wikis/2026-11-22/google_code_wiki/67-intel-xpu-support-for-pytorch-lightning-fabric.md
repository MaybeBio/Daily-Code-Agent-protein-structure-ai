### Intel XPU Support for PyTorch Lightning Fabric
The [`foundry.utils.xpu`](https://github.com/rosettacommons/foundry/src/foundry/trainers/fabric.py#L38) module provides utilities for enabling and managing Intel XPU (GPU) devices within PyTorch Lightning Fabric applications. This support allows for XPU acceleration, single-device training strategies, and mixed precision operations on Intel GPUs.

The [`SingleXPUStrategy`](https://github.com/rosettacommons/foundry/src/foundry/utils/xpu/single_xpu_strategy.py#L13) class, defined in [`/rosettacommons/foundry/src/foundry/utils/xpu/single_xpu_strategy.py`](https://github.com/rosettacommons/foundry/src/foundry/utils/xpu/single_xpu_strategy.py), extends Lightning's [`SingleDeviceStrategy`](https://github.com/rosettacommons/foundry/src/foundry/utils/xpu/single_xpu_strategy.py#L9) to manage training and inference specifically on a single Intel XPU device. It ensures that Lightning Fabric components are configured and executed correctly on XPU, verifying device availability during initialization.

For managing interactions with Intel XPU devices, the [`XPUAccelerator`](https://github.com/rosettacommons/foundry/src/foundry/utils/xpu/xpu_accelerator.py#L9) class in [`/rosettacommons/foundry/src/foundry/utils/xpu/xpu_accelerator.py`](https://github.com/rosettacommons/foundry/src/foundry/utils/xpu/xpu_accelerator.py) inherits from [`Accelerator`](https://github.com/rosettacommons/foundry/src/foundry/trainers/fabric.py#L20). It handles device setup, parsing of device specifications, and reporting available XPU device counts, relying on [`torch.xpu`](https://github.com/rosettacommons/foundry/src/foundry/utils/ddp.py#L39) functionalities.

Mixed precision training on Intel XPU devices is facilitated by the [`XPUMixedPrecision`](https://github.com/rosettacommons/foundry/src/foundry/utils/xpu/xpu_precision.py#L11) class, located in [`/rosettacommons/foundry/src/foundry/utils/xpu/xpu_precision.py`](https://github.com/rosettacommons/foundry/src/foundry/utils/xpu/xpu_precision.py). This component enables automatic mixed precision (AMP) by using [`torch.autocast`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/trainer/rfd3.py#L92) during the model's forward pass, ensuring that computations are performed at the appropriate floating-point precision (e.g., [`torch.float16`](https://github.com/rosettacommons/foundry/src/foundry/utils/xpu/xpu_precision.py#L33) or [`torch.bfloat16`](https://github.com/rosettacommons/foundry/src/foundry/utils/xpu/xpu_precision.py#L35)).

These components are designed to allow [`Lightning Fabric`](https://github.com/rosettacommons/foundry/models/rfd3/README.md#L150) [`Trainer`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/train.py#L92) instances to leverage Intel XPU devices for scalable and efficient model development. For further details on the [`FabricTrainer`](https://github.com/rosettacommons/foundry/src/foundry/trainers/fabric.py#L56), see [Training Harness with PyTorch Lightning Fabric](#foundry-core-library-and-ml-workflows-training-harness-with-pytorch-lightning-fabric).
