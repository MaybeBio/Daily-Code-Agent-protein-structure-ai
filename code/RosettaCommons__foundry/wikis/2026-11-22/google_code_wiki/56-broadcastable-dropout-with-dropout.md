### Broadcastable Dropout with `Dropout`
The [`Dropout`](https://github.com/rosettacommons/foundry/src/foundry/model/layers/blocks.py#L32) class, defined in [`/rosettacommons/foundry/src/foundry/model/layers/blocks.py`](https://github.com/rosettacommons/foundry/src/foundry/model/layers/blocks.py), implements a flexible broadcastable dropout mechanism. This allows for dropout to be applied not just to individual elements, but to entire rows or columns of a tensor, depending on the [`broadcast_dim`](https://github.com/rosettacommons/foundry/src/foundry/model/layers/blocks.py#L34) parameter. The [`p_drop`](https://github.com/rosettacommons/foundry/src/foundry/model/layers/blocks.py#L34) parameter controls the probability of an element being dropped. During training, [`Dropout`](https://github.com/rosettacommons/foundry/src/foundry/model/layers/blocks.py#L32) uses a [`torch.distributions.bernoulli.Bernoulli`](https://github.com/rosettacommons/foundry/src/foundry/model/layers/blocks.py#L37) distribution to sample a binary mask, which is then applied to the input tensor. This masked input is scaled to maintain the expected sum. During evaluation, the [`Dropout`](https://github.com/rosettacommons/foundry/src/foundry/model/layers/blocks.py#L32) layer passes the input through without modification, ensuring consistent output for inference. This functionality is part of the broader collection of [Neural Network Building Blocks](#neural-network-building-blocks) available in Foundry.
