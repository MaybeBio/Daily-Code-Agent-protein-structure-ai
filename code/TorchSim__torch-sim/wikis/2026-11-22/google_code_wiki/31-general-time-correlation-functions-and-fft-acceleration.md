### General Time Correlation Functions and FFT Acceleration
The [`CorrelationCalculator`](https://github.com/torchsim/torch-sim/torch_sim/properties/correlations.py#L100) class in [`/torchsim/torch-sim/torch_sim/properties/correlations.py`](https://github.com/torchsim/torch-sim/torch_sim/properties/correlations.py) is designed to compute both auto- and cross-correlation functions for arbitrary simulation properties. It efficiently manages and processes time series data, leveraging FFT-based methods for accelerated computation on various devices supported by PyTorch.

At its core, the [`CorrelationCalculator`](https://github.com/torchsim/torch-sim/torch_sim/properties/correlations.py#L100) utilizes a [`CircularBuffer`](https://github.com/torchsim/torch-sim/torch_sim/properties/correlations.py#L31) for storing historical data of multiple simulation properties. This buffer, also defined within [`/torchsim/torch-sim/torch_sim/properties/correlations.py`](https://github.com/torchsim/torch-sim/torch_sim/properties/correlations.py), is a fixed-size, efficient data structure that prevents frequent memory reallocations, ensuring smooth data handling as new time steps are added. Properties are tracked using user-defined functions that extract relevant [`torch.Tensor`](https://github.com/torchsim/torch-sim/CHANGELOG.md#L90) data from a [`SimState`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L121) object at each simulation step.

The process involves updating the calculator with the current simulation state, which then extracts and appends property data to their respective circular buffers. Once sufficient data has accumulated within these buffers, the [`CorrelationCalculator`](https://github.com/torchsim/torch-sim/torch_sim/properties/correlations.py#L100) triggers an FFT-based calculation to determine the auto- and cross-correlation functions. This approach significantly speeds up the computation of correlations compared to direct summation methods, especially for long time series. PyTorch provides the underlying acceleration, allowing these calculations to be performed efficiently on both CPUs and GPUs. The results, including optional normalization, are then stored and can be retrieved for analysis. This general framework also forms the basis for specialized calculators like the [Specialized AutoCorrelation Functions (VACF and HFACF)](#simulation-property-calculators-specialized-autocorrelation-functions-vacf-and-hfacf).
