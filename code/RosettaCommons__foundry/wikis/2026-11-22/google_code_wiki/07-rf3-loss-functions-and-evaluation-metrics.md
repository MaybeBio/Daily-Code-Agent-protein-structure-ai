### RF3 Loss Functions and Evaluation Metrics
Within RF3, various loss functions and evaluation metrics guide model training and assess prediction quality, including [`ConfidenceLoss`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/loss/af3_confidence_loss.py#L18), [`DiffusionLoss`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/loss/af3_losses.py#L416), [`DistogramLoss`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/loss/af3_losses.py#L628), lDDT scores, and specialized metrics for chirality and clashing. These components are primarily defined within the [`/rosettacommons/foundry/models/rf3/src/rf3/loss`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/loss) and [`/rosettacommons/foundry/models/rf3/src/rf3/metrics`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/metrics) directories.

The [`DiffusionLoss`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/loss/af3_losses.py#L416) in [`/rosettacommons/foundry/models/rf3/src/rf3/loss/af3_losses.py`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/loss/af3_losses.py) is central to the denoising diffusion process. It calculates the mean squared error between predicted and ground-truth coordinates, incorporating atom-specific weighting and optionally applying a smoothed lDDT loss. This loss is crucial for models that learn to reverse a diffusion process to generate structures. For evaluating clashing within predicted protein structures, the [`CountClashingChains`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/metrics/clashing_chains.py#L10) metric defined in [`/rosettacommons/foundry/models/rf3/src/rf3/metrics/clashing_chains.py`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/metrics/clashing_chains.py) identifies if a significant number of atoms from different chains are too close.

The [`DistogramLoss`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/loss/af3_losses.py#L628) (found in [`/rosettacommons/foundry/models/rf3/src/rf3/loss/af3_losses.py`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/loss/af3_losses.py)) compares predicted inter-atomic distance distributions to ground-truth distributions using cross-entropy, guiding the model to learn correct spatial relationships between residues. Relatedly, various lDDT (Local Distance Difference Test) scores are employed for evaluating the accuracy of local atomic environments, with implementations such as [`AllAtomLDDT`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/metrics/lddt.py#L205) and [`InterfaceLDDTByType`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/metrics/lddt.py#L268) located in [`/rosettacommons/foundry/models/rf3/src/rf3/metrics/lddt.py`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/metrics/lddt.py).

For predicting structural confidence, the [`ConfidenceLoss`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/loss/af3_confidence_loss.py#L18) in [`/rosettacommons/foundry/models/rf3/src/rf3/loss/af3_confidence_loss.py`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/loss/af3_confidence_loss.py) combines several metrics: Predicted Local Distance Difference Test ([`plddt`](https://github.com/rosettacommons/foundry/examples/all.ipynb#L231)), Predicted Aligned Error ([`pae`](https://github.com/rosettacommons/foundry/examples/all.ipynb#L231)), Predicted Distance Error ([`pde`](https://github.com/rosettacommons/foundry/examples/all.ipynb#L300)), and expected resolved status ([`exp_resolved`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/model/RF3.py#L391)). This loss treats confidence prediction as a classification problem over binned values, using cross-entropy. It also includes an optional ranking loss ([`listnet_loss`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/loss/af3_confidence_loss.py#L511)) to prioritize the accuracy of confidence score ordering.

Chirality, a fundamental property in molecular structures, is evaluated by the [`ChiralLoss`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/metrics/chiral.py#L158) metric, detailed in [`/rosettacommons/foundry/models/rf3/src/rf3/metrics/chiral.py`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/metrics/chiral.py). This metric calculates the squared error of predicted dihedral angles against ideal angles for chiral centers and identifies the percentage of correctly predicted chiral centers. In addition, the system also incorporates analytical gradients for dihedral angle mean squared error loss with respect to atomic coordinates, primarily for chiral centers, as seen in [`calc_ddihedralmse_dxyz`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/loss/loss.py#L8) within [`/rosettacommons/foundry/models/rf3/src/rf3/loss/loss.py`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/loss/loss.py). This approach is particularly useful when precise control over geometric constraints is required, potentially offering efficiency benefits over automatic differentiation.

Specialized losses for handling molecular symmetry are also present. [`ResidueSymmetryResolution`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/loss/af3_losses.py#L10) and [`SubunitSymmetryResolution`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/loss/af3_losses.py#L56) in [`/rosettacommons/foundry/models/rf3/src/rf3/loss/af3_losses.py`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/loss/af3_losses.py) aim to align predicted and native structures by finding optimal permutations or rigid transformations of symmetric elements, minimizing alignment metrics. These symmetry-aware losses ensure that models accurately capture and reproduce symmetrical molecular arrangements. For details on the overall RF3 model architecture, refer to [RF3 Model Architecture and Confidence Estimation](#introduction-to-foundry-models-rf3-model-architecture-and-confidence-estimation).
