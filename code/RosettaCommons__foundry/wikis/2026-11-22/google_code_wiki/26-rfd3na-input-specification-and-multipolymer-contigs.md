### RFD3NA Input Specification and Multipolymer Contigs
RFdiffusion3NA (RFD3NA) employs a specialized input system to manage complex multipolymer designs, enabling users to define regions for design, impose structural constraints, and specify interactions. This system facilitates the generation of diverse biomolecular architectures involving proteins, DNA, and RNA.

A central element of RFD3NA's input system is the [`contig`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L134) specification, which allows for defining continuous regions of polymers to be designed or preserved. Unlike single-polymer systems, RFD3NA extends this to multipolymer types, such as [`10-10,20-20R,30-30D`](https://github.com/rosettacommons/foundry/models/rfd3na/README.md#L55), where [`P`](https://github.com/rosettacommons/foundry/pyproject.toml#L112) (or no suffix) denotes protein, [`R`](https://github.com/rosettacommons/foundry/README.md#L161) denotes RNA, and [`D`](https://github.com/rosettacommons/foundry/models/rf3/README.md#L392) denotes DNA. This syntax allows for precise control over the composition and length of different polymer chains within a single design problem. The system processes these specifications, along with [`length`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L141) constraints and [`unindex`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L135) tokens, to delineate designable and fixed regions. These specifications are validated and prepared by the [`DesignInputSpecification`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L115) class, found in [`/rosettacommons/foundry/models/rfd3na/src/rfd3na/inference/input_parsing.py`](https://github.com/rosettacommons/foundry/models/rfd3na/src/rfd3na/inference/input_parsing.py), which ensures internal consistency and handles the transformation of user input into a machine-readable format. For backwards compatibility, a [`LegacySpecification`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L80) in [`/rosettacommons/foundry/models/rfd3na/src/rfd3na/inference/legacy_input_parsing.py`](https://github.com/rosettacommons/foundry/models/rfd3na/src/rfd3na/inference/legacy_input_parsing.py) exists to process older input formats. The [`accumulate_components`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L1287) function, critical to both new and legacy parsing, constructs the initial molecular structure by combining motif regions from existing structures and newly generated diffused residues, managing chain breaks and polymer type assignments.

Beyond contig specification, RFD3NA offers a flexible [`InputSelection`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/parsing.py#L26) mini-language for specifying precise residue and atom selections. This capability allows users to designate specific atoms or residues for various conditioning tasks, such as fixing their coordinates ([`select_fixed_atoms`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L152)), controlling their sequence identity ([`select_unfixed_sequence`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L160)), or specifying their burial or exposure ([`select_buried`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L170), [`select_exposed`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L172)). More advanced conditioning includes defining hotspots ([`select_hotspots`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L176)) for interaction interfaces and specifying hydrogen bond donors or acceptors ([`select_hbond_donor`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L175), [`select_hbond_acceptor`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L174)). These selections are processed and applied as annotations to the [`AtomArray`](https://github.com/rosettacommons/foundry/examples/all.ipynb#L20) data structure, enabling the model to incorporate these constraints during the diffusion process. The [`/rosettacommons/foundry/models/rfd3na/src/rfd3na/inference/parsing.py`](https://github.com/rosettacommons/foundry/models/rfd3na/src/rfd3na/inference/parsing.py) module handles the parsing and validation of these [`InputSelection`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/parsing.py#L26) objects, converting various input forms into canonicalized data dictionaries and masks.

For nucleic acid designs, RFD3NA integrates advanced constraints. This includes specifying nucleic acid secondary structure through parameters like [`ss_dbn`](https://github.com/rosettacommons/foundry/models/rfd3na/docs/examples/atom23_design.md#L48), which supports dot-bracket notation, and defining paired or loop regions using [`paired_region_list`](https://github.com/rosettacommons/foundry/models/rfd3na/docs/examples/atom23_design.md#L91), [`loop_region_list`](https://github.com/rosettacommons/foundry/models/rfd3na/docs/examples/atom23_design.md#L92), and [`paired_position_list`](https://github.com/rosettacommons/foundry/models/rfd3na/docs/examples/atom23_design.md#L116). These features are crucial for guiding the design towards specific RNA or DNA folds and interactions. Ligand interactions can also be specified using the [`ligand`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L142) parameter, enabling the design of protein or nucleic acid binders to small molecules. Additionally, global conditioning flags like [`plddt_enhanced`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L190), [`is_non_loopy`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L191), and [`partial_t`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L193) allow for further control over the design process, such as enabling confidence-based design or partial diffusion from an existing structure.

The overall input management system, as implemented in the [`/rosettacommons/foundry/models/rfd3na/src/rfd3na/inference`](https://github.com/rosettacommons/foundry/models/rfd3na/src/rfd3na/inference) directory, provides the necessary tools for users to define complex multipolymer design problems. It transforms these high-level specifications into a structured representation that the diffusion model can interpret and act upon, forming the basis for diverse biomolecular engineering tasks.
