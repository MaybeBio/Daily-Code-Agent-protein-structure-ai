### Cell Optimization and Filter-Based Design
Cell optimization within [`torch-sim`](https://github.com/torchsim/torch-sim/README.md#L3) utilizes a filter-based design to manage constraints and parameterizations when optimizing unit cell parameters alongside atomic positions during geometry relaxations. This approach is primarily defined and managed within the [`/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py) module.

The system offers two primary [`CellFilter`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py#L287) types: [`unit`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py#L290) and [`frechet`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py#L291). These define how the cell's deformation gradient is represented and updated. The [`unit`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py#L290) filter directly updates the cell based on a deformation gradient where [`cell_positions`](https://github.com/torchsim/torch-sim/torch_sim/integrators/npt.py#L108) are a scaled representation. In contrast, the [`frechet`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py#L291) filter operates in log-space, where [`cell_positions`](https://github.com/torchsim/torch-sim/torch_sim/integrators/npt.py#L108) represent the logarithm of the deformation gradient, using functions like [`torch.matrix_exp`](https://github.com/torchsim/torch-sim/torch_sim/math.py#L103) and [`tsm.matrix_log_33`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/fire.py#L463) for conversions.

For each [`CellFilter`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py#L287) type, there are distinct initialization functions, such as [`unit_cell_filter_init`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py#L181) and [`frechet_cell_filter_init`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py#L230), which set up the initial state for cell optimization. These functions establish properties like the [`reference_cell`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L866) and derive initial [`cell_positions`](https://github.com/torchsim/torch-sim/torch_sim/integrators/npt.py#L108). Corresponding step functions, [`unit_cell_step`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py#L295) and [`frechet_cell_step`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py#L324), then define how the cell parameters are updated in each optimization iteration. These steps involve calculating cell forces from stress and virial tensors via [`compute_cell_forces`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py#L353) and subsequently adjusting the cell's configuration based on these forces and a learning rate.

The [`cell_filter`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py#L431) mechanism allows for flexible handling of cell optimization within various algorithms, including [Geometry Optimization Algorithms](#geometry-optimization-algorithms). When a cell filter is active, optimizer states, like [`OptimState`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/state.py#L12), are extended to [`CellOptimState`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py#L427) (and its specialized derivatives like [`CellFireState`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py#L458) or [`CellBFGSState`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py#L471)), which incorporate cell-specific attributes such as [`reference_cell`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L866), [`cell_filter`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py#L431), [`cell_positions`](https://github.com/torchsim/torch-sim/torch_sim/integrators/npt.py#L108), and [`cell_forces`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py#L438). This enables the management of cell constraints, like [`hydrostatic_strain`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py#L434) or [`constant_volume`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py#L435), ensuring that optimization steps adhere to physical or user-defined conditions. A crucial aspect of numerical stability is addressed by functions like [`_clamp_deform_grad_log`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py#L26), which prevent numerical overflow when large cell deformations occur, particularly relevant for the [`frechet`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py#L291) method.
