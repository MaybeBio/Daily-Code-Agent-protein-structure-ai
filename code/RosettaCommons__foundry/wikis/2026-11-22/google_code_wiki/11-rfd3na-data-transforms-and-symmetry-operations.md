### RFD3NA Data Transforms and Symmetry Operations
The RFD3NA framework leverages a comprehensive suite of data transformations to prepare molecular structures for multipolymer design, ensuring accurate representation and conditioning. These transformations are critical for tasks ranging from conditioning the diffusion process to generating specialized features and applying symmetry constraints.

A core aspect of this framework is the definition and application of various **conditioning strategies**. These strategies, implemented as [`Transform`](https://github.com/rosettacommons/foundry/models/rf3/README.md#L453) classes, guide the model by specifying fixed regions, motifs, or designable areas within a molecular structure. Files such as [`/rosettacommons/foundry/models/rfd3na/src/rfd3na/transforms/conditioning_base.py`](https://github.com/rosettacommons/foundry/models/rfd3na/src/rfd3na/transforms/conditioning_base.py) and [`/rosettacommons/foundry/models/rfd3na/src/rfd3na/transforms/training_conditions.py`](https://github.com/rosettacommons/foundry/models/rfd3na/src/rfd3na/transforms/training_conditions.py) manage the global conditioning syntax. This includes [`IslandCondition`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/training_conditions.py#L56) for selecting token "islands" as motifs, [`PPICondition`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/training_conditions.py#L176) for defining protein-protein interaction interfaces, and [`SubtypeCondition`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/training_conditions.py#L272) for targeting specific molecular subtypes like protein, DNA, or RNA. These conditions dictate how annotations such as [`is_motif_atom_with_fixed_seq`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/constants.py#L9) (fixed sequence), [`is_motif_atom_with_fixed_coord`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/constants.py#L10) (fixed coordinates), and [`is_motif_atom_unindexed`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/constants.py#L11) (tokens whose positions are diffused) are applied to the [`AtomArray`](https://github.com/rosettacommons/foundry/examples/all.ipynb#L20). The [`UnindexFlaggedTokens`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/conditioning_base.py#L315) transform is particularly significant as it handles the expansion of unindexed motifs and generates [`unindexing_pair_mask`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/model/layers/blocks.py#L341) for relative positional encoding, ensuring proper information flow within the model.

**Feature generation** is another critical component, detailed within [`/rosettacommons/foundry/models/rfd3na/src/rfd3na/transforms/design_transforms.py`](https://github.com/rosettacommons/foundry/models/rfd3na/src/rfd3na/transforms/design_transforms.py). These transforms create diverse molecular features essential for the model's predictive capabilities. Examples include [`CreateDesignReferenceFeatures`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/design_transforms.py#L117) for generating reference positions and motif token classes, [`FeaturizeAtoms`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/design_transforms.py#L346) for adding atom-wise properties like RASA and hydrogen bond donor/acceptor states, and [`AddIsXFeats`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/design_transforms.py#L399) for boolean masks indicating atom types (e.g., backbone, alpha carbon). Noise augmentation, such as [`AugmentNoise`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/design_transforms.py#L611), is also applied here to enhance the robustness of diffusion models during training.

The framework incorporates specialized transformations for **hydrogen bond calculations**. [`/rosettacommons/foundry/models/rfd3na/src/rfd3na/transforms/hbonds.py`](https://github.com/rosettacommons/foundry/models/rfd3na/src/rfd3na/transforms/hbonds.py) handles the addition of hydrogen atoms and the calculation of hydrogen bonds using [`biotite`](https://github.com/rosettacommons/foundry/.env#L19), while [`/rosettacommons/foundry/models/rfd3na/src/rfd3na/transforms/hbonds_hbplus.py`](https://github.com/rosettacommons/foundry/models/rfd3na/src/rfd3na/transforms/hbonds_hbplus.py) integrates with the external [`HBPLUS`](https://github.com/rosettacommons/foundry/models/rfd3/README.md#L143) tool for more sophisticated H-bond analysis. These transforms annotate structures with [`active_donor`](https://github.com/rosettacommons/foundry/models/rfd3/docs/input.md#L85) and [`active_acceptor`](https://github.com/rosettacommons/foundry/models/rfd3/docs/input.md#L85) features, which are vital for designing hydrogen bond-mediated interactions.

A key capability for multipolymer design is the handling of **nucleic acid secondary structure**. The [`/rosettacommons/foundry/models/rfd3na/src/rfd3na/transforms/na_geom.py`](https://github.com/rosettacommons/foundry/models/rfd3na/src/rfd3na/transforms/na_geom.py) and [`/rosettacommons/foundry/models/rfd3na/src/rfd3na/transforms/na_geom_utils.py`](https://github.com/rosettacommons/foundry/models/rfd3na/src/rfd3na/transforms/na_geom_utils.py) modules compute nucleic acid secondary structure features, including base-pair partners and counts, either from geometric analysis or user-provided specifications like dot-bracket strings. This allows the model to explicitly condition on or generate desired nucleic acid conformations.

**Symmetry operations** are crucial for designing symmetric biomolecular assemblies, and are primarily managed by [`/rosettacommons/foundry/models/rfd3na/src/rfd3na/transforms/symmetry.py`](https://github.com/rosettacommons/foundry/models/rfd3na/src/rfd3na/transforms/symmetry.py). The [`AddSymmetryFeats`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/symmetry.py#L10) transform extracts and integrates symmetry-related transformations ([`sym_transform`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/symmetry.py#L33)) and annotations ([`sym_transform_id`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/symmetry.py#L22), [`sym_entity_id`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/symmetry.py#L23), [`is_sym_asu`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/symmetry.py#L24)) into the data. These features help ensure that generated structures adhere to specified symmetries, maintaining structural integrity across repeated units. Further details on symmetry handling in RFD3NA, including utility functions like [`add_sym_annotations`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/symmetry/atom_array.py#L15) and [`apply_symmetry_to_atomarray_coord`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/symmetry/atom_array.py#L152), can be found in [RFD3NA Multipolymer Contig Specification and Input Selection](#introduction-to-foundry-models-rfd3na-multipolymer-contig-specification-and-input-selection) and [RFD3NA Input Specification and Multipolymer Contigs](#rfdiffusion3na-rfd3na-for-multipolymer-design-rfd3na-input-specification-and-multipolymer-contigs). The tests in [`/rosettacommons/foundry/models/rfd3na/tests`](https://github.com/rosettacommons/foundry/models/rfd3na/tests) validate these symmetry operations, confirming that atoms are correctly assigned to symmetry mates and that the structural relationships are preserved.

The orchestration of these diverse transformations into coherent pipelines is handled by [`/rosettacommons/foundry/models/rfd3na/src/rfd3na/transforms/pipelines.py`](https://github.com/rosettacommons/foundry/models/rfd3na/src/rfd3na/transforms/pipelines.py). This module uses constructs like [`Compose`](https://github.com/rosettacommons/foundry/src/foundry/utils/rigid.py#L626) to sequence transforms, [`ConditionalRoute`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/data/pipelines.py#L42) for executing transforms based on specific conditions (e.g., training vs. inference), and [`RandomRoute`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/data/pipelines.py#L45) for stochastic elements like cropping. This modular design enables flexible and powerful data preparation workflows tailored to various multipolymer design challenges.
