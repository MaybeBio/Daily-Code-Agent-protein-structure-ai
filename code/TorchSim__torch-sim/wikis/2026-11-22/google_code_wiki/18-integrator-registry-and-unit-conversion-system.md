### Integrator Registry and Unit Conversion System
The [`INTEGRATOR_REGISTRY`](https://github.com/torchsim/torch-sim/torch_sim/integrators/__init__.py#L193) system facilitates the dynamic selection and initialization of molecular dynamics integrators. This registry, defined in [`/torchsim/torch-sim/torch_sim/integrators/__init__.py`](https://github.com/torchsim/torch-sim/torch_sim/integrators/__init__.py), maps an [`Integrator`](https://github.com/torchsim/torch-sim/torch_sim/integrators/__init__.py#L125) enumeration value to a pair of functions: an initialization function ([`init_fn`](https://github.com/torchsim/torch-sim/torch_sim/integrators/md.py#L376)) and a stepping function ([`step_fn`](https://github.com/torchsim/torch-sim/torch_sim/workflows/a2c.py#L731)). This structure allows the system to abstract away the specific details of different integration schemes, enabling a unified interface for various NVE, NVT, and NPT simulations.

A robust unit conversion system is integrated to handle physical units consistently across all integrator parameters. This is managed by the [`IntegratorKwargUnits`](https://github.com/torchsim/torch-sim/torch_sim/integrators/__init__.py#L221) dataclass and the [`_collect_unit_kwargs`](https://github.com/torchsim/torch-sim/torch_sim/integrators/__init__.py#L231) utility function. The [`_collect_unit_kwargs`](https://github.com/torchsim/torch-sim/torch_sim/integrators/__init__.py#L231) function inspects the type hints of an integrator's [`init_fn`](https://github.com/torchsim/torch-sim/torch_sim/integrators/md.py#L376) and [`step_fn`](https://github.com/torchsim/torch-sim/torch_sim/workflows/a2c.py#L731) to identify parameters that carry physical units (e.g., time, pressure, inverse time). It then collects their corresponding unit conversion factors, which are stored in [`INTEGRATOR_KWARG_UNITS`](https://github.com/torchsim/torch-sim/torch_sim/integrators/__init__.py#L251). This pre-calculated dictionary ensures that all integrator parameters are automatically converted to internal units, simplifying user input and preventing errors related to unit inconsistencies.
