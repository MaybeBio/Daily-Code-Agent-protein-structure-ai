# Contributing

You can contribute to PGEL in many ways and every submission will be greatly appreciated. 

## Reporting issues or problems

Please use [GitHub issues](https://github.com/AstraZeneca/PGEL/issues) to report bugs. To do so, please include:

* The name and version of your operating system.
* Detailed steps to reproduce the bug.

## Implementing new features 

Please use [pull requests](https://github.com/AstraZeneca/PGEL/pulls) if you want to modify the master branch. 

* Pull requests should include automated tests.
* The added functions should include their corresponding docstrings.

## Reaching out to code developers

The list of authors and their email addresses are available [here](https://github.com/AstraZeneca/PGEL/blob/main/AUTHORS.md).
