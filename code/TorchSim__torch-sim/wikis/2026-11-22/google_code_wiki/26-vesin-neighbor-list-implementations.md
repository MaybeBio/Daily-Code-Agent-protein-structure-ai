### Vesin Neighbor List Implementations
The [`torch-sim`](https://github.com/torchsim/torch-sim/README.md#L3) library provides integrations with the external [`vesin`](https://github.com/torchsim/torch-sim/pyproject.toml#L50) library for efficient neighbor list calculations, offering both standard Python and TorchScript-optimized versions. These implementations contribute to the automatic fallback mechanism for neighbor list generation, prioritizing performance-optimized external libraries. The primary functions are [`vesin_nl_ts`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/vesin.py#L184) and [`vesin_nl`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/vesin.py#L36), both located in [`/torchsim/torch-sim/torch_sim/neighbors/vesin.py`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/vesin.py).

The [`vesin_nl_ts`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/vesin.py#L184) function leverages [`VesinNeighborListTorch`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/vesin.py#L28) for TorchScript-compatible environments, enabling potential performance benefits through JIT compilation. The [`vesin_nl`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/vesin.py#L36) function uses the standard [`VesinNeighborList`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/vesin.py#L18) for environments where TorchScript optimization is not applicable or desired. Both functions require inputs such as atomic positions, cell vectors, periodic boundary conditions (PBC), a cutoff distance, and system indices for batched operations. They handle internal data type and device conversions, ensuring that [`torch.Tensor`](https://github.com/torchsim/torch-sim/CHANGELOG.md#L90) inputs are appropriately processed (e.g., converted to CPU and [`float64`](https://github.com/torchsim/torch-sim/torch_sim/io.py#L273) precision) as required by the [`vesin`](https://github.com/torchsim/torch-sim/pyproject.toml#L50) library, and results are then converted back to the original device and data type.

These [`vesin`](https://github.com/torchsim/torch-sim/pyproject.toml#L50) implementations are an integral part of the automatic neighbor list selection process within [`torch-sim`](https://github.com/torchsim/torch-sim/README.md#L3). When a neighbor list is requested, the system first checks for the availability of [`nvalchemiops`](https://github.com/torchsim/torch-sim/torch_sim/autobatching.py#L42). If not found, it then attempts to use [`vesin_nl_ts`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/vesin.py#L184) if [`VESIN_TORCHSCRIPT_AVAILABLE`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/vesin.py#L31) is true. If that is also unavailable, it falls back to [`vesin_nl`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/vesin.py#L36) if [`VESIN_AVAILABLE`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/vesin.py#L30) is true. This prioritization ensures that the most performant available option is chosen, contributing to the overall efficiency and robustness of simulations. For further details on this selection process, refer to [Automatic Fallback and Prioritization](#neighbor-list-algorithms-automatic-fallback-and-prioritization).
