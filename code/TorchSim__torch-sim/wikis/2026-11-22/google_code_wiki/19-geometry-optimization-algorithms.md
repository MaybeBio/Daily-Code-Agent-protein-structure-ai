## Geometry Optimization Algorithms
Optimization algorithms within this repository are designed for batched geometry relaxations of atomic structures. These algorithms update atomic positions and, optionally, cell parameters to minimize the system's energy. A key feature is the filter-based design, which handles various constraints and parameterizations for cell optimization.

The system supports several optimizers, including Gradient Descent, FIRE (Fast Inertial Relaxation Engine), BFGS, and L-BFGS. Each optimizer has dedicated initialization and stepping functions for managing its state and performing iterative updates on batched systems. For instance, [`bfgs_init`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/bfgs.py#L87) in [`/torchsim/torch-sim/torch_sim/optimizers/bfgs.py`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/bfgs.py) sets up the initial optimization state, including the Hessian matrix, while [`bfgs_step`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/bfgs.py#L216) performs iterative updates. Similarly, [`fire_init`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/fire.py#L22) and [`fire_step`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/fire.py#L117) in [`/torchsim/torch-sim/torch_sim/optimizers/fire.py`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/fire.py) manage the FIRE algorithm's adaptive timestep and momentum-like updates. The core logic for each optimizer is registered in the [`OPTIM_REGISTRY`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/__init__.py#L47) in [`/torchsim/torch-sim/torch_sim/optimizers/__init__.py`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/__init__.py), allowing for dynamic selection and execution.

Cell optimization is managed through a filter-based design, as detailed in [`/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py). This module defines [`CellFilter`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py#L287) types, such as [`unit`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py#L290) and [`frechet`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py#L291), which specify how cell parameters are initialized and updated. These filters calculate cell forces from stress and virial tensors and update cell positions accordingly. For example, [`unit_cell_filter_init`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py#L181) initializes the state for the "unit" cell filter, deriving initial [`cell_positions`](https://github.com/torchsim/torch-sim/torch_sim/integrators/npt.py#L108) from the deformation gradient. The [`CELL_FILTER_REGISTRY`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py#L404) in [`/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py) provides a mechanism to register and retrieve these different cell filtering methods. This approach enables flexible handling of cell constraints, such as hydrostatic strain or constant volume, and different parameterizations.

The state management for all optimizers, including those handling cell parameters, is unified through a hierarchy of dataclasses in [`/torchsim/torch-sim/torch_sim/optimizers/state.py`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/state.py). The base [`OptimState`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/state.py#L12) extends [`SimState`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L121) to include general optimization-related attributes like forces, energy, and stress. Specialized states such as [`FireState`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/state.py#L39), [`BFGSState`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/state.py#L55), and [`LBFGSState`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/state.py#L102) inherit from [`OptimState`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/state.py#L12) and add algorithm-specific parameters and history tracking. For instance, [`BFGSState`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/state.py#L55) includes the approximate Hessian matrix, while [`LBFGSState`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/state.py#L102) maintains histories of displacement and gradient differences for its two-loop recursion. When cell optimization is active, these states are further extended (e.g., [`CellOptimState`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py#L427), [`CellFireState`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py#L458)) to manage cell-specific attributes like [`reference_cell`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L866), [`cell_filter`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py#L431), and [`cell_forces`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/cell_filters.py#L438), ensuring consistent context and parameter management throughout the optimization process. For a detailed discussion of state management, see [Optimization State Management and Batched Operations](#geometry-optimization-algorithms-optimization-state-management-and-batched-operations).
