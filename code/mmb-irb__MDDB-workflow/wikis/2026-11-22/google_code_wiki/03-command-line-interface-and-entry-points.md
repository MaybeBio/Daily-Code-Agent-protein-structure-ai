### Command-Line Interface and Entry Points
The MDDB workflow provides command-line interfaces (CLIs) as primary entry points for users to interact with and orchestrate molecular dynamics (MD) simulation projects. These CLIs are defined in [`/mmb-irb/mddb-workflow/mddb_workflow/__main__.py`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/__main__.py) and [`/mmb-irb/mddb-workflow/mddb_workflow/console.py`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/console.py), allowing the package to be executed directly from the terminal.

The main CLI functionality is implemented within [`/mmb-irb/mddb-workflow/mddb_workflow/console.py`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/console.py), which leverages Python's [`argparse`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/console.py#L4) module to define a suite of subcommands. This subcommand-based structure organizes the workflow's diverse capabilities, making them accessible and manageable. A custom argument parser ([`CustomArgumentParser`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/console.py#L106)) and formatter ([`CustomHelpFormatter`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/console.py#L31)) enhance the user experience by providing improved help messages and specific error handling for subcommands. Help text for many arguments is dynamically generated from function docstrings, ensuring consistency between internal documentation and CLI usage.

The available subcommands facilitate various stages of the MD simulation data lifecycle:

*   **[`run`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/tools/nassa_base.py#L109)**: This is the core command for executing the main MDDB workflow. It accepts numerous arguments to specify input files (topology, structure, trajectory), project configuration (directory, accession), and workflow control parameters (download behavior, setup, error handling, selection criteria, and task management).
*   **[`inputs`](https://github.com/mmb-irb/mddb-workflow/manual_tools/inputs_generator.py#L12)**: Assists users in setting up and managing workflow input files, typically [`inputs.yaml`](https://github.com/mmb-irb/mddb-workflow/test/conftest.py#L90). It can copy template files and optionally open them with a specified editor.
*   **[`convert`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/tools/conversions.py#L34)**: Enables the conversion of molecular structures and trajectories between different file formats. It also supports merging multiple input trajectories into a single output.
*   **[`filter`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/utils/structures.py#L2296)**: Allows users to apply atomic filtering to structures and/or trajectories based on a defined selection string and syntax. This is useful for removing unwanted elements or focusing on specific parts of a system.
*   **[`subset`](https://github.com/mmb-irb/mddb-workflow/DEVELOPMENT.md#L57)**: Extracts a subset of frames from a trajectory, providing options to specify start, end, and step values, or individual frames, which is useful for reducing trajectory size or isolating specific time points.
*   **[`chainer`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/utils/structures.py#L2373)**: Modifies chain identifiers within PDB structures, often used for re-labeling or consolidating chains based on atom selections.
*   **[`nassa`](https://github.com/mmb-irb/mddb-workflow/test/conftest.py#L67)**: Manages and executes Nucleic Acid Structural Statistical Analysis (NASSA) pipelines. Users can generate configuration files, select specific analyses to run, and define input parameters for nucleic acid-specific computations, such as helical parameters.
*   **[`dataset`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/core/dataset.py#L154)** (aliased as [`ds`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/console.py#L349)): Provides comprehensive management for MDDB project datasets. This includes subcommands to add or remove projects, display their status, show a summary or live view of the dataset, generate [`inputs.yaml`](https://github.com/mmb-irb/mddb-workflow/test/conftest.py#L90) files for projects, launch workflow execution for selected projects, and scan directories for new projects. This subcommand leverages the [Project and MD Dataset Persistence and Status Tracking](#project-and-md-dataset-management-project-and-md-dataset-persistence-and-status-tracking) for its operations.
*   **[`upref`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/console.py#L548)**: Used for updating reference data across specified nodes and for various reference types, streamlining the maintenance of external data dependencies.

These command-line tools provide a structured and efficient way to interact with the MDDB workflow, enabling users to manage projects, run analyses, and process data without direct interaction with the underlying Python code.
