### Conformational Sampling and Dynamics Analyses
Methods for characterizing conformational dynamics include clustering, Principal Component Analysis (PCA) on both structures and contacts, and the generation of data for Markov State Models.

Clustering analysis, as implemented in [`/mmb-irb/mddb-workflow/mddb_workflow/analyses/clusters.py`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/analyses/clusters.py), identifies and characterizes conformational clusters and transitions within molecular dynamics trajectories. This analysis can summarize the overall structural states and specific interaction interfaces by generating representative snapshots and detailed cluster data. The process involves defining atom selections, potentially reducing the trajectory size for efficiency, and calculating RMSD matrices. An iterative clustering algorithm then groups frames based on RMSD cutoffs, dynamically adjusting parameters to achieve a desired number of clusters. This analysis also identifies transitions between clusters and selects the "most representative frame" for each cluster for visualization.

Two distinct approaches are available for generating Markov State Model (MSM) data. The module [`/mmb-irb/mddb-workflow/mddb_workflow/analyses/markov.py`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/analyses/markov.py) focuses on identifying the most populated frames within a trajectory, calculating the RMSD matrix between these frames, and generating corresponding visual representations. It efficiently extracts coordinates for high-population frames and computes RMSD values using selected atoms. Another module, [`/mmb-irb/mddb-workflow/mddb_workflow/analyses/markov_2.py`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/analyses/markov_2.py), also identifies highly populated frames but constructs a transition probability matrix specifically among these selected frames. It takes pre-calculated population and transition data as input, filtering to a subset of key frames and their associated transition probabilities, along with generating screenshots of these frames. Both approaches prioritize memory efficiency by iteratively loading trajectory frames.

Principal Component Analysis (PCA) is applied to molecular dynamics trajectories through [`/mmb-irb/mddb-workflow/mddb_workflow/analyses/pca.py`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/analyses/pca.py). This analysis generates PCA projections, eigenvalues, and projection data to describe the dominant modes of motion. The process involves parsing atom selections for fitting and analysis, potentially reducing the trajectory, and superimposing frames to remove translational and rotational motion. After applying PCA, the analysis extracts eigenvalues and eigenvectors, generating "projection" trajectories along significant principal components. Another PCA variant, found in [`/mmb-irb/mddb-workflow/mddb_workflow/analyses/pca_contacts.py`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/analyses/pca_contacts.py), focuses on inter-residue contacts. This tool computes distances between specified residue pairs, filters for frequently contacting pairs, and then applies PCA to smoothed contact distances. This identifies the principal components of contact variation, providing insight into how interaction networks evolve. The contact analysis can utilize either Pytraj or MDTraj libraries for trajectory processing and incorporates a sigmoid function to smooth distances before PCA, transforming them into a measure of contact strength.
