## Protein and Ligand Inverse Folding (MPNN)
The Message Passing Neural Network (MPNN) models, including ProteinMPNN, LigandMPNN, and SolubleMPNN, provide functionalities for protein and ligand sequence design given a fixed backbone structure. These models are re-implemented within the Foundry framework, leveraging [`atomworks`](https://github.com/rosettacommons/foundry/.env#L12) and [`foundry`](https://github.com/rosettacommons/foundry/pyproject.toml#L95) for backend support, aiming for stability and performance. The architecture for these models typically involves graph featurization, message passing layers, and specific decoding strategies for sequence generation.

The data preparation pipelines handle the conversion of raw structural data into features suitable for model input. This involves cleaning and filtering structural components, atomization, indexing, and generating residue- and atom-level features. The pipelines also integrate user-defined settings, such as structural noise or causality patterns, and compute polymer-ligand interface masks when applicable.

Training infrastructure for MPNN models utilizes a token-budgeted batching system and efficient collators to manage variable-length examples. The training process uses a [`LabelSmoothedNLLLoss`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/loss/nll_loss.py#L7) for optimizing model parameters and [`NoamOpt`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/train.py#L49)-style learning rate schedulers. The [`MPNNTrainer`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/trainers/mpnn.py#L21) orchestrates the training and validation loops, including model construction and metric computation.

For inference, the [`MPNNInferenceEngine`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/inference_engines/mpnn.py#L38) manages model loading, processing input structures through the data transformation pipeline, and decoding sequences. This engine supports loading legacy model weights from original implementations. Evaluation metrics such as negative log-likelihood (NLL), perplexity, confidence scores, and sequence recovery are computed to assess design quality, both generally and for specific interface residues. Output structures and FASTA files are generated as part of the inference process.
