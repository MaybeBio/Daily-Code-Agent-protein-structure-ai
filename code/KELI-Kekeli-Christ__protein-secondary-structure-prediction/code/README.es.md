Predicción hélice / lámina / ovillo. Hay dos enfoques en los notebooks: un MLP con ventana deslizante y un LSTM bidireccional. El README indica cerca del 69 % de accuracy de validación para el MLP. Abre `protein_structure_mlp.ipynb` o `protein_structure_lstm.ipynb`. Los archivos de entrenamiento y validación son `protein-secondary-structure.*`.


La documentación en inglés que ya estaba en este repositorio sigue en el archivo en inglés.
