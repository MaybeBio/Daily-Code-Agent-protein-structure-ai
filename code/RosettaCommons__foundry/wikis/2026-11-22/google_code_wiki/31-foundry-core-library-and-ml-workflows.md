## Foundry Core Library and ML Workflows
The Foundry core library provides the foundational infrastructure for machine learning workflows, encompassing configuration management, general utility functions, inference engines, metrics, and training harnesses. This design ensures a structured approach to building and deploying biomolecular design models.

A package-wide initialization process, defined in [`/rosettacommons/foundry/src/foundry/__init__.py`](https://github.com/rosettacommons/foundry/src/foundry/__init__.py), configures global settings. This includes loading environment variables from [`.env`](https://github.com/rosettacommons/foundry/.env#L2) files for parameters like debug mode and type checking, and setting up the package-specific logger. Crucially, it manages the integration of GPU acceleration technologies such as [`cuEquivariance`](https://github.com/rosettacommons/foundry/README.md#L39) and defines a global flag to disable checkpointing. Dynamic configuration is supported through custom Hydra [`OmegaConf`](https://github.com/rosettacommons/foundry/src/foundry/utils/logging.py#L8) resolvers in [`/rosettacommons/foundry/src/foundry/hydra/resolvers.py`](https://github.com/rosettacommons/foundry/src/foundry/hydra/resolvers.py), which allow for importing Python modules and converting enum values to regex strings directly within configuration files.

The framework includes a callback system, detailed in [Machine Learning Callbacks](#machine-learning-callbacks), which provides an extensible mechanism for injecting custom logic at various stages of the training and validation processes. These callbacks enable functionalities such as tracking model health, logging validation metrics, and profiling training performance.

The system incorporates a generic training harness, the [`FabricTrainer`](https://github.com/rosettacommons/foundry/src/foundry/trainers/fabric.py#L56), built on PyTorch Lightning Fabric. This harness orchestrates the entire training lifecycle, handling accelerator and strategy configuration, managing the model's state, and dynamically constructing models (with support for Exponential Moving Average or EMA), optimizers, and schedulers. It also implements robust training and validation loops, manages gradient accumulation, handles NaN/Inf gradients, and provides a checkpointing mechanism for saving and restoring the model's state.

Essential training utilities complement the [`FabricTrainer`](https://github.com/rosettacommons/foundry/src/foundry/trainers/fabric.py#L56). The [`EMA`](https://github.com/rosettacommons/foundry/src/foundry/training/EMA.py#L9) class in [`/rosettacommons/foundry/src/foundry/training/EMA.py`](https://github.com/rosettacommons/foundry/src/foundry/training/EMA.py) smooths model parameters for improved generalization. Gradient checkpointing techniques, such as [`create_custom_forward`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/util_module.py#L33) and [`activation_checkpointing`](https://github.com/rosettacommons/foundry/src/foundry/training/checkpoint.py#L38) in [`/rosettacommons/foundry/src/foundry/training/checkpoint.py`](https://github.com/rosettacommons/foundry/src/foundry/training/checkpoint.py), optimize memory usage during training. Learning rate schedulers, including the [`AF3Scheduler`](https://github.com/rosettacommons/foundry/src/foundry/training/schedulers.py#L7) in [`/rosettacommons/foundry/src/foundry/training/schedulers.py`](https://github.com/rosettacommons/foundry/src/foundry/training/schedulers.py), control learning rate adjustments over the training process.

The library offers a comprehensive set of utilities for data, model, and distributed management. Data handling is managed by [`SquashfsManager`](https://github.com/rosettacommons/foundry/src/foundry/utils/squashfs.py#L18) in [`/rosettacommons/foundry/src/foundry/utils/squashfs.py`](https://github.com/rosettacommons/foundry/src/foundry/utils/squashfs.py) for lazy mounting of Squashfs filesystems, and the functionality found in [`/rosettacommons/foundry/src/foundry/utils/datasets.py`](https://github.com/rosettacommons/foundry/src/foundry/utils/datasets.py) for distributed data loading and dataset composition. Model weight management, including flexible loading and parameter freezing policies, is provided by the functionality found in [`/rosettacommons/foundry/src/foundry/utils/weights.py`](https://github.com/rosettacommons/foundry/src/foundry/utils/weights.py). Dynamic instantiation of callbacks and loggers is handled by [`instantiate_callbacks`](https://github.com/rosettacommons/foundry/src/foundry/utils/instantiators.py#L19) and [`instantiate_loggers`](https://github.com/rosettacommons/foundry/src/foundry/utils/instantiators.py#L47) in [`/rosettacommons/foundry/src/foundry/utils/instantiators.py`](https://github.com/rosettacommons/foundry/src/foundry/utils/instantiators.py), while distributed training utilities including [`get_current_rank`](https://github.com/rosettacommons/foundry/src/foundry/utils/ddp.py#L12) and [`is_rank_zero`](https://github.com/rosettacommons/foundry/src/foundry/utils/ddp.py#L17) in [`/rosettacommons/foundry/src/foundry/utils/ddp.py`](https://github.com/rosettacommons/foundry/src/foundry/utils/ddp.py) facilitate DDP setup, rank management, and XPU acceleration support in [`/rosettacommons/foundry/src/foundry/utils/xpu`](https://github.com/rosettacommons/foundry/src/foundry/utils/xpu).

For structural bioinformatics, specialized utilities for geometric and tensor operations are provided. These include [`weighted_rigid_align`](https://github.com/rosettacommons/foundry/src/foundry/utils/alignment.py#L8) in [`/rosettacommons/foundry/src/foundry/utils/alignment.py`](https://github.com/rosettacommons/foundry/src/foundry/utils/alignment.py) for point cloud alignment, robust parsing and validation of protein component identifiers via functions like [`split_contig`](https://github.com/rosettacommons/foundry/src/foundry/utils/components.py#L48) and [`extract_pn_unit_info`](https://github.com/rosettacommons/foundry/src/foundry/utils/components.py#L64) in [`/rosettacommons/foundry/src/foundry/utils/components.py`](https://github.com/rosettacommons/foundry/src/foundry/utils/components.py), and core utilities for 3D rigid transformations through [`Rotation`](https://github.com/rosettacommons/foundry/src/foundry/utils/rigid.py#L278) and [`Rigid`](https://github.com/rosettacommons/foundry/src/foundry/utils/rigid.py#L850) classes in [`/rosettacommons/foundry/src/foundry/utils/rigid.py`](https://github.com/rosettacommons/foundry/src/foundry/utils/rigid.py). Methods for applying geometric augmentation through random rotations and translations are also available via [`get_random_augmentation`](https://github.com/rosettacommons/foundry/src/foundry/utils/rotation_augmentation.py#L17) and [`uniform_random_rotation`](https://github.com/rosettacommons/foundry/src/foundry/utils/rotation_augmentation.py#L37) in [`/rosettacommons/foundry/src/foundry/utils/rotation_augmentation.py`](https://github.com/rosettacommons/foundry/src/foundry/utils/rotation_augmentation.py).

Finally, command-line interface (CLI) tools, described in [Command Line Interface (CLI) Utilities](#command-line-interface-cli-utilities), enable users to manage various aspects of the Foundry ecosystem, such as installing, listing, and cleaning up model checkpoints.
