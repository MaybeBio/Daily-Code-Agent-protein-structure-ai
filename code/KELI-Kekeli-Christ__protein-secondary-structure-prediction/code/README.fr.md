Prédiction hélice / feuillet / pelote. Deux approches sont dans les notebooks : un MLP à fenêtre glissante et un LSTM bidirectionnel. Le README indique environ 69 % d’accuracy de validation pour le MLP. Ouvrez `protein_structure_mlp.ipynb` ou `protein_structure_lstm.ipynb`. Les fichiers d’apprentissage et de validation sont `protein-secondary-structure.*`.


La documentation anglaise déjà présente dans ce dépôt reste dans le fichier anglais.
