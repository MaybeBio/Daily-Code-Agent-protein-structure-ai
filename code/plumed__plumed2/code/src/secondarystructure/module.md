The variables within this module can be used to detect the presence of secondary structure elements such as alpha helices or parallel and antiparallel beta sheets in a protein.

Notice that the [ALPHARMSD](https://github.com/plumed/plumed2/blob/HEAD/src/secondarystructure/ALPHARMSD.md), [ANTIBETARMSD](https://github.com/plumed/plumed2/blob/HEAD/src/secondarystructure/ANTIBETARMSD.md) and [PARABETARMSD](https://github.com/plumed/plumed2/blob/HEAD/src/secondarystructure/PARABETARMSD.md) are implemented as shortcuts.  In other words, the only non shortcut
actions in this module are [SECONDARY_STRUCTURE_RMSD](https://github.com/plumed/plumed2/blob/HEAD/src/secondarystructure/SECONDARY_STRUCTURE_RMSD.md) and [SECONDARY_STRUCTURE_DRMSD](https://github.com/plumed/plumed2/blob/HEAD/src/secondarystructure/SECONDARY_STRUCTURE_DRMSD.md), which calculate the RMSD or DRMSD distance
between each segment of residues and the idealised version of the secondary structure element.  This structure makes it easy to add additional CVs that work similarly
to the [ALPHARMSD](https://github.com/plumed/plumed2/blob/HEAD/src/secondarystructure/ALPHARMSD.md), [ANTIBETARMSD](https://github.com/plumed/plumed2/blob/HEAD/src/secondarystructure/ANTIBETARMSD.md) and [PARABETARMSD](https://github.com/plumed/plumed2/blob/HEAD/src/secondarystructure/PARABETARMSD.md) either directly in the input file or by adding a new shortcut action.
