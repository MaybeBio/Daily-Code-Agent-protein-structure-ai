### In-Depth Tutorials for Key Features
Tutorials in [`torch-sim`](https://github.com/torchsim/torch-sim/README.md#L3) guide users through core functionalities, from fundamental [`SimState`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L121) management to advanced simulation techniques. These examples demonstrate how to create, manipulate, and interconvert system states with external atomistic libraries. The core data structure, [`SimState`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L121), handles atomistic system properties for single or batched systems. Tutorials illustrate [`SimState`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L121) creation using [`initialize_state`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L1480) from formats like [`ASE`](https://github.com/torchsim/torch-sim/README.md#L24) [`Atoms`](https://github.com/torchsim/torch-sim/CHANGELOG.md#L26), [`Pymatgen`](https://github.com/torchsim/torch-sim/README.md#L24) [`Structure`](https://github.com/torchsim/torch-sim/torch_sim/io.py#L10), and [`Phonopy`](https://github.com/torchsim/torch-sim/README.md#L24) [`PhonopyAtoms`](https://github.com/torchsim/torch-sim/torch_sim/io.py#L5). The [`to`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L730) method manages data types and device placement, while methods like [`clone`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L591), [`pop`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L701), [`split`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L690), and [`concatenate_states`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L1317) facilitate state manipulation. For molecular dynamics, the [`MDState`](https://github.com/torchsim/torch-sim/torch_sim/integrators/md.py#L32) subclass extends [`SimState`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L121) with properties like [`momenta`](https://github.com/torchsim/torch-sim/torch_sim/integrators/md.py#L62) and [`forces`](https://github.com/torchsim/torch-sim/torch_sim/runners.py#L904). For more details, see [Core Simulation State Management](#atomistic-simulation-engine-core-core-simulation-state-management).

[`torch-sim`](https://github.com/torchsim/torch-sim/README.md#L3) provides both low-level and high-level APIs. The low-level API is detailed in the tutorial located at [`/torchsim/torch-sim/examples/tutorials/low_level_tutorial.py`](https://github.com/torchsim/torch-sim/examples/tutorials/low_level_tutorial.py). This tutorial shows how to directly interact with models, such as [`MaceModel`](https://github.com/torchsim/torch-sim/torch_sim/models/mace.py#L22), to compute energy, forces, and stress, and manually apply optimizers (e.g., FIRE via [`fire_init`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/fire.py#L22) and [`fire_step`](https://github.com/torchsim/torch-sim/torch_sim/optimizers/fire.py#L117)) and integrators (e.g., NVT Langevin via [`nvt_langevin_init`](https://github.com/torchsim/torch-sim/torch_sim/integrators/nvt.py#L89) and [`nvt_langevin_step`](https://github.com/torchsim/torch-sim/torch_sim/integrators/nvt.py#L145)). This approach offers fine-grained control for users to implement custom simulation loops. The high-level API, demonstrated in [`/torchsim/torch-sim/examples/tutorials/high_level_tutorial.py`](https://github.com/torchsim/torch-sim/examples/tutorials/high_level_tutorial.py), simplifies common simulation tasks through functions like [`integrate`](https://github.com/torchsim/torch-sim/torch_sim/runners.py#L317) for molecular dynamics, [`optimize`](https://github.com/torchsim/torch-sim/torch_sim/runners.py#L638) for geometry optimization, and [`static`](https://github.com/torchsim/torch-sim/torch_sim/runners.py#L844) for single-point calculations. These functions support various integrators and optimizers and include features for trajectory reporting and autobatching. See [High-Level Simulation Runners](#atomistic-simulation-engine-core-high-level-simulation-runners) for further context.

Autobatching strategies are critical for efficient GPU memory management when simulating multiple systems. The tutorial at [`/torchsim/torch-sim/examples/tutorials/autobatching_tutorial.py`](https://github.com/torchsim/torch-sim/examples/tutorials/autobatching_tutorial.py) explains how [`BinningAutoBatcher`](https://github.com/torchsim/torch-sim/torch_sim/autobatching.py#L475) groups states using a binpacking algorithm for fixed-iteration workflows, while [`InFlightAutoBatcher`](https://github.com/torchsim/torch-sim/torch_sim/autobatching.py#L768) provides dynamic batching for tasks like geometry optimization, where states converge at different rates. These mechanisms help maintain high GPU utilization. Refer to [Autobatching Mechanisms](#atomistic-simulation-engine-core-autobatching-mechanisms) for a deeper understanding.

Trajectory reporting is handled by [`TorchSimTrajectory`](https://github.com/torchsim/torch-sim/torch_sim/trajectory.py#L561) for low-level HDF5 file interaction and [`TrajectoryReporter`](https://github.com/torchsim/torch-sim/torch_sim/trajectory.py#L68) for high-level data recording. The tutorial at [`/torchsim/torch-sim/examples/tutorials/reporting_tutorial.py`](https://github.com/torchsim/torch-sim/examples/tutorials/reporting_tutorial.py) illustrates how to save simulation data, including custom properties, to HDF5 files. The [`TrajectoryReporter`](https://github.com/torchsim/torch-sim/torch_sim/trajectory.py#L68) supports custom property calculators, allowing users to log specific quantities at defined frequencies.

Reproducible restarts are crucial for simulation integrity. The tutorial in [`/torchsim/torch-sim/examples/tutorials/reproducible_restart_tutorial.py`](https://github.com/torchsim/torch-sim/examples/tutorials/reproducible_restart_tutorial.py) demonstrates how to save and restore the complete simulation state, including the [`torch.Generator`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L40) random number generator state, to ensure exact reproducibility, especially for stochastic integrators. This involves comparing trajectories and final RNG states between continuous and restarted simulations to verify identical results.

Differentiable simulations enable meta-optimization. The tutorial at [`/torchsim/torch-sim/examples/tutorials/diff_sim.py`](https://github.com/torchsim/torch-sim/examples/tutorials/diff_sim.py) shows how [`torch-sim`](https://github.com/torchsim/torch-sim/README.md#L3) can be used to reproduce a bubble raft example, finding an optimal particle diameter by minimizing potential energy through gradient descent. This involves leveraging [`torch.autograd.grad`](https://github.com/torchsim/torch-sim/examples/tutorials/diff_sim.py#L273) to calculate gradients of the final energy with respect to simulation parameters, making the simulation process itself differentiable.

Finally, [`torch-sim`](https://github.com/torchsim/torch-sim/README.md#L3) supports hybrid simulation methods. The tutorial in [`/torchsim/torch-sim/examples/tutorials/hybrid_swap_tutorial.py`](https://github.com/torchsim/torch-sim/examples/tutorials/hybrid_swap_tutorial.py) demonstrates combining molecular dynamics with Monte Carlo, specifically NVT Langevin MD with Swap Monte Carlo. This showcases the modularity of [`torch-sim`](https://github.com/torchsim/torch-sim/README.md#L3) components, allowing for custom state objects and alternating between different integrators to build complex simulation workflows.
