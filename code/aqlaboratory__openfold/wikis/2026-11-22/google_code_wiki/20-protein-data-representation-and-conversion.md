### Protein Data Representation and Conversion
Protein structure data is standardized and managed through the [`Protein`](https://github.com/aqlaboratory/openfold/openfold/np/protein.py#L45) dataclass defined in [`/aqlaboratory/openfold/openfold/np/protein.py`](https://github.com/aqlaboratory/openfold/openfold/np/protein.py). This dataclass stores key structural attributes, including atom positions, amino acid types, atom masks, residue indices, B-factors, and chain indices.

The system provides functionalities to convert between the [`Protein`](https://github.com/aqlaboratory/openfold/openfold/np/protein.py#L45) dataclass and various standard protein data formats. It can parse PDB strings into [`Protein`](https://github.com/aqlaboratory/openfold/openfold/np/protein.py#L45) objects and generate PDB strings from [`Protein`](https://github.com/aqlaboratory/openfold/openfold/np/protein.py#L45) objects, including handling chain termination records and PDB headers. Similarly, it supports conversion from ProteinNet formatted strings, extracting sequence, tertiary coordinates, and masking information. For ModelCIF format, [`Protein`](https://github.com/aqlaboratory/openfold/openfold/np/protein.py#L45) objects can be transformed into ModelCIF strings, incorporating detailed system, entity, asymmetric unit, and assembly information, along with quality metrics derived from B-factors.

Additionally, the system includes utilities for generating ideal atom masks based on standard heavy atoms for each amino acid type and for constructing [`Protein`](https://github.com/aqlaboratory/openfold/openfold/np/protein.py#L45) objects directly from model prediction outputs, including the assignment of chain indices and B-factors. The [`Protein`](https://github.com/aqlaboratory/openfold/openfold/np/protein.py#L45) dataclass includes validation to ensure the number of unique chain indices does not exceed the PDB format limit. For a comprehensive overview of protein structure refinement, see [Protein Structure Refinement and Relaxation](#protein-structure-refinement-and-relaxation).
