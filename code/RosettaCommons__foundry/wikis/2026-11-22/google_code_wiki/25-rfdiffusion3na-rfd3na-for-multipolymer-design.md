## RFdiffusion3NA (RFD3NA) for Multipolymer Design
RFdiffusion3NA (RFD3NA) is a framework designed for *de novo* biomolecular design, specifically extending the capabilities of RFDiffusion3 to multipolymer systems including proteins, DNA, and RNA. The framework supports the design of complex structures with atomic functional sites, offering comprehensive tools for model definition, training, inference, and evaluation.

Installation involves installing the [`rc-foundry[rfd3na]`](https://github.com/rosettacommons/foundry/models/rfd3na/README.md#L20) package and downloading necessary checkpoints, managed through commands like [`pip install rc-foundry[rfd3na]`](https://github.com/rosettacommons/foundry/models/rfd3na/README.md#L134) and [`foundry install rfd3na`](https://github.com/rosettacommons/foundry/README.md#L1).

For inference, the [`rfd3na design`](https://github.com/rosettacommons/foundry/README.md#L1) command-line interface facilitates running design tasks. Users can define multipolymer [`contig`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L134) regions, specifying protein, RNA, or DNA chains (e.g., [`10-10,20-20R,30-30D`](https://github.com/rosettacommons/foundry/models/rfd3na/README.md#L55)). This process is managed by the [`RFD3InferenceEngine`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/engine.py#L140) in [`/rosettacommons/foundry/models/rfd3na/src/rfd3na/engine.py`](https://github.com/rosettacommons/foundry/models/rfd3na/src/rfd3na/engine.py), which handles input processing and model execution to generate [`RFD3Output`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/engine.py#L92). Advanced control over the inference process is available through options such as [`dump_trajectories`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/utils/io.py#L141) for debugging, [`prevalidate_inputs`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/engine.py#L71) for input validation, and [`skip_existing`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/engine.py#L51) to manage output files.

RFD3NA incorporates hydrogen bond conditioning during design. This functionality leverages external tools like [`HBPLUS`](https://github.com/rosettacommons/foundry/models/rfd3/README.md#L143), which requires specific configuration of its path via an environment variable.

The framework also supports training and fine-tuning. The main entry point for this is the script in [`/rosettacommons/foundry/models/rfd3na/src/rfd3na/train.py`](https://github.com/rosettacommons/foundry/models/rfd3na/src/rfd3na/train.py), which utilizes [`hydra`](https://github.com/rosettacommons/foundry/pyproject.toml#L27) for configuration and [`lightning.fabric`](https://github.com/rosettacommons/foundry/examples/all.ipynb#L84) for distributed execution. Training involves complex conditioning strategies, where the model learns from a variety of generated "problems" that fix specific atoms, sequences, or coordinates. This allows for diverse design scenarios. The [`AADesignTrainer`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/trainer/rfd3.py#L33) in [`/rosettacommons/foundry/models/rfd3na/src/rfd3na/trainer/rfd3na.py`](https://github.com/rosettacommons/foundry/models/rfd3na/src/rfd3na/trainer/rfd3na.py) extends a generic trainer to manage the specific steps involved in design training, including network input assembly and output generation. The training process can be monitored with various logging options, including Weights & Biases or CSV.

The core model implementation, located in [`/rosettacommons/foundry/models/rfd3na/src/rfd3na/model`](https://github.com/rosettacommons/foundry/models/rfd3na/src/rfd3na/model), features the [`RFD3`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/model/RFD3.py#L19) class, which integrates a [`diffusion_module`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/engine.py#L241) (an [`RFD3DiffusionModule`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/model/RFD3_diffusion_module.py#L32)) and an [`inference_sampler`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/engine.py#L54) ([`ConditionalDiffusionSampler`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/model/inference_sampler.py#L582)). The [`RFD3DiffusionModule`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/model/RFD3_diffusion_module.py#L32) employs a UNet-like architecture for denoising coordinates and sequence features. The [`inference_sampler`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/engine.py#L54) supports controlled, iterative denoising, including classifier-free guidance and symmetry application.

The framework also provides extensive data transformation capabilities in [`/rosettacommons/foundry/models/rfd3na/src/rfd3na/transforms`](https://github.com/rosettacommons/foundry/models/rfd3na/src/rfd3na/transforms). These [`Transform`](https://github.com/rosettacommons/foundry/models/rf3/README.md#L453) classes preprocess [`biotite.structure.AtomArray`](https://github.com/rosettacommons/foundry/models/rfd3/docs/input.md#L124) objects, handling conditioning strategies, feature generation, hydrogen bond calculations, and symmetry integration to ensure structural integrity during multipolymer design.

Finally, RFD3NA includes a comprehensive suite of metrics in [`/rosettacommons/foundry/models/rfd3na/src/rfd3na/metrics`](https://github.com/rosettacommons/foundry/models/rfd3na/src/rfd3na/metrics) for evaluating design quality. These metrics assess aspects such as clashes, chain breaks, backbone metrics, protein-protein interface (PPI) characteristics, sequence recovery, nucleic acid secondary structure similarity (using F1 scores), and ligand contacts, guiding the training process and informing the quality of generated designs.
