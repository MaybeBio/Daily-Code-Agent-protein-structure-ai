### RFD3 Inference and Design Examples
The RFdiffusion3 (RFD3) inference process orchestrates the *de novo* design of biomolecules through iterative denoising, producing novel structures based on specified constraints. The primary entry point for inference is [`rfd3 design`](https://github.com/rosettacommons/foundry/README.md#L1), which can be executed from the command line after installation or by directly running the script in [`/rosettacommons/foundry/models/rfd3/src/rfd3/run_inference.py`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/run_inference.py). This process is managed by the [`RFD3InferenceEngine`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/engine.py#L140) in [`/rosettacommons/foundry/models/rfd3/src/rfd3/engine.py`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/engine.py), which handles input parsing, batching, and output generation.

Users define design problems using an [`InputSpecification`](https://github.com/rosettacommons/foundry/models/rfd3/docs/input.md#L112) (detailed in [`/rosettacommons/foundry/models/rfd3/docs/input.md`](https://github.com/rosettacommons/foundry/models/rfd3/docs/input.md)), which can be provided via JSON or YAML files. This specification allows for precise control over design constraints, such as defining fixed and designable regions using [`contig`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L134) strings (e.g., [`"A1-10,/0,B15-24,/0,120-130"`](https://github.com/rosettacommons/foundry/models/rfd3/docs/examples/demo.json#L32) for protein, DNA, and RNA chains), specifying ligands, fixing atom coordinates using [`select_fixed_atoms`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L152), or applying hydrogen bond conditioning with [`select_hbond_donor`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L175) and [`select_hbond_acceptor`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L174). The [`InputSelection`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/parsing.py#L26) mini-language provides a flexible way to select specific residues and atoms for these constraints.

The core of the inference process involves the [`ConditionalDiffusionSampler`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/model/inference_sampler.py#L582) (found in [`/rosettacommons/foundry/models/rfd3/src/rfd3/model/inference_sampler.py`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/model/inference_sampler.py)), which performs iterative sampling and denoising. This sampler can operate with conditional diffusion and classifier-free guidance, enabling fine-grained control over the generated designs. The process also supports partial diffusion, where design occurs around already partially diffused structures, enabled by the [`partial_t`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L193) parameter.

RFD3 supports a wide array of design examples, showcasing its versatility across different biomolecular systems. These include:
*   **Enzyme Design:** Configuring enzyme design tasks by specifying input theozymes, identifying ligands, and defining fixed catalytic residues (illustrated in [`/rosettacommons/foundry/models/rfd3/docs/examples/enzyme_design.md`](https://github.com/rosettacommons/foundry/models/rfd3/docs/examples/enzyme_design.md)).
*   **Nucleic Acid Binder Design:** Designing proteins that bind to dsDNA, ssDNA, or RNA, involving complex [`contig`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L134) specifications, length definitions, and hydrogen bond conditioning (examples in [`/rosettacommons/foundry/models/rfd3/docs/examples/na_binder_design.md`](https://github.com/rosettacommons/foundry/models/rfd3/docs/examples/na_binder_design.md)).
*   **Protein Binder Design:** Creating novel protein-protein interfaces by defining target proteins, binder lengths, and binding hotspots. This often involves adjusting parameters like [`inference_sampler.step_scale`](https://github.com/rosettacommons/foundry/models/rfd3/docs/input.md#L69) and [`inference_sampler.gamma_0`](https://github.com/rosettacommons/foundry/models/rfd3/docs/designability_vs_diversity.md#L8) to balance designability and diversity (detailed in [`/rosettacommons/foundry/models/rfd3/docs/examples/protein_binder_design.md`](https://github.com/rosettacommons/foundry/models/rfd3/docs/examples/protein_binder_design.md)). Further discussion on balancing designability and diversity is available in [Controlling Designability vs. Diversity](#rfdiffusion3-rfd3-for-de-novo-design-rfd3-inference-and-design-examples-controlling-designability-vs-diversity).
*   **Small Molecule Binder Design:** Designing proteins to encapsulate or interact with specific small molecules, using [`select_fixed_atoms`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L152), [`select_exposed`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L172), and [`select_buried`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L170) to guide the placement and interaction of the protein with the ligand (see [`/rosettacommons/foundry/models/rfd3/docs/examples/sm_binder_design.md`](https://github.com/rosettacommons/foundry/models/rfd3/docs/examples/sm_binder_design.md)).
*   **Symmetry Design:** Generating proteins with precise cyclic ([`C`](https://github.com/rosettacommons/foundry/models/rf3/README.md#L61)) or dihedral ([`D`](https://github.com/rosettacommons/foundry/models/rf3/README.md#L392)) symmetries, either unconditionally or by scaffolding around existing motifs. The [`symmetry`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L185) object in the input JSON/YAML allows defining the symmetry group and identifying motifs that should or should not be symmetrized (explained in [`/rosettacommons/foundry/models/rfd3/docs/examples/symmetry.md`](https://github.com/rosettacommons/foundry/models/rfd3/docs/examples/symmetry.md)).

After successful inference, RFD3 outputs generated structures as [`.cif.gz`](https://github.com/rosettacommons/foundry/models/rf3/README.md#L620) files and design metrics as [`.json`](https://github.com/rosettacommons/foundry/models/rfd3/README.md#L67) files, providing comprehensive results for analysis. The utility script [`/rosettacommons/foundry/models/rfd3/docs/examples/run_inf_tutorial.sh`](https://github.com/rosettacommons/foundry/models/rfd3/docs/examples/run_inf_tutorial.sh) demonstrates how to orchestrate multiple inference runs and manage output files.
