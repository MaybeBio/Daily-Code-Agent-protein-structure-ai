## Example Workflows and Tutorials
[`torch-sim`](https://github.com/torchsim/torch-sim/README.md#L3) provides a variety of examples, tutorials, and benchmarking tools to guide users through its functionalities for atomistic simulations. These resources demonstrate practical applications of molecular dynamics, structural optimization, phonon calculations, and the use of high-level APIs. The examples also highlight autobatching mechanisms and concepts such as differentiable simulations and provide insights into performance evaluation.

Practical example scripts located in [`/torchsim/torch-sim/examples/scripts`](https://github.com/torchsim/torch-sim/examples/scripts) illustrate core [`torch-sim`](https://github.com/torchsim/torch-sim/README.md#L3) features. These include an introduction to basic operations with both classical potentials (e.g., [`LennardJonesModel`](https://github.com/torchsim/torch-sim/torch_sim/models/lennard_jones.py#L74)) and machine learning potentials (e.g., [`MaceModel`](https://github.com/torchsim/torch-sim/torch_sim/models/mace.py#L22)), covering both single-system and batched simulations as shown in [`/torchsim/torch-sim/examples/scripts/1_introduction.py`](https://github.com/torchsim/torch-sim/examples/scripts/1_introduction.py). Structural optimization techniques, such as FIRE, Gradient Descent, L-BFGS, and BFGS, are demonstrated with various cell filters in [`/torchsim/torch-sim/examples/scripts/2_structural_optimization.py`](https://github.com/torchsim/torch-sim/examples/scripts/2_structural_optimization.py). Molecular dynamics simulations across NVE, NVT, and NPT ensembles using different thermostats and barostats are detailed in [`/torchsim/torch-sim/examples/scripts/3_dynamics.py`](https://github.com/torchsim/torch-sim/examples/scripts/3_dynamics.py). The high-level API, which streamlines complex workflows like MD and geometry optimization, is showcased in [`/torchsim/torch-sim/examples/scripts/4_high_level_api.py`](https://github.com/torchsim/torch-sim/examples/scripts/4_high_level_api.py), including how to integrate models, utilize trajectory reporting, and define custom convergence criteria. Advanced workflows, such as in-flight autobatching for efficient optimization and the calculation of elastic constants, are presented in [`/torchsim/torch-sim/examples/scripts/5_workflow.py`](https://github.com/torchsim/torch-sim/examples/scripts/5_workflow.py). Furthermore, [`torch-sim`](https://github.com/torchsim/torch-sim/README.md#L3)'s integration with Phonopy for phonon calculations, including structure relaxation, batched force constant computations, and phonon density of states/band structure analysis, is covered in [`/torchsim/torch-sim/examples/scripts/6_phonons.py`](https://github.com/torchsim/torch-sim/examples/scripts/6_phonons.py). Additional features, like batched neighbor list calculations and Velocity Autocorrelation Function (VACF) computations, are found in [`/torchsim/torch-sim/examples/scripts/7_others.py`](https://github.com/torchsim/torch-sim/examples/scripts/7_others.py).

In-depth tutorials in [`/torchsim/torch-sim/examples/tutorials`](https://github.com/torchsim/torch-sim/examples/tutorials) offer guided explanations of key [`torch-sim`](https://github.com/torchsim/torch-sim/README.md#L3) concepts. The [`SimState`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L121) dataclass, which is central to managing atomistic system properties and enables batched operations, is thoroughly explained in [`/torchsim/torch-sim/examples/tutorials/state_tutorial.py`](https://github.com/torchsim/torch-sim/examples/tutorials/state_tutorial.py). This tutorial also covers its creation from external formats and conversion back to them. Tutorials further explore low-level API usage for direct model interaction and manual application of optimizers and integrators, and high-level APIs that orchestrate MD, geometry optimization, and static calculations. The mechanisms of autobatching, including [`BinningAutoBatcher`](https://github.com/torchsim/torch-sim/torch_sim/autobatching.py#L475) and [`InFlightAutoBatcher`](https://github.com/torchsim/torch-sim/torch_sim/autobatching.py#L768) for managing GPU memory and optimizing batch processing, are detailed in [`/torchsim/torch-sim/examples/tutorials/autobatching_tutorial.py`](https://github.com/torchsim/torch-sim/examples/tutorials/autobatching_tutorial.py). [Autobatching Mechanisms](#atomistic-simulation-engine-core-autobatching-mechanisms) provides more information on this feature. Trajectory reporting with [`TorchSimTrajectory`](https://github.com/torchsim/torch-sim/torch_sim/trajectory.py#L561) for efficient data storage and retrieval is discussed in [`/torchsim/torch-sim/examples/tutorials/reporting_tutorial.py`](https://github.com/torchsim/torch-sim/examples/tutorials/reporting_tutorial.py). Tutorials also provide guidance on ensuring reproducibility in simulations, addressing non-determinism from GPU operations and stochastic integrators, as demonstrated in [`/torchsim/torch-sim/examples/tutorials/reproducible_restart_tutorial.py`](https://github.com/torchsim/torch-sim/examples/tutorials/reproducible_restart_tutorial.py). [Ensuring Reproducibility in TorchSim](#user-guide-to-core-concepts-ensuring-reproducibility-in-torchsim) offers further details on this. Differentiable simulations, for instance, for meta-optimization tasks such as finding optimal parameters for a [`SoftSphereMultiModel`](https://github.com/torchsim/torch-sim/torch_sim/models/soft_sphere.py#L248), are illustrated in [`/torchsim/torch-sim/examples/tutorials/diff_sim.py`](https://github.com/torchsim/torch-sim/examples/tutorials/diff_sim.py). Hybrid MD/MC methods are also demonstrated, showing how to combine different simulation techniques, as seen in [`/torchsim/torch-sim/examples/tutorials/hybrid_swap_tutorial.py`](https://github.com/torchsim/torch-sim/examples/tutorials/hybrid_swap_tutorial.py).

For performance evaluation, the [`/torchsim/torch-sim/examples/benchmarking`](https://github.com/torchsim/torch-sim/examples/benchmarking) directory contains scripts that benchmark various aspects of [`torch-sim`](https://github.com/torchsim/torch-sim/README.md#L3). These include molecular dynamics throughput comparisons between [`torch-sim`](https://github.com/torchsim/torch-sim/README.md#L3)'s batched NVT-Langevin and [`ASE`](https://github.com/torchsim/torch-sim/README.md#L24)'s sequential Langevin dynamics in [`/torchsim/torch-sim/examples/benchmarking/md-throughput.py`](https://github.com/torchsim/torch-sim/examples/benchmarking/md-throughput.py). Neighbor list algorithms are benchmarked for efficiency across different implementations (e.g., linked-cell, Alchemiops, Vesin) using random structures from public databases, as shown in [`/torchsim/torch-sim/examples/benchmarking/neighborlists.py`](https://github.com/torchsim/torch-sim/examples/benchmarking/neighborlists.py). The optimization throughput of MACE models using LBFGS or FIRE optimizers is evaluated and compared against [`ASE`](https://github.com/torchsim/torch-sim/README.md#L24) in [`/torchsim/torch-sim/examples/benchmarking/opt-throughput.py`](https://github.com/torchsim/torch-sim/examples/benchmarking/opt-throughput.py). Finally, [`/torchsim/torch-sim/examples/benchmarking/scaling.py`](https://github.com/torchsim/torch-sim/examples/benchmarking/scaling.py) assesses [`torch-sim`](https://github.com/torchsim/torch-sim/README.md#L3)'s scaling performance for static calculations, structural relaxation, NVE, and NVT molecular dynamics across varying numbers of structures. These benchmarking tools help understand the efficiency and performance characteristics of [`torch-sim`](https://github.com/torchsim/torch-sim/README.md#L3) across different use cases and hardware configurations.
