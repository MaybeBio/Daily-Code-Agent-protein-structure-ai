### Fourier Feature Encoding with `FourierEmbedding`
The [`FourierEmbedding`](https://github.com/rosettacommons/foundry/src/foundry/model/layers/blocks.py#L7) class, found in [`/rosettacommons/foundry/src/foundry/model/layers/blocks.py`](https://github.com/rosettacommons/foundry/src/foundry/model/layers/blocks.py), implements a Fourier feature encoding technique for scalar inputs. This method transforms a single scalar value into a higher-dimensional representation using cosine functions. This expansion allows neural networks to better capture periodic patterns and fine-grained details within the input data, which can be particularly useful for tasks involving spatial or temporal coordinates.

The class includes a [`reset_parameters`](https://github.com/rosettacommons/foundry/src/foundry/model/layers/blocks.py#L20) method for initializing the learnable weight ([`w`](https://github.com/rosettacommons/foundry/src/foundry/model/layers/blocks.py#L10)) and bias ([`b`](https://github.com/rosettacommons/foundry/src/foundry/model/layers/blocks.py#L11)) parameters that define the mapping. During its forward pass, [`FourierEmbedding`](https://github.com/rosettacommons/foundry/src/foundry/model/layers/blocks.py#L7) computes [`torch.cos(2 * pi * (t[..., None] * self.w + self.b))`](https://github.com/rosettacommons/foundry/src/foundry/model/layers/blocks.py#L4), where [`t`](https://github.com/rosettacommons/foundry/Makefile#L52) is the input scalar. This mathematical operation effectively projects the scalar into a feature space where its position can be uniquely and periodically encoded, thereby enriching the input representation for subsequent neural network layers.
