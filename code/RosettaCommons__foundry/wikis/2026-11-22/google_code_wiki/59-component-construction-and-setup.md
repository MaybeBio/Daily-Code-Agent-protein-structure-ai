### Component Construction and Setup
The [`FabricTrainer`](https://github.com/rosettacommons/foundry/src/foundry/trainers/fabric.py#L56) orchestrates the dynamic instantiation and preparation of critical training components: models, optimizers, and learning rate schedulers. Configuration for these components is typically handled using Hydra, allowing for flexible and declarative definitions. Once constructed, these components are prepared for PyTorch Lightning Fabric's distributed environment. A key feature is the optional wrapping of models with an Exponential Moving Average (EMA), which can enhance model stability and generalization during training. This component construction and setup process is foundational to the overall training lifecycle managed by the [Training Harness with PyTorch Lightning Fabric](#foundry-core-library-and-ml-workflows-training-harness-with-pytorch-lightning-fabric).
