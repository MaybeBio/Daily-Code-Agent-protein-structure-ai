### Checkpoint Management: Installation and Resolution
The Foundry command-line interface (CLI) provides a mechanism for managing model checkpoints, particularly focusing on their installation and resolution. The [`install`](https://github.com/rosettacommons/foundry/src/foundry_cli/download_checkpoints.py#L145) command in [`/rosettacommons/foundry/src/foundry_cli/download_checkpoints.py`](https://github.com/rosettacommons/foundry/src/foundry_cli/download_checkpoints.py) facilitates downloading and setting up model weights.

When a user executes the [`install`](https://github.com/rosettacommons/foundry/src/foundry_cli/download_checkpoints.py#L145) command, the system first determines where these checkpoints should be stored. This involves a function, [`_resolve_checkpoint_dirs`](https://github.com/rosettacommons/foundry/src/foundry_cli/download_checkpoints.py#L33) in [`/rosettacommons/foundry/src/foundry_cli/download_checkpoints.py`](https://github.com/rosettacommons/foundry/src/foundry_cli/download_checkpoints.py), which prioritizes any directory specified by the user. If no user-defined path is provided, it defaults to predefined locations. After identifying the primary storage directory, this path is recorded using [`append_checkpoint_to_env`](https://github.com/rosettacommons/foundry/src/foundry/inference_engines/checkpoint_registry.py#L49) to ensure consistency for future operations.

Once the target directory is established, the CLI proceeds to download the specified models. Each model download is handled by the [`install_model`](https://github.com/rosettacommons/foundry/src/foundry_cli/download_checkpoints.py#L106) function in [`/rosettacommons/foundry/src/foundry_cli/download_checkpoints.py`](https://github.com/rosettacommons/foundry/src/foundry_cli/download_checkpoints.py). To ensure the integrity of the downloaded files, a SHA256 hash verification is performed, preventing the use of corrupted or altered model weights. This process allows users to easily obtain and integrate pre-trained models into their Foundry workflows.
