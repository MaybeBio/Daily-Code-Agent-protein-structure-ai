### REST API Utilities for Project Data Management
The [`/mmb-irb/mddb-workflow/manual_tools/api_tools.py`](https://github.com/mmb-irb/mddb-workflow/manual_tools/api_tools.py) script provides tools for interacting with the MDDB REST API. It enables users to query project data, paginate through results, and download specific files associated with projects. The system manages the retrieval of project accessions and details through pagination, ensuring all relevant data is collected from the API. It also supports downloading various file types, such as configuration files, by constructing appropriate URLs and handling file storage. The default API endpoint used by these utilities is derived from the [`DEFAULT_API_URL`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/utils/constants.py#L54) within the [`mddb_workflow.console`](https://github.com/mmb-irb/mddb-workflow/pyproject.toml#L25) module, specifically pointing to the [`/rest/current`](https://github.com/mmb-irb/mddb-workflow/manual_tools/logger_and_loader.py#L19) path. For an overview of other manual tools, refer to [Manual Tools for Workflow Interaction](#manual-tools-for-workflow-interaction).
