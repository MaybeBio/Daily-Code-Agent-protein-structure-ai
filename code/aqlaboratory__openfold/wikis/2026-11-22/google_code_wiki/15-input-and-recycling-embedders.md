### Input and Recycling Embedders
Initial sequence and MSA features are transformed into dense representations suitable for the model's core Evoformer blocks via various embedding modules. The primary [`AlphaFold`](https://github.com/aqlaboratory/openfold/openfold/model/model.py#L66) model class orchestrates the use of these embedders during its forward pass, processing raw input data into meaningful numerical vectors.

The [`InputEmbedder`](https://github.com/aqlaboratory/openfold/openfold/model/embedders.py#L39) ([`/aqlaboratory/openfold/openfold/model/embedders.py`](https://github.com/aqlaboratory/openfold/openfold/model/embedders.py)) processes target features (like amino acid type), MSA features, and relative positional information to generate initial MSA and pair embeddings. For multimeric protein complexes, the [`InputEmbedderMultimer`](https://github.com/aqlaboratory/openfold/openfold/model/embedders.py#L158) ([`/aqlaboratory/openfold/openfold/model/embedders.py`](https://github.com/aqlaboratory/openfold/openfold/model/embedders.py)) extends this functionality by incorporating chain-aware relative positional encodings, enabling the model to distinguish between interactions within a single chain and those between different chains. An alternative, [`PreembeddingEmbedder`](https://github.com/aqlaboratory/openfold/openfold/model/embedders.py#L313) ([`/aqlaboratory/openfold/openfold/model/embedders.py`](https://github.com/aqlaboratory/openfold/openfold/model/embedders.py)), is available for scenarios where pre-computed sequence embeddings are utilized instead of raw MSA data.

To enhance prediction accuracy through iterative refinement, a recycling mechanism is employed. The [`RecyclingEmbedder`](https://github.com/aqlaboratory/openfold/openfold/model/embedders.py#L407) ([`/aqlaboratory/openfold/openfold/model/embedders.py`](https://github.com/aqlaboratory/openfold/openfold/model/embedders.py)) takes outputs from a previous prediction cycle—specifically the previous MSA and pair embeddings, along with predicted C-beta coordinates—and converts them into fresh embeddings. These recycled embeddings are then fed back into the model in subsequent iterations, allowing the model to progressively refine its understanding of the protein's structure. The decision to continue recycling can be governed by an early stopping criterion, such as the [`tolerance_reached`](https://github.com/aqlaboratory/openfold/openfold/model/model.py#L186) function in the [`AlphaFold`](https://github.com/aqlaboratory/openfold/openfold/model/model.py#L66) model ([`/aqlaboratory/openfold/openfold/model/model.py`](https://github.com/aqlaboratory/openfold/openfold/model/model.py)), which monitors the RMSD difference between successive predictions to avoid unnecessary computations. This iterative process allows the model to build upon its own predictions, gradually converging towards a more accurate protein structure.
