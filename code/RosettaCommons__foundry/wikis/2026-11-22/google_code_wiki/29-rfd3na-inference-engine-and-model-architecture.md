### RFD3NA Inference Engine and Model Architecture
RFdiffusion3NA (RFD3NA) provides a framework for designing complex biomolecular structures involving proteins, DNA, and RNA. The inference engine, primarily managed by [`RFD3InferenceEngine`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/engine.py#L140) in [`/rosettacommons/foundry/models/rfd3na/src/rfd3na/engine.py`](https://github.com/rosettacommons/foundry/models/rfd3na/src/rfd3na/engine.py), orchestrates the entire design workflow, from handling input specifications to generating and saving multipolymer outputs.

The inference process begins with robust input handling, where [`RFD3InferenceEngine`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/engine.py#L140) processes diverse input formats, including file paths and detailed [`DesignInputSpecification`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L115) objects. This standardization ensures that design constraints, such as defining specific [`contig`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/inference/input_parsing.py#L134) regions (e.g., [`10-10,20-20R,30-30D`](https://github.com/rosettacommons/foundry/models/rfd3na/README.md#L55) for protein, RNA, and DNA chains) or specifying fixed atoms and unindexed areas, are correctly interpreted and prepared for the model. The [`run`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/engine.py#L273) method of [`RFD3InferenceEngine`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/engine.py#L140) then executes the design process by interacting with the underlying diffusion model.

At the core of the design process is the [`RFD3`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/model/RFD3.py#L19) model, defined in [`/rosettacommons/foundry/models/rfd3na/src/rfd3na/model/RFD3.py`](https://github.com/rosettacommons/foundry/models/rfd3na/src/rfd3na/model/RFD3.py). This model wraps the [`RFD3DiffusionModule`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/model/RFD3_diffusion_module.py#L32), which serves as the generative engine. The [`RFD3DiffusionModule`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/model/RFD3_diffusion_module.py#L32) (found in [`/rosettacommons/foundry/models/rfd3na/src/rfd3na/model/RFD3_diffusion_module.py`](https://github.com/rosettacommons/foundry/models/rfd3na/src/rfd3na/model/RFD3_diffusion_module.py)) employs a UNet-like architecture to iteratively denoise noisy atomic coordinates and sequence features. It refines predictions through a recycling mechanism, continuously improving the generated structures. The module's design incorporates various neural network building blocks, such as specialized attention mechanisms and token encoders, optimized for biomolecular structure prediction.

The iterative denoising process is guided by the [`ConditionalDiffusionSampler`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/model/inference_sampler.py#L582), implemented in [`/rosettacommons/foundry/models/rfd3na/src/rfd3na/model/inference_sampler.py`](https://github.com/rosettacommons/foundry/models/rfd3na/src/rfd3na/model/inference_sampler.py). This sampler manages the step-by-step refinement of the structure, allowing for controlled diffusion. It supports advanced features like classifier-free guidance, which enables the model to generate diverse designs while adhering to specified conditions by comparing predictions made with and without conditioning information. Furthermore, the sampler can apply symmetry constraints during the diffusion process, ensuring that generated multipolymer structures maintain desired symmetries. The flexibility of the [`ConditionalDiffusionSampler`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/model/inference_sampler.py#L582) extends to incorporating motif alignment and other specific design criteria throughout the sampling trajectory.
