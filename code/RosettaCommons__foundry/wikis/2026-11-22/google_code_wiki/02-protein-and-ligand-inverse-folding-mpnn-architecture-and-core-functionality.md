### Protein and Ligand Inverse Folding (MPNN) Architecture and Core Functionality
The ProteinMPNN model, implemented in the [`ProteinMPNN`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/mpnn.py#L21) class found in [`/rosettacommons/foundry/models/mpnn/src/mpnn/model/mpnn.py`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/mpnn.py), is designed for protein sequence prediction based on 3D structural information. This model, along with its ligand-aware variant ([`LigandMPNN`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/mpnn.py#L2303)), processes protein coordinates and residue masks to output amino acid sequences. Its architecture is composed of several key stages: graph featurization, message passing layers, positional encoding, and sequence decoding strategies.

Graph featurization transforms raw atomic coordinates and residue identities into a graph representation suitable for neural network processing. The [`ProteinFeatures`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/layers/graph_embeddings.py#L11) class within [`/rosettacommons/foundry/models/mpnn/src/mpnn/model/layers/graph_embeddings.py`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/layers/graph_embeddings.py) is central to this process. It extracts features such as 3D coordinates, computes pairwise distances between residues, and applies radial basis function (RBF) embeddings to convert these distances into a higher-dimensional representation. This module also handles the extraction of specific atom types (e.g., backbone atoms) and can generate virtual atoms for more abstract structural representations. Specialized subclasses like [`ProteinFeaturesMembrane`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/layers/graph_embeddings.py#L791), [`ProteinFeaturesPSSM`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/layers/graph_embeddings.py#L849), and [`ProteinFeaturesLigand`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/layers/graph_embeddings.py#L897) extend this base functionality to incorporate additional information such as membrane context, position-specific scoring matrix (PSSM) data, or complex protein-ligand interaction features, respectively. These extensions allow the model to adapt to a wider range of biomolecular design problems by generating more specific node and edge features.

Following featurization, the model employs message passing layers to integrate information across the protein graph. The encoder ([`EncLayer`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/layers/message_passing.py#L114)) and decoder ([`DecLayer`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/layers/message_passing.py#L227)), defined in [`/rosettacommons/foundry/models/mpnn/src/mpnn/model/layers/message_passing.py`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/layers/message_passing.py), use these features to iteratively update node and edge embeddings. These layers aggregate information from neighboring nodes and edges, allowing the model to develop a comprehensive understanding of the protein's structural and chemical environment. Positional encoding, managed by the [`PositionalEncodings`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/layers/positional_encoding.py#L5) class in [`/rosettacommons/foundry/models/mpnn/src/mpnn/model/layers/positional_encoding.py`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/layers/positional_encoding.py), provides chain-aware embeddings that capture the relative positions of residues, ensuring that spatial and sequential relationships are preserved throughout the message passing process.

Sequence design is achieved through decoding strategies. During training, [`decode_teacher_forcing`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/mpnn.py#L986) uses the known ground truth sequence to guide the model's predictions, which helps stabilize learning. For inference, [`decode_auto_regressive`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/mpnn.py#L1259) iteratively predicts residues in a specified order, using previously predicted residues as context. This iterative approach allows for the generation of novel protein sequences. Both decoding methods utilize dynamically generated causality masks ([`causal_mask`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/mpnn.py#L373), [`anti_causal_mask`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/mpnn.py#L375)) to control the flow of information, preventing the model from accessing future information during prediction and ensuring adherence to autoregressive principles. The model also incorporates mechanisms to handle sequence symmetry, adjusting the decoding order and aggregating logits across symmetric residues to ensure consistent and biologically plausible designs. The [`logits_to_sample`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/mpnn.py#L872) function converts raw model outputs into sampled sequences, allowing control over sequence diversity through parameters such as [`temperature`](https://github.com/rosettacommons/foundry/models/mpnn/README.md#L122) and [`bias`](https://github.com/rosettacommons/foundry/models/rfd3/docs/input.md#L225).
