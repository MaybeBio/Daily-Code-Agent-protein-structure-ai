## Protein Structure Prediction Core
The OpenFold protein structure prediction system is organized into a modular architecture designed to process protein sequence data and predict its 3D atomic coordinates. This architecture includes components for embedding input features, an iterative refinement process, and a module dedicated to converting abstract representations into physical structures.

The overall design of OpenFold centers around the [`AlphaFold`](https://github.com/aqlaboratory/openfold/openfold/model/model.py#L66) class, defined in [`/aqlaboratory/openfold/openfold/model/model.py`](https://github.com/aqlaboratory/openfold/openfold/model/model.py). This class orchestrates the various modules that comprise the prediction pipeline. Initial processing of raw sequence and alignment data into numerical representations is handled by specialized embedding modules, which prepare the input for the core of the model. These embedding modules handle different types of data, such as target features, Multiple Sequence Alignment (MSA) features, and template information, converting them into a format suitable for the Evoformer, the primary computational engine of the model. For more details on the specific modules, refer to [Overall Model Architecture and Components](#protein-structure-prediction-core-overall-model-architecture-and-components).

The system integrates external bioinformatics tools to enhance the quality of initial data. Tools such as Jackhmmer and HHblits are used to generate rich MSAs, while HHsearch and HMMsearch are utilized for identifying and extracting homologous template structures. These external tools are critical for providing evolutionary and structural context, which significantly informs the prediction process. The [`/aqlaboratory/openfold/openfold/data/tools`](https://github.com/aqlaboratory/openfold/openfold/data/tools) directory contains Python wrappers for these command-line tools, enabling their seamless integration into the data processing pipeline. Further information about this integration can be found in [Integration of External Bioinformatics Tools](#protein-structure-prediction-core-integration-of-external-bioinformatics-tools).

The processing of raw protein data into model-ready features is a multi-step pipeline. This includes loading and parsing various data formats, applying a range of transformations and augmentations, and assembling features for both single proteins and multimeric complexes. This pipeline ensures that the model receives a consistent and enriched representation of the protein. The [`/aqlaboratory/openfold/openfold/data`](https://github.com/aqlaboratory/openfold/openfold/data) directory encompasses the entirety of this data handling process, including data modules, loaders, and an array of transformation functions. For a deeper dive into how protein data is processed, see [Data Processing and Feature Generation Pipeline](#protein-structure-prediction-core-data-processing-and-feature-generation-pipeline).

Throughout the prediction process, a variety of numerical operations are performed, particularly those related to 3D geometry and rigid body transformations. These operations are fundamental for manipulating and representing protein structures. OpenFold utilizes specialized data structures and utilities, such as [`Vec3Array`](https://github.com/aqlaboratory/openfold/openfold/utils/geometry/vector.py#L25) for vectors, [`Rot3Array`](https://github.com/aqlaboratory/openfold/openfold/utils/geometry/rotation_matrix.py#L30) for rotation matrices, and [`Rigid3Array`](https://github.com/aqlaboratory/openfold/openfold/utils/geometry/rigid_matrix_vector.py#L30) for rigid transformations, which are defined in [`/aqlaboratory/openfold/openfold/utils/geometry`](https://github.com/aqlaboratory/openfold/openfold/utils/geometry). These components facilitate calculations involving atomic coordinates, bond angles, and overall protein backbone movements, ensuring accurate structural predictions. A detailed explanation of these geometric operations is available in [Geometric Operations and Rigid Body Transformations](#protein-structure-prediction-core-geometric-operations-and-rigid-body-transformations).

After an initial structure prediction, the system incorporates a refinement step to improve the physical realism and reduce steric clashes of the predicted models. This post-prediction refinement often involves energy minimization using molecular mechanics force fields. OpenFold employs the Amber energy minimization process, leveraging the OpenMM library, to relax the predicted protein structures. This step is crucial for producing high-quality, stable 3D models. The implementation for this can be found within the [`/aqlaboratory/openfold/openfold/np/relax`](https://github.com/aqlaboratory/openfold/openfold/np/relax) directory. More information on this refinement process is provided in [Protein Structure Refinement and Relaxation](#protein-structure-prediction-core-protein-structure-refinement-and-relaxation).
