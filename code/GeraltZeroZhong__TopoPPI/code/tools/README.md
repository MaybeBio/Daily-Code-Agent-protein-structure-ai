# TopoPPI tools

[OptCuts](https://github.com/GeraltZeroZhong/TopoPPI/blob/HEAD/tools/OptCuts/residue_aware/README.md) contains the native solver build scripts and residue-aware objective. [Affinity tools](https://github.com/GeraltZeroZhong/TopoPPI/blob/HEAD/plugins/affinity/tools/README.md) provide reusable feature preparation, fitting and evaluation commands for user-supplied inputs.

Routine mapping uses the [application, CLI or Python API](https://github.com/GeraltZeroZhong/TopoPPI/blob/HEAD/README.md). The [hotspot plugin](https://github.com/GeraltZeroZhong/TopoPPI/blob/HEAD/plugins/hotspot/README.md) exposes residue ranking separately.
