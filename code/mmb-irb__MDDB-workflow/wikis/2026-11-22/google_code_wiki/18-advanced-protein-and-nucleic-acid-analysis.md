### Advanced Protein and Nucleic Acid Analysis
The system provides a suite of tools for the comprehensive analysis of protein chains and nucleic acids within molecular systems. This includes capabilities for mapping protein sequences to external biological databases, integrating structural data from the Protein Data Bank (PDB), performing domain identification, and calculating metrics related to system coverage and residue presence.

A central component for protein analysis is the [`ProteinMapper`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/tools/generate_map.py#L104) class, located in [`/mmb-irb/mddb-workflow/mddb_workflow/tools/generate_map.py`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/tools/generate_map.py). This class orchestrates the process of identifying protein chains within a molecular structure and mapping their sequences to UniProt reference sequences. It employs a prioritized approach, first checking for explicitly provided references, then local files, remote project data, and PDB-derived UniProt IDs. As a last resort, it utilizes a BLAST search ([`run_blastp`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/utils/blast.py#L73)) to find potential UniProt matches for unassigned chains, ensuring that most protein sequences can be reliably characterized. The [`ProteinMapper`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/tools/generate_map.py#L104) also cleans protein sequences by replacing non-standard amino acid representations with 'X' to ensure robust alignment.

Once UniProt references are identified, the system fetches detailed information for each UniProt ID from the EBI UniProt API using [`get_uniprot_reference`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/tools/generate_map.py#L739) in [`/mmb-irb/mddb-workflow/mddb_workflow/tools/generate_map.py`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/tools/generate_map.py). This function retrieves essential metadata such as protein name, gene names, organism, sequence, and domain information, which is then structured for storage and further analysis. A specific algorithm is also integrated to identify SARS-CoV-2 variants in spike proteins by aligning sequences against a curated set of known COVID-19 spike variants, as detailed in [Curated SARS-CoV-2 Variant Sequences](#biological-resources-curated-sars-cov-2-variant-sequences).

The system further integrates with the EBI InterProScan web service for domain identification. The module [`prepare_chain_references`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/tools/chains.py#L98) in [`/mmb-irb/mddb-workflow/mddb_workflow/tools/chains.py`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/tools/chains.py) handles the submission of unique protein sequences to InterProScan, monitors job status, and retrieves the results. This allows for the identification of conserved protein domains and functional sites. For additional details on this process, refer to [Comprehensive MD Analysis Suite](#md-simulation-data-lifecycle-and-analysis-comprehensive-md-analysis-suite).

For integrating structural data, the system retrieves and processes PDB entries from the RCSB PDB API. The [`prepare_pdb_references`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/tools/generate_pdb_references.py#L19) function in [`/mmb-irb/mddb-workflow/mddb_workflow/tools/generate_pdb_references.py`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/tools/generate_pdb_references.py) downloads PDB data, extracts relevant structural and biological information, and calculates Solvent Accessible Surface Area (SASA) for protein chains using GROMACS tools. It also establishes residue-level mappings between UniProt IDs and PDB chains, which is crucial for cross-referencing information between sequence and structural databases.

Finally, [`get_coverage_and_presence`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/tools/get_coverage_and_presence.py#L11) in [`/mmb-irb/mddb-workflow/mddb_workflow/tools/get_coverage_and_presence.py`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/tools/get_coverage_and_presence.py) calculates the coverage and presence of protein and nucleic acid residues within the molecular system based on the established residue mappings and reference lengths. This provides a clear understanding of which parts of the biological references are represented in the simulation. The generated metadata, which includes all these characterizations, is consolidated using functions like [`prepare_project_metadata`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/tools/generate_metadata.py#L14) and [`generate_md_metadata`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/tools/generate_metadata.py#L294) in [`/mmb-irb/mddb-workflow/mddb_workflow/tools/generate_metadata.py`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/tools/generate_metadata.py), ensuring that each project and MD simulation is fully annotated with its protein and nucleic acid characteristics.
