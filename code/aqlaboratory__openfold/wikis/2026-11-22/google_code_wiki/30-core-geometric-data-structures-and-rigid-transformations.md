### Core Geometric Data Structures and Rigid Transformations
OpenFold utilizes a suite of PyTorch-based data structures for efficient and batched handling of 3D geometric information, which is fundamental for protein structure representation and manipulation. This includes specialized classes for 3D vectors, rotation matrices, and rigid transformations, enabling advanced operations essential for protein modeling.

The primary geometric data structures are:
*   [`Vec3Array`](https://github.com/aqlaboratory/openfold/openfold/utils/geometry/vector.py#L25): Represents 3D vectors. This class allows for standard vector arithmetic (addition, subtraction, multiplication, division), dot and cross products, and calculates vector norms. It supports both single vectors and batches of vectors, facilitating vectorized computations crucial for neural network processing. The module also provides utilities for calculating [`square_euclidean_distance`](https://github.com/aqlaboratory/openfold/openfold/utils/geometry/vector.py#L174), [`euclidean_distance`](https://github.com/aqlaboratory/openfold/openfold/utils/geometry/vector.py#L214), and [`dihedral_angle`](https://github.com/aqlaboratory/openfold/openfold/utils/geometry/vector.py#L236) between [`Vec3Array`](https://github.com/aqlaboratory/openfold/openfold/utils/geometry/vector.py#L25) instances in [`/aqlaboratory/openfold/openfold/utils/geometry/vector.py`](https://github.com/aqlaboratory/openfold/openfold/utils/geometry/vector.py).
*   [`Rot3Array`](https://github.com/aqlaboratory/openfold/openfold/utils/geometry/rotation_matrix.py#L30): Encapsulates 3x3 rotation matrices. This structure supports matrix multiplication for composing rotations, inversion to find the opposite rotation, and applying rotations to 3D points. It can be constructed from two vectors to define an orthonormal basis, or from quaternions, allowing for flexible representation of 3D rotations in [`/aqlaboratory/openfold/openfold/utils/geometry/rotation_matrix.py`](https://github.com/aqlaboratory/openfold/openfold/utils/geometry/rotation_matrix.py).
*   [`Rigid3Array`](https://github.com/aqlaboratory/openfold/openfold/utils/geometry/rigid_matrix_vector.py#L30): Combines a [`Rot3Array`](https://github.com/aqlaboratory/openfold/openfold/utils/geometry/rotation_matrix.py#L30) and a [`Vec3Array`](https://github.com/aqlaboratory/openfold/openfold/utils/geometry/vector.py#L25) to represent complete 3D rigid transformations, which include both rotation and translation. This class enables transformation composition, inversion, and applying rigid transformations to 3D points. It also supports conversion to and from 4x4 homogeneous matrices, ensuring compatibility with various geometric frameworks in [`/aqlaboratory/openfold/openfold/utils/geometry/rigid_matrix_vector.py`](https://github.com/aqlaboratory/openfold/openfold/utils/geometry/rigid_matrix_vector.py).

These foundational data structures, collectively exposed via [`/aqlaboratory/openfold/openfold/utils/geometry/__init__.py`](https://github.com/aqlaboratory/openfold/openfold/utils/geometry/__init__.py), provide a robust framework for managing and operating on 3D coordinates and orientations within OpenFold. For instance, the [`QuatRigid`](https://github.com/aqlaboratory/openfold/openfold/utils/geometry/quat_rigid.py#L10) module in [`/aqlaboratory/openfold/openfold/utils/geometry/quat_rigid.py`](https://github.com/aqlaboratory/openfold/openfold/utils/geometry/quat_rigid.py) translates neural network activations into [`Rigid3Array`](https://github.com/aqlaboratory/openfold/openfold/utils/geometry/rigid_matrix_vector.py#L30) transformations using quaternion representations for rotation, providing a differentiable interface between model outputs and geometric transformations. This suite of tools underpins the model's ability to iteratively refine and predict protein structures in 3D space. More information on geometric operations and rigid body transformations can be found in [Geometric Operations and Rigid Body Transformations](#protein-structure-prediction-core-geometric-operations-and-rigid-body-transformations).
