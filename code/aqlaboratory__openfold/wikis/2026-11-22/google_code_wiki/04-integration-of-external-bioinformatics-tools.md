### Integration of External Bioinformatics Tools
OpenFold integrates external bioinformatics tools to generate essential features like Multiple Sequence Alignments (MSAs) and template information, which are crucial inputs for protein structure prediction. The primary interface for these tools is located within the [`/aqlaboratory/openfold/openfold/data/tools`](https://github.com/aqlaboratory/openfold/openfold/data/tools) directory, which contains Python wrappers for various binaries.

The [`AlignmentRunner`](https://github.com/aqlaboratory/openfold/openfold/data/data_pipeline.py#L334) class in [`/aqlaboratory/openfold/openfold/data/data_pipeline.py`](https://github.com/aqlaboratory/openfold/openfold/data/data_pipeline.py) orchestrates the execution of these tools. It is configured with paths to the necessary bioinformatics binaries and databases, such as Jackhmmer, HHblits, HHsearch, and HMMsearch. When processing a protein sequence, [`AlignmentRunner`](https://github.com/aqlaboratory/openfold/openfold/data/data_pipeline.py#L334) invokes these tools to perform homology searches against sequence databases, generating MSAs and identifying homologous protein structures that can serve as templates. The raw outputs from these tools are then parsed and converted into a standardized feature format suitable for the prediction model.

The parsing of various bioinformatics file formats, such as FASTA, Stockholm, A3M, and HHR, is handled by utilities in [`/aqlaboratory/openfold/openfold/data/parsers.py`](https://github.com/aqlaboratory/openfold/openfold/data/parsers.py). These parsers convert the raw text outputs from tools like Jackhmmer, HHblits, and HHsearch into structured data representations, such as [`Msa`](https://github.com/aqlaboratory/openfold/openfold/data/parsers.py#L29) objects for MSAs and [`TemplateHit`](https://github.com/aqlaboratory/openfold/openfold/data/parsers.py#L57) objects for identified structural templates. This structured data is then further processed into numerical features by the data pipeline.

For instance, the [`HHBlits`](https://github.com/aqlaboratory/openfold/openfold/data/tools/hhblits.py#L30) class in [`/aqlaboratory/openfold/openfold/data/tools/hhblits.py`](https://github.com/aqlaboratory/openfold/openfold/data/tools/hhblits.py) provides a wrapper for the [`HHblits`](https://github.com/aqlaboratory/openfold/docs/source/index.md#L51) sequence search tool, allowing OpenFold to query protein sequence databases and generate A3M-formatted MSAs. Similarly, the [`HHSearch`](https://github.com/aqlaboratory/openfold/openfold/data/tools/hhsearch.py#L27) class in [`/aqlaboratory/openfold/openfold/data/tools/hhsearch.py`](https://github.com/aqlaboratory/openfold/openfold/data/tools/hhsearch.py) wraps [`hhsearch`](https://github.com/aqlaboratory/openfold/openfold/data/tools/hhsearch.py#L27) for identifying structural templates, while [`Jackhmmer`](https://github.com/aqlaboratory/openfold/openfold/data/tools/jackhmmer.py#L30) in [`/aqlaboratory/openfold/openfold/data/tools/jackhmmer.py`](https://github.com/aqlaboratory/openfold/openfold/data/tools/jackhmmer.py) handles iterative sequence searches. The system also includes wrappers for [`hmmbuild`](https://github.com/aqlaboratory/openfold/openfold/data/tools/hmmbuild.py#L25) in [`/aqlaboratory/openfold/openfold/data/tools/hmmbuild.py`](https://github.com/aqlaboratory/openfold/openfold/data/tools/hmmbuild.py) and [`hmmsearch`](https://github.com/aqlaboratory/openfold/openfold/data/tools/hmmsearch.py#L27) in [`/aqlaboratory/openfold/openfold/data/tools/hmmsearch.py`](https://github.com/aqlaboratory/openfold/openfold/data/tools/hmmsearch.py) for HMM-based searches, and [`Kalign`](https://github.com/aqlaboratory/openfold/openfold/data/tools/kalign.py#L36) in [`/aqlaboratory/openfold/openfold/data/tools/kalign.py`](https://github.com/aqlaboratory/openfold/openfold/data/tools/kalign.py) for multiple sequence alignment.

These wrappers manage the execution of external binaries, handle temporary files for input and output, and capture the results and any errors. This abstraction allows the core data processing pipeline to seamlessly integrate data from these tools without needing to manage their command-line specifics. Further details on how these features are incorporated into the model can be found in [Data Processing and Feature Generation Pipeline](#protein-structure-prediction-core-data-processing-and-feature-generation-pipeline).
