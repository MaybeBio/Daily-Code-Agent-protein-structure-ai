### Geometric and Tensor Operation Utilities
Utilities for geometric and tensor operations provide foundational capabilities for structural bioinformatics models, encompassing functions for aligning 3D point clouds, managing protein component identifiers, and performing rigid transformations.

For instance, the function [`weighted_rigid_align`](https://github.com/rosettacommons/foundry/src/foundry/utils/alignment.py#L8) in [`/rosettacommons/foundry/src/foundry/utils/alignment.py`](https://github.com/rosettacommons/foundry/src/foundry/utils/alignment.py) performs a weighted rigid body alignment of a ground truth 3D point cloud onto another, crucial for comparing or superimposing molecular structures. This involves calculating centroids, forming a weighted covariance matrix, and using Singular Value Decomposition (SVD) to derive a rotation matrix that ensures a proper rotation without reflection. This module also includes [`get_rmsd`](https://github.com/rosettacommons/foundry/src/foundry/utils/alignment.py#L87) for calculating Root Mean Square Deviation between point clouds.

The parsing and validation of protein or molecular component identifiers, often referred to as "contigs," are managed by functions within [`/rosettacommons/foundry/src/foundry/utils/components.py`](https://github.com/rosettacommons/foundry/src/foundry/utils/components.py). These utilities convert contig strings (e.g., "A20-21" or "1-5") into structured representations, enabling the definition of fixed or variable regions in design patterns. Functions such as [`split_contig`](https://github.com/rosettacommons/foundry/src/foundry/utils/components.py#L48), [`extract_pn_unit_info`](https://github.com/rosettacommons/foundry/src/foundry/utils/components.py#L64), and [`get_design_pattern_with_constraints`](https://github.com/rosettacommons/foundry/src/foundry/utils/components.py#L83) facilitate this conversion and validate input formats. Additionally, this module generates atom masks based on these identifiers using functions like [`get_name_mask`](https://github.com/rosettacommons/foundry/src/foundry/utils/components.py#L254) and [`fetch_mask_from_idx`](https://github.com/rosettacommons/foundry/src/foundry/utils/components.py#L352), which are essential for selecting specific parts of an [`AtomArray`](https://github.com/rosettacommons/foundry/examples/all.ipynb#L20).

Core utilities for 3D rigid transformations, including rotations and translations, are centralized in [`/rosettacommons/foundry/src/foundry/utils/rigid.py`](https://github.com/rosettacommons/foundry/src/foundry/utils/rigid.py). This module supports both rotation matrix and quaternion representations, providing low-level [`torch`](https://github.com/rosettacommons/foundry/README.md#L22) tensor operations for numerical stability and GPU acceleration. The [`Rotation`](https://github.com/rosettacommons/foundry/src/foundry/utils/rigid.py#L278) class encapsulates 3D rotations, offering methods for composition, inversion, and application to 3D points. Building upon this, the [`Rigid`](https://github.com/rosettacommons/foundry/src/foundry/utils/rigid.py#L850) class represents a full rigid transformation by combining a [`Rotation`](https://github.com/rosettacommons/foundry/src/foundry/utils/rigid.py#L278) object with a 3D translation vector. It provides analogous methods for composing transformations, applying them to points, and inverting them. The [`from_3_points`](https://github.com/rosettacommons/foundry/src/foundry/utils/rigid.py#L1249) static method is particularly notable for constructing a [`Rigid`](https://github.com/rosettacommons/foundry/src/foundry/utils/rigid.py#L850) transformation from three 3D points, a critical operation for defining local coordinate frames in structural biology.

Geometric augmentation, which involves applying random rotations and translations to batched atom coordinates, is handled by [`/rosettacommons/foundry/src/foundry/utils/rotation_augmentation.py`](https://github.com/rosettacommons/foundry/src/foundry/utils/rotation_augmentation.py). Functions like [`centre_random_augmentation`](https://github.com/rosettacommons/foundry/src/foundry/utils/rotation_augmentation.py#L30) prepare input coordinates by centering them and then apply random transformations, such as [`uniform_random_rotation`](https://github.com/rosettacommons/foundry/src/foundry/utils/rotation_augmentation.py#L37), to introduce diversity in training data or design outputs.

Finally, general PyTorch utilities in [`/rosettacommons/foundry/src/foundry/utils/torch.py`](https://github.com/rosettacommons/foundry/src/foundry/utils/torch.py) support these geometric and tensor operations by providing functions for managing tensor device and data type transfers ([`map_to`](https://github.com/rosettacommons/foundry/src/foundry/utils/torch.py#L27)), asserting tensor properties like shape and the absence of NaN values ([`assert_shape`](https://github.com/rosettacommons/foundry/src/foundry/utils/torch.py#L154), [`_assert_no_nans`](https://github.com/rosettacommons/foundry/src/foundry/utils/torch.py#L93)), and performing scatter-mean aggregations ([`scatter_mean`](https://github.com/rosettacommons/foundry/src/foundry/utils/torch.py#L209)), ensuring robust and efficient tensor manipulation across the framework.
