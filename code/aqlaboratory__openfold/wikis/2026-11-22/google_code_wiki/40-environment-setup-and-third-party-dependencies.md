### Environment Setup and Third-Party Dependencies
The OpenFold repository includes scripts to manage its Conda environment and integrate essential third-party bioinformatics tools. The script [`/aqlaboratory/openfold/scripts/activate_conda_env.sh`](https://github.com/aqlaboratory/openfold/scripts/activate_conda_env.sh), which sources [`scripts/vars.sh`](https://github.com/aqlaboratory/openfold/scripts/activate_conda_env.sh#L3) to define [`ENV_NAME`](https://github.com/aqlaboratory/openfold/scripts/vars.sh#L3), handles the activation of the OpenFold Conda environment by executing [`conda activate $ENV_NAME`](https://github.com/aqlaboratory/openfold/scripts/activate_conda_env.sh#L5). Conversely, [`/aqlaboratory/openfold/scripts/deactivate_conda_env.sh`](https://github.com/aqlaboratory/openfold/scripts/deactivate_conda_env.sh) provides a straightforward way to exit the active Conda environment using [`conda deactivate`](https://github.com/aqlaboratory/openfold/scripts/deactivate_conda_env.sh#L3).

For setting up the necessary external dependencies, [`/aqlaboratory/openfold/scripts/install_third_party_dependencies.sh`](https://github.com/aqlaboratory/openfold/scripts/install_third_party_dependencies.sh) orchestrates the installation of various tools and configurations. This script manages resources such as [`stereo_chemical_props.txt`](https://github.com/aqlaboratory/openfold/setup.py#L133), prepares test data, installs OpenFold itself via [`python setup.py install`](https://github.com/aqlaboratory/openfold/Dockerfile#L10), and clones [`NVIDIA/cutlass`](https://github.com/aqlaboratory/openfold/scripts/install_third_party_dependencies.sh#L17) (specifically version [`v3.6.0`](https://github.com/aqlaboratory/openfold/scripts/install_third_party_dependencies.sh#L17)). It also configures several environment variables critical for performance, including [`CUTLASS_PATH`](https://github.com/aqlaboratory/openfold/scripts/install_third_party_dependencies.sh#L18), [`KMP_AFFINITY`](https://github.com/aqlaboratory/openfold/docs/source/FAQ.md#L30), [`LIBRARY_PATH`](https://github.com/aqlaboratory/openfold/docs/source/Installation.md#L23), and [`LD_LIBRARY_PATH`](https://github.com/aqlaboratory/openfold/Dockerfile#L28). Additionally, [`/aqlaboratory/openfold/scripts/install_hh_suite.sh`](https://github.com/aqlaboratory/openfold/scripts/install_hh_suite.sh) automates the cloning, building, and installation of [`hh-suite`](https://github.com/aqlaboratory/openfold/scripts/install_hh_suite.sh#L3) (branch [`v3.3.0`](https://github.com/aqlaboratory/openfold/scripts/install_hh_suite.sh#L3)) from GitHub, placing it in [`/opt/hhsuite`](https://github.com/aqlaboratory/openfold/scripts/install_hh_suite.sh#L6) and creating necessary symlinks in [`/usr/bin`](https://github.com/aqlaboratory/openfold/train_openfold.py#L522) for system-wide access. This setup ensures that tools like HHblits and HHsearch, which are vital for generating features such as Multiple Sequence Alignments (MSAs), are correctly integrated. More details on how these external tools are used can be found in [Bioinformatics Tool Wrappers](#bioinformatics-tool-wrappers).
