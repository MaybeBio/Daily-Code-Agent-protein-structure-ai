### Specialized AutoCorrelation Functions (VACF and HFACF)
The [`VelocityAutoCorrelation`](https://github.com/torchsim/torch-sim/torch_sim/properties/correlations.py#L392) and [`HeatFluxAutoCorrelation`](https://github.com/torchsim/torch-sim/torch_sim/properties/correlations.py#L479) classes provide specialized tools for analyzing simulation dynamics by calculating their respective time correlation functions. These classes extend the general capabilities of the [General Time Correlation Functions and FFT Acceleration](#simulation-property-calculators-general-time-correlation-functions-and-fft-acceleration) by focusing on specific physical properties.

[`VelocityAutoCorrelation`](https://github.com/torchsim/torch-sim/torch_sim/properties/correlations.py#L392) (found in [`/torchsim/torch-sim/torch_sim/properties/correlations.py`](https://github.com/torchsim/torch-sim/torch_sim/properties/correlations.py)) is designed to compute the velocity autocorrelation function (VACF). It leverages the underlying [`CorrelationCalculator`](https://github.com/torchsim/torch-sim/torch_sim/properties/correlations.py#L100) to track atomic velocities from a simulation state and compute their autocorrelation. This class also supports the accumulation of a running average of the VACF across multiple simulation windows, which is useful for obtaining statistically robust results from molecular dynamics trajectories.

Similarly, [`HeatFluxAutoCorrelation`](https://github.com/torchsim/torch-sim/torch_sim/properties/correlations.py#L479) (also in [`/torchsim/torch-sim/torch_sim/properties/correlations.py`](https://github.com/torchsim/torch-sim/torch_sim/properties/correlations.py)) focuses on the heat flux autocorrelation function (HFACF). This involves a more complex calculation, as the heat flux itself needs to be derived from the model's per-atom stresses and energies. Like the VACF calculator, it utilizes the [`CorrelationCalculator`](https://github.com/torchsim/torch-sim/torch_sim/properties/correlations.py#L100) for its core correlation capabilities and manages a running average of the HFACF. This allows for the efficient determination of thermal transport properties from simulation data.
