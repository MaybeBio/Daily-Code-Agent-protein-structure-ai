### Advanced Physical Property Calculations
Capabilities for calculating advanced physical quantities and properties in atomistic simulations are provided, encompassing elastic tensor computations, Monte Carlo swap simulations, and specialized correlation analysis functions.

Elastic properties of crystal structures can be determined by analyzing their symmetry and applying a series of precisely chosen deformations. The system then computes stresses using a provided model, ultimately deriving elastic constants and moduli from the stress-strain relationships. Functions such as [`get_bravais_type`](https://github.com/torchsim/torch-sim/torch_sim/elastic.py#L55) in [`/torchsim/torch-sim/torch_sim/elastic.py`](https://github.com/torchsim/torch-sim/torch_sim/elastic.py) analyze the lattice parameters and angles of a [`SimState`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L121) to classify the crystal system, which is crucial for applying appropriate symmetry constraints during elastic tensor calculations. [`get_elementary_deformations`](https://github.com/torchsim/torch-sim/torch_sim/elastic.py#L678) then creates [`SimState`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L121) objects representing slightly deformed versions of the crystal, chosen to efficiently sample non-equivalent strain components. The [`calculate_elastic_tensor`](https://github.com/torchsim/torch-sim/torch_sim/elastic.py#L1105) function in [`/torchsim/torch-sim/torch_sim/elastic.py`](https://github.com/torchsim/torch-sim/torch_sim/elastic.py) orchestrates this process, from generating deformations to calculating the full elastic tensor. Finally, [`calculate_elastic_moduli`](https://github.com/torchsim/torch-sim/torch_sim/elastic.py#L1177) computes common elastic moduli (Bulk modulus, Shear modulus, Poisson's ratio, Pugh's ratio) using Voigt-Reuss-Hill averaging from the derived elastic tensor. For a more detailed understanding of the specific algorithms, refer to [Advanced Physical Property Calculations](#atomistic-simulation-engine-core-advanced-physical-property-calculations).

For systems requiring particle exchange or reordering, Monte Carlo (MC) simulations are available. The module [`/torchsim/torch-sim/torch_sim/monte_carlo.py`](https://github.com/torchsim/torch-sim/torch_sim/monte_carlo.py) focuses on swap MC in atomic systems, extending the core [`SimState`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L121) with MC-specific properties. The [`SwapMCState`](https://github.com/torchsim/torch-sim/torch_sim/monte_carlo.py#L37) dataclass manages attributes like system energy and a tensor tracking permutations applied to atoms. The [`generate_swaps`](https://github.com/torchsim/torch-sim/torch_sim/monte_carlo.py#L70) function in [`/torchsim/torch-sim/torch_sim/monte_carlo.py`](https://github.com/torchsim/torch-sim/torch_sim/monte_carlo.py) proposes atom swaps between different types within the same system. The [`metropolis_criterion`](https://github.com/torchsim/torch-sim/torch_sim/monte_carlo.py#L157) function in [`/torchsim/torch-sim/torch_sim/monte_carlo.py`](https://github.com/torchsim/torch-sim/torch_sim/monte_carlo.py) implements the standard Metropolis acceptance criterion, determining whether to accept or reject proposed moves based on energy differences and temperature. The [`swap_mc_step`](https://github.com/torchsim/torch-sim/torch_sim/monte_carlo.py#L240) function in [`/torchsim/torch-sim/torch_sim/monte_carlo.py`](https://github.com/torchsim/torch-sim/torch_sim/monte_carlo.py) advances the simulation by generating and evaluating swaps, ensuring rejected moves are properly reversed. This framework enables the study of phenomena like phase transitions and structural evolution through atom exchanges.

Specialized time correlation functions are provided for in-depth analysis of simulation trajectories. The [`/torchsim/torch-sim/torch_sim/properties`](https://github.com/torchsim/torch-sim/torch_sim/properties) directory offers tools for calculating various correlation properties. The [`CorrelationCalculator`](https://github.com/torchsim/torch-sim/torch_sim/properties/correlations.py#L100) class in [`/torchsim/torch-sim/torch_sim/properties/correlations.py`](https://github.com/torchsim/torch-sim/torch_sim/properties/correlations.py) is designed to compute both auto- and cross-correlation functions for arbitrary simulation properties using efficient FFT-based methods. It tracks multiple properties defined by callable functions and stores historical data in a [`CircularBuffer`](https://github.com/torchsim/torch-sim/torch_sim/properties/correlations.py#L31) for efficient processing. Building upon this, [`VelocityAutoCorrelation`](https://github.com/torchsim/torch-sim/torch_sim/properties/correlations.py#L392) and [`HeatFluxAutoCorrelation`](https://github.com/torchsim/torch-sim/torch_sim/properties/correlations.py#L479) in [`/torchsim/torch-sim/torch_sim/properties/correlations.py`](https://github.com/torchsim/torch-sim/torch_sim/properties/correlations.py) provide specialized functionalities for their respective physical quantities, including the calculation of heat flux and the management of running averages. These tools are crucial for deriving transport coefficients and understanding dynamic behavior from MD simulations.
