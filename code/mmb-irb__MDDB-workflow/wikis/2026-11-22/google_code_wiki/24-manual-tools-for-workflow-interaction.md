## Manual Tools for Workflow Interaction
The [`/mmb-irb/mddb-workflow/manual_tools`](https://github.com/mmb-irb/mddb-workflow/manual_tools) directory contains scripts designed to facilitate direct interaction with the MDDB workflow. These tools bridge the gap between automated workflow execution and user-driven data management, configuration, and analysis.

One aspect involves querying and downloading project-specific data. The [`/mmb-irb/mddb-workflow/manual_tools/api_tools.py`](https://github.com/mmb-irb/mddb-workflow/manual_tools/api_tools.py) script provides utilities for programmatic interaction with a REST API to retrieve project details, manage data, and download associated files such as [`topology.json`](https://github.com/mmb-irb/mddb-workflow/docs/source/usage.rst#L116) directly from the database. This capability supports data integrity and consistent access within the MDDB ecosystem.

For structural manipulation, the [`/mmb-irb/mddb-workflow/manual_tools/chainer.py`](https://github.com/mmb-irb/mddb-workflow/manual_tools/chainer.py) script automates the modification of PDB chain identifiers for specific atom selections. It interacts with [`VMD`](https://github.com/mmb-irb/mddb-workflow/docker/Dockerfile#L10) (Visual Molecular Dynamics) to perform targeted changes and save the modified PDB files. This functionality supports the preparation or re-processing of structural data for MD simulations.

The directory also includes tools for generating workflow input configurations. The [`/mmb-irb/mddb-workflow/manual_tools/inputs_generator_by_pdb.py`](https://github.com/mmb-irb/mddb-workflow/manual_tools/inputs_generator_by_pdb.py) script automates the batch creation of [`inputs.yaml`](https://github.com/mmb-irb/mddb-workflow/test/conftest.py#L90) files, customizing each with a PDB ID derived from the directory name. The [`/mmb-irb/mddb-workflow/manual_tools/inputs_generator.py`](https://github.com/mmb-irb/mddb-workflow/manual_tools/inputs_generator.py) script also exists for generating [`inputs.json`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/utils/constants.py#L67) files that incorporate mutation and ligand details. These generators streamline the setup of new simulation projects by creating standardized configuration files.

Another utility is the [`/mmb-irb/mddb-workflow/manual_tools/logger_and_loader.py`](https://github.com/mmb-irb/mddb-workflow/manual_tools/logger_and_loader.py) script, which processes project accessions to retrieve metadata, log project details, and initiate directory uploads. This tool automates the handling of new projects, fetching information from a database and coordinating the transfer of relevant data.

Finally, the [`/mmb-irb/mddb-workflow/manual_tools/references_updater.py`](https://github.com/mmb-irb/mddb-workflow/manual_tools/references_updater.py) script systematically updates and generates various reference data—including proteins, ligands, PDBs, and chains—by querying external APIs and identifying orphan data. This ensures that the workflow operates with current and consistent reference datasets, supporting the accuracy of MD simulations and analyses. These manual tools provide mechanisms for interaction and data management within the MDDB workflow, supplementing its automated processes.
