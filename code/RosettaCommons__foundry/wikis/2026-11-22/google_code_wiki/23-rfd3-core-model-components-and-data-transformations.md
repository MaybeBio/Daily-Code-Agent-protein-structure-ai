### RFD3 Core Model Components and Data Transformations
The RFdiffusion3 (RFD3) model, implemented primarily within the [`/rosettacommons/foundry/models/rfd3`](https://github.com/rosettacommons/foundry/models/rfd3) directory, is a generative diffusion model designed for *de novo* biomolecular interaction design. At its core, the [`RFD3`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/model/RFD3.py#L19) class in [`/rosettacommons/foundry/models/rfd3/src/rfd3/model/RFD3.py`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/model/RFD3.py) integrates several components: a [`TokenInitializer`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/model/layers/encoders.py#L36) for feature preparation, a [`diffusion_module`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/engine.py#L241) responsible for denoising, and an [`inference_sampler`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/engine.py#L54) ([`ConditionalDiffusionSampler`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/model/inference_sampler.py#L582)) to manage the iterative sampling process during inference. This modular design allows for flexible configuration and clear separation of concerns between input feature generation, the core denoising logic, and the multi-step diffusion sampling. The model supports conditional diffusion, where generation can be guided by input features, and incorporates classifier-free guidance during inference to enhance sample quality.

Neural network building blocks are located in [`/rosettacommons/foundry/models/rfd3/src/rfd3/model/layers`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/model/layers). This collection provides various attention mechanisms, such as [`GatedCrossAttention`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/model/layers/attention.py#L92) and [`LocalAttentionPairBias`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/model/layers/attention.py#L189), which are crucial for processing atomic and token-level features, often incorporating pairwise biases for detailed structural interactions. Feature embedding layers like [`PositionPairDistEmbedder`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/model/layers/blocks.py#L66) and [`OneDFeatureEmbedder`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/model/layers/blocks.py#L116) are used to transform input data, while components like [`Upcast`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/model/layers/blocks.py#L465) and [`Downcast`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/model/layers/blocks.py#L514) manage the conversion between atom-level and token-level representations. For memory efficiency with large structures, specialized modules like [`ChunkedPairwiseEmbedder`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/model/layers/chunked_pairwise.py#L142) perform calculations only on relevant subsets of data. Encoder blocks, such as [`TokenInitializer`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/model/layers/encoders.py#L36) and [`DiffusionTokenEncoder`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/model/layers/encoders.py#L304), refine these features, often integrating diffusion-specific information like distograms. These layers leverage performance optimizations such as activation checkpointing and mixed-precision training.

A comprehensive set of [`Transform`](https://github.com/rosettacommons/foundry/models/rf3/README.md#L453) classes, found in [`/rosettacommons/foundry/models/rfd3/src/rfd3/transforms`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/transforms), handles the preparation of [`AtomArray`](https://github.com/rosettacommons/foundry/examples/all.ipynb#L20) data for both training and inference. These transformations manage conditioning by extracting motif information and setting default annotations via the transforms in [`/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/conditioning_base.py`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/conditioning_base.py). They apply design-specific featurization, such as creating reference features and adding boolean flags ([`is_backbone`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/pipelines.py#L504), [`is_sidechain`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/metrics/losses.py#L104), [`is_virtual`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/metrics/losses.py#L103)) using transforms in [`/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/design_transforms.py`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/design_transforms.py). Hydrogen bond calculations are performed by transforms in [`/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/hbonds.py`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/hbonds.py) and [`/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/hbonds_hbplus.py`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/hbonds_hbplus.py), supporting both Biotite's internal functions and external tools like HBPLUS. Other transformations include cropping for protein-DNA contacts using transforms in [`/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/dna_crop.py`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/dna_crop.py), chirality manipulations using transforms in [`/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/ncaa_transforms.py`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/ncaa_transforms.py), and RASA calculation using transforms in [`/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/rasa.py`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/rasa.py). The [`/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/pipelines.py`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/pipelines.py) module defines how these individual transforms are composed into comprehensive data processing workflows, often applying transformations conditionally based on whether the process is inference or training. For further details on the training process, see [RFD3 Training Pipeline and Conditioning Strategies](#rfdiffusion3-rfd3-for-de-novo-design-rfd3-training-pipeline-and-conditioning-strategies). The inference engine's operation is detailed in [RFD3 Inference and Design Examples](#rfdiffusion3-rfd3-for-de-novo-design-rfd3-inference-and-design-examples).
