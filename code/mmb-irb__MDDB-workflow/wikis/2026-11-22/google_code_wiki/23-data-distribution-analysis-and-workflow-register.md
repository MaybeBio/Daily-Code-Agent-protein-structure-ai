### Data Distribution Analysis and Workflow Register
Specialized tools are provided for analyzing data distributions and tracking workflow metadata. The [`BiBiTransformer`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/utils/bibitransformer_nassa.py#L6) class in [`/mmb-irb/mddb-workflow/mddb_workflow/utils/bibitransformer_nassa.py`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/utils/bibitransformer_nassa.py) is designed to characterize data distributions by assessing binormality and bimodality. It fits both single-component and two-component Gaussian Mixture Models to input data, then compares them using Bayesian Information Criterion (BIC) scores to determine if a distribution is uninormal, binormal, or if there is insufficient evidence to make a classification. For distributions identified as binormal, it further applies a modified Helguero's theorem to assess bimodality. This process aids in understanding the underlying nature of observed data distributions within molecular simulations.

The [`Register`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/utils/register.py#L11) class in [`/mmb-irb/mddb-workflow/mddb_workflow/utils/register.py`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/utils/register.py) manages workflow execution history and metadata. It tracks the outcomes of tests, captures and deduplicates warnings, and stores relevant workflow metadata such as command-line arguments, execution time, date, and project version. The [`Register`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/utils/register.py#L11) class persists its state to a JSON file, and upon initialization, it can load results from previous runs to maintain a continuous record of workflow activities. This functionality helps ensure reproducibility and provides a traceable history of operations and potential issues encountered during workflow execution.
