## Biological Resources
The [`mddb-workflow`](https://github.com/mmb-irb/mddb-workflow/README.md#L4) repository includes a [`resources`](https://github.com/mmb-irb/mddb-workflow/README.md#L4) directory for managing biological sequence data and processing scientific output files. This directory primarily serves two functions: providing curated biological sequence data, specifically for SARS-CoV-2 variants, and offering tools for processing and summarizing specific types of scientific output.

The module [`/mmb-irb/mddb-workflow/mddb_workflow/resources/covid_variants.py`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/resources/covid_variants.py) contains a curated collection of SARS-CoV-2 spike protein amino acid sequences. These sequences, organized in a dictionary ([`covid_spike_variants`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/resources/covid_variants.py#L4)), allow for quick retrieval of specific variant sequences (e.g., Wild Type, Alpha, Delta, Omicron) for research and analysis purposes. This resource is valuable for studies requiring precise genetic information on different SARS-CoV-2 strains.

Another utility in this section, [`/mmb-irb/mddb-workflow/mddb_workflow/resources/get_energies_sum.py`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/resources/get_energies_sum.py), processes output files from the CMIP tool. It extracts and aggregates energy components, specifically van der Waals and electrostatic energies, to provide a summarized view of interaction energies. This tool is designed to parse structured output, sum relevant energy values, and handle potential "infinity" values by filtering them out, thereby providing a numerical summary suitable for further analysis.
