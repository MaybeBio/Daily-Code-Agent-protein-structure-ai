### Distributed Training Utilities and Logging
Utilities are available for setting up and managing Distributed Data Parallel (DDP) environments, including functions to determine the current process rank and check if it is the rank-zero process. The function [`set_accelerator_based_on_availability`](https://github.com/rosettacommons/foundry/src/foundry/utils/ddp.py#L22) in [`/rosettacommons/foundry/src/foundry/utils/ddp.py`](https://github.com/rosettacommons/foundry/src/foundry/utils/ddp.py) automatically configures the accelerator settings within a training configuration based on available hardware, such as CUDA GPUs, Intel XPUs, or Apple MPS, ensuring appropriate [`accelerator`](https://github.com/rosettacommons/foundry/README.md#L40), [`devices_per_node`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/engine.py#L79), and [`num_nodes`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/engine.py#L78) are set. Additionally, a [`RankedLogger`](https://github.com/rosettacommons/foundry/src/foundry/utils/ddp.py#L58) is provided for DDP-aware logging, which prefixes log messages with the current process's rank and supports rank-zero-only logging, preventing redundant output in distributed setups. See [Foundry Core Library and ML Workflows](#foundry-core-library-and-ml-workflows) for additional details.
