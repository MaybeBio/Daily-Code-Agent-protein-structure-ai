### Intermolecular and Intramolecular Interaction Analyses
This section describes the analysis of various interactions within molecular dynamics (MD) simulations, including inter-residue distances, hydrogen bonding, and detailed interaction energies between agents.

Inter-residue distance analysis is handled by the [`distance_per_residue`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/analyses/distance_per_residue.py#L22) function in [`/mmb-irb/mddb-workflow/mddb_workflow/analyses/distance_per_residue.py`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/analyses/distance_per_residue.py). This function quantifies the spatial proximity between pairs of residues belonging to different interacting agents. It leverages [`pytraj`](https://github.com/mmb-irb/mddb-workflow/envs/environment.yml#L10) to efficiently calculate pairwise distances across the trajectory, computing both mean and standard deviation. To manage large datasets, it employs a reduction strategy where, if the number of calculated distances exceeds a predefined limit, the analysis is constrained to interface residues only. The results, including statistical summaries, are stored in JSON format for easy downstream processing.

Hydrogen bond analysis is performed by the [`hydrogen_bonds`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/analyses/hydrogen_bonds.py#L26) function in [`/mmb-irb/mddb-workflow/mddb_workflow/analyses/hydrogen_bonds.py`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/analyses/hydrogen_bonds.py). This module identifies and quantifies hydrogen bonds formed between specified molecular interfaces over the course of an MD simulation. It utilizes [`pytraj`](https://github.com/mmb-irb/mddb-workflow/envs/environment.yml#L10)'s hydrogen bond calculation capabilities to detect these interactions and then processes the results to focus on inter-agent hydrogen bonds, excluding those occurring within the same agent. The analysis accounts for [`pytraj`](https://github.com/mmb-irb/mddb-workflow/envs/environment.yml#L10)'s residue numbering schemes and can optionally incorporate population weighting and time-dependent analysis. To mitigate storage issues for extensive trajectories, the analysis typically focuses on a subset of frames.

Interaction energy calculations are conducted by the [`energies`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/analyses/energies.py#L45) function in [`/mmb-irb/mddb-workflow/mddb_workflow/analyses/energies.py`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/analyses/energies.py). This function uses the [`CMIP`](https://github.com/mmb-irb/mddb-workflow/envs/environment.yml#L14) (Classical Molecular Interaction Potential) tool to determine electrostatic and Van der Waals interaction energies between specified agents. The process involves preparing [`CMIP`](https://github.com/mmb-irb/mddb-workflow/envs/environment.yml#L14)-specific PDB input files that include atomic charges and "dummy" atoms (representing regions with low dielectric or atoms involved in strong bonds to prevent energy spikes). It dynamically adapts [`CMIP`](https://github.com/mmb-irb/mddb-workflow/envs/environment.yml#L14)'s grid parameters to ensure accurate and memory-efficient calculations, even for large systems, by preventing [`CMIP`](https://github.com/mmb-irb/mddb-workflow/envs/environment.yml#L14) failures related to atom limits or grid point limits. The function iterates through trajectory frames, extracts per-atom energies from [`CMIP`](https://github.com/mmb-irb/mddb-workflow/envs/environment.yml#L14) output, and then averages these energies over the entire trajectory, providing initial and final frame averages for various energy components. A debugging mode is available to generate [`CMIP`](https://github.com/mmb-irb/mddb-workflow/envs/environment.yml#L14) command lines for manual inspection.

Dihedral energy calculations are carried out by [`compute_dihedral_energies`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/analyses/dihedral_energies.py#L10) in [`/mmb-irb/mddb-workflow/mddb_workflow/analyses/dihedral_energies.py`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/analyses/dihedral_energies.py). This function computes torsion, electrostatic (EE), and Van der Waals (VDW) energies for specified dihedrals along an MD trajectory. It can reduce the trajectory size for performance and memory management. The calculations involve summing the energy of individual torsion terms and using Coulombic and Lennard-Jones potentials for EE and VDW energies, respectively. The averaged dihedral energies are saved in a JSON file.

Finally, lipid-protein interactions are analyzed by the [`lipid_interactions`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/analyses/lipid_interactions.py#L12) function in [`/mmb-irb/mddb-workflow/mddb_workflow/analyses/lipid_interactions.py`](https://github.com/mmb-irb/mddb-workflow/mddb_workflow/analyses/lipid_interactions.py). This module classifies and quantifies contacts between lipid molecules (categorized by head and tail parts) and protein residues. It supports atomistic, united-atom, and coarse-grained representations by dynamically selecting the appropriate analysis method. The process involves parallel computation across trajectory frames to detect contacts within a specified distance, accumulating contact events, and normalizing them by the total number of frames to derive interaction probabilities. The results are stored in JSON format and can be visualized. For a broader overview of analysis capabilities, refer to the [Comprehensive MD Analysis Suite](#md-simulation-data-lifecycle-and-analysis-comprehensive-md-analysis-suite).
