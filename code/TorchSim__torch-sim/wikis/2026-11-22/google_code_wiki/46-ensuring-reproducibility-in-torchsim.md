### Ensuring Reproducibility in TorchSim
Achieving deterministic behavior in molecular dynamics simulations within TorchSim requires careful management of random number generation and system states, especially given the presence of stochastic integrators and potential non-deterministic GPU operations. While exact reproducibility is not always critical for tasks focused on sampling and ensemble statistics, it becomes essential when repeatable trajectories are desired, for instance, during debugging or when comparing specific simulation runs.

TorchSim provides mechanisms to ensure determinism by requiring explicit seeding of the [`SimState`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L121). Unlike global PyTorch seeding mechanisms, TorchSim internally uses an explicit [`torch.Generator()`](https://github.com/torchsim/torch-sim/docs/user/reproducibility.md#L44) in [`SimState.rng`](https://github.com/torchsim/torch-sim/docs/user/reproducibility.md#L44), which is independent of the global seed. Therefore, users must explicitly seed their [`SimState`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L121) via [`sim_state.rng = 42`](https://github.com/torchsim/torch-sim/torch_sim/testing.py#L18) to ensure deterministic trajectories. This is particularly important for stochastic integrators, such as [`ts.Integrator.nvt_langevin`](https://github.com/torchsim/torch-sim/README.md#L61) and [`ts.Integrator.npt_langevin_anisotropic`](https://github.com/torchsim/torch-sim/docs/user/reproducibility.md#L53), which incorporate random terms but will produce identical trajectories when [`state.rng`](https://github.com/torchsim/torch-sim/torch_sim/integrators/npt.py#L37) is consistently seeded. For algorithmically deterministic integrators, like [`ts.Integrator.nvt_nose_hoover`](https://github.com/torchsim/torch-sim/docs/user/reproducibility.md#L56) and [`ts.Integrator.nve`](https://github.com/torchsim/torch-sim/docs/user/reproducibility.md#L56), explicit seeding is not required for their inherent operations, as they do not introduce stochastic terms.

When performing batched simulations, reproducibility also depends on the batch composition. Since all systems in a batch share a single [`torch.Generator`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L40), maintaining identical batch composition—meaning the same systems in the same order—is necessary for exact reproducibility. Any changes to the batch composition will alter the consumption of random numbers and lead to divergence in trajectories.

For reproducible restarts, the complete simulation state, including the [`torch.Generator`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L40)'s state, must be serialized and reloaded. While a simple [`torch.save`](https://github.com/torchsim/torch-sim/docs/user/reproducibility.md#L84) of the full state dictionary might work for [`torch.Generator`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L40) objects in recent PyTorch versions (with [`weights_only=False`](https://github.com/torchsim/torch-sim/docs/user/reproducibility.md#L93)), a more robust and portable method involves saving the RNG state as a plain [`uint8`](https://github.com/torchsim/torch-sim/docs/user/reproducibility.md#L99) tensor using [`get_state`](https://github.com/torchsim/torch-sim/torch_sim/trajectory.py#L1202) and restoring it by creating a new [`torch.Generator`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L40) and setting its state with [`set_state`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L54). This approach avoids potential pickle incompatibilities across different PyTorch versions. A complete example demonstrating this process can be found in [`/torchsim/torch-sim/examples/tutorials/reproducible_restart_tutorial.py`](https://github.com/torchsim/torch-sim/examples/tutorials/reproducible_restart_tutorial.py). Further details on global deterministic setup in PyTorch, including environment variables and seeding of various random number generators, are outlined in [`/torchsim/torch-sim/docs/user/reproducibility.md`](https://github.com/torchsim/torch-sim/docs/user/reproducibility.md). A broader overview of TorchSim's core concepts, including its state management and auto-batching, is available in [User Guide to Core Concepts](#user-guide-to-core-concepts).
