### Alchemiops Neighbor List Implementation
The [`alchemiops_nl_n2`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/alchemiops.py#L35) implementation within [`torch-sim`](https://github.com/torchsim/torch-sim/README.md#L3) leverages NVIDIA's [`nvalchemiops`](https://github.com/torchsim/torch-sim/torch_sim/autobatching.py#L42) library to accelerate neighbor list computations, particularly for GPU environments. This approach is part of the system's strategy to prioritize high-performance, hardware-accelerated solutions for neighbor list generation, as outlined in [Automatic Fallback and Prioritization](#neighbor-list-algorithms-automatic-fallback-and-prioritization).

This implementation provides [`torch-sim`](https://github.com/torchsim/torch-sim/README.md#L3) with the capability to perform N² (naive) or cell-list based neighbor searches efficiently, handling batched systems with varying atom counts and supporting periodic boundary conditions. The function accepts atomic [`positions`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L177), [`cell`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L179) vectors, [`pbc`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L180) flags, a [`cutoff`](https://github.com/torchsim/torch-sim/examples/scripts/7_others.py#L56) distance, and [`system_idx`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L182) to manage atom ownership in batched scenarios. It returns a mapping of atom pairs, their corresponding system assignments, and the periodic shift indices required to bring neighbors into the primary image of central atoms.

A key aspect of its integration is the handling of self-interactions; [`nvalchemiops`](https://github.com/torchsim/torch-sim/torch_sim/autobatching.py#L42) typically excludes these by default, so [`alchemiops_nl_n2`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/alchemiops.py#L35) explicitly adds self-pairs to the output if the [`self_interaction`](https://github.com/torchsim/torch-sim/examples/scripts/7_others.py#L57) flag is set to [`True`](https://github.com/torchsim/torch-sim/README.md#L46). Furthermore, the implementation includes specific logic to address how [`nvalchemiops`](https://github.com/torchsim/torch-sim/torch_sim/autobatching.py#L42) handles non-periodic systems with zero cell vectors. In such cases, it temporarily substitutes a nominal identity matrix for the zero cell to prevent potential errors within the [`nvalchemiops`](https://github.com/torchsim/torch-sim/torch_sim/autobatching.py#L42) warp kernels, demonstrating robustness in diverse simulation setups. Input normalization is performed using utilities like [`normalize_inputs`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/utils.py#L7) found in [`/torchsim/torch-sim/torch_sim/neighbors/utils.py`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/utils.py) to ensure consistent tensor shapes for [`cell`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L179) and [`pbc`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L180) across [`nvalchemiops`](https://github.com/torchsim/torch-sim/torch_sim/autobatching.py#L42) calls.
