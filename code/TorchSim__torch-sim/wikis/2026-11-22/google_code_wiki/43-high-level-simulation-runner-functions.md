### High-Level Simulation Runner Functions
TorchSim provides high-level runner functions—[`integrate`](https://github.com/torchsim/torch-sim/torch_sim/runners.py#L317), [`optimize`](https://github.com/torchsim/torch-sim/torch_sim/runners.py#L638), and [`static`](https://github.com/torchsim/torch-sim/torch_sim/runners.py#L844)—designed to orchestrate various atomistic simulations. These functions serve as a unified interface for conducting molecular dynamics (MD) simulations, geometry optimizations, and single-point calculations, respectively. They are built upon TorchSim's modular functional architecture, which employs specialized [`init`](https://github.com/torchsim/torch-sim/CHANGELOG.md#L271) and [`update`](https://github.com/torchsim/torch-sim/torch_sim/properties/correlations.py#L179) functions that operate on unique [`State`](https://github.com/torchsim/torch-sim/docs/user/overview.md#L10) objects, ultimately inheriting from [`SimState`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L121) [Core Simulation State Management](#atomistic-simulation-engine-core-core-simulation-state-management).

The [`integrate`](https://github.com/torchsim/torch-sim/torch_sim/runners.py#L317) function is primarily used for MD simulations, enabling the propagation of atomic systems through time using various integrators, such as those for the NVE, NVT, and NPT ensembles [Simulation Integrators](#simulation-integrators). For instance, it can handle Langevin dynamics or Nose-Hoover chains, as described in [NVT Integrator Implementations](#simulation-integrators-nvt-integrator-implementations), or NPT barostats [NPT Integrator Implementations](#simulation-integrators-npt-integrator-implementations). The [`optimize`](https://github.com/torchsim/torch-sim/torch_sim/runners.py#L638) function is tailored for geometry optimizations, supporting algorithms like Gradient Descent, BFGS, L-BFGS, and FIRE to find stable atomic configurations [Geometry Optimization Algorithms](#geometry-optimization-algorithms). The [`static`](https://github.com/torchsim/torch-sim/torch_sim/runners.py#L844) function, on the other hand, performs single-point calculations, evaluating energy, forces, and other properties for a given atomic structure without time evolution or optimization.

These high-level runners share a consistent interface, supporting a diverse range of models for energy, force, and stress calculations, including classical potentials and wrappers for external machine learning potentials [Model Implementations and Integration](#model-implementations-and-integration). They also facilitate compatibility with external I/O formats, ensuring interoperability with other simulation tools. A key feature is their support for automatic batching, which efficiently manages GPU memory and optimizes computations for varying system sizes and model complexities [Autobatching Mechanisms](#atomistic-simulation-engine-core-autobatching-mechanisms). This allows for processing multiple simulation states concurrently, improving computational throughput. Additionally, these runners are integrated with [`TorchSimTrajectory`](https://github.com/torchsim/torch-sim/torch_sim/trajectory.py#L561) for efficient trajectory reporting, storing simulation data in an [`HDF5`](https://github.com/torchsim/torch-sim/docs/user/overview.md#L24)-based format that supports binary encoding and on-the-fly compression [Trajectory Reporting with `TorchSimTrajectory`](#user-guide-to-core-concepts-trajectory-reporting-with-torchsimtrajectory). All calculations performed by these runners adhere to the [`metal`](https://github.com/torchsim/torch-sim/torch_sim/units.py#L150) unit system. Further details on their operation and best practices can be found in [`/torchsim/torch-sim/docs/user/overview.md`](https://github.com/torchsim/torch-sim/docs/user/overview.md). For information regarding achieving deterministic behavior in simulations using these runners, refer to [Ensuring Reproducibility in TorchSim](#user-guide-to-core-concepts-ensuring-reproducibility-in-torchsim).
