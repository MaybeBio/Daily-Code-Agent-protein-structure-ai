This module contains methods for calculating the distance between two configurations as well as the distances between 
multiple configurations.  The functionality within this module is used in both the [mapping](https://github.com/plumed/plumed2/blob/HEAD/src/refdist/module_mapping.md) and 
[dimred](https://github.com/plumed/plumed2/blob/HEAD/src/refdist/module_dimred.md) modules.
