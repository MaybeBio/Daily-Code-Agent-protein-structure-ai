### Reference Data Updates and Management
The [`updater`](https://github.com/mmb-irb/mddb-workflow/manual_tools/references_updater.py#L32) function, located in [`/mmb-irb/mddb-workflow/manual_tools/references_updater.py`](https://github.com/mmb-irb/mddb-workflow/manual_tools/references_updater.py), automates the process of generating and updating various types of reference data, including proteins, ligands, PDB entries, and chains. This tool maintains up-to-date biological and structural information used throughout the MDDB workflow.

The core functionality of the script orchestrates the retrieval of project options from a configured database API and then fetches existing reference data. A key aspect of its design is the identification of "orphan" data; it distinguishes between project IDs that lack corresponding references and references that are no longer associated with any active projects. This mechanism helps ensure data consistency and prevents the accumulation of stale entries.

Based on the specified reference type (e.g., proteins, PDBs, chains), the [`updater`](https://github.com/mmb-irb/mddb-workflow/manual_tools/references_updater.py#L32) function invokes specialized sub-functions. For protein references, it retrieves fresh data from external sources and intelligently merges it with custom fields from older entries, preserving curated information. For chains, it interacts with external services like InterProScan, submitting sequences for analysis in batches and subsequently integrating the results. All processed and updated reference data are then saved into structured JSON files, making them readily accessible for other components of the workflow. This systematic approach ensures that the MDDB workflow operates with accurate and current reference information.
