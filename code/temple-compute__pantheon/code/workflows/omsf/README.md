# OMSF: Open Molecular Software Foundation workflows

Native Horus ports of selected workflows from the [OMSF workflow directory](https://directory.omsf.io/workflows/), covering [Open Force Field](https://openforcefield.org), [Open Free Energy](https://openfree.energy) and [OpenADMET](https://openadmet.org).

## Workflows

| # | Directory | Workflow | Upstream |
|---|---|---|---|

| 02 | [w02-openadmet-cyp3a4](https://github.com/temple-compute/pantheon/blob/HEAD/workflows/omsf/w02-openadmet-cyp3a4) | OpenADMET CYP3A4 Inhibition Models | [OpenADMET/openadmet-demos](https://github.com/OpenADMET/openadmet-demos) (Apache-2.0) |
