### Auxiliary Simulation Functionalities
This section covers the auxiliary functions that support the core atomistic simulation engine, providing capabilities for managing simulation constraints, facilitating data exchange with external atomistic simulation packages, and offering specialized mathematical operations for tensor manipulation.

The constraint system, defined in [`/torchsim/torch-sim/torch_sim/constraints.py`](https://github.com/torchsim/torch-sim/torch_sim/constraints.py), allows for the application of various restrictions on atomic systems during simulations. This includes [`FixAtoms`](https://github.com/torchsim/torch-sim/torch_sim/constraints.py#L444), which keeps specific atoms stationary, [`FixCom`](https://github.com/torchsim/torch-sim/torch_sim/constraints.py#L522), which maintains the center of mass for a system, and [`FixSymmetry`](https://github.com/torchsim/torch-sim/torch_sim/constraints.py#L777), which preserves the spacegroup symmetry of a crystal structure. These constraints influence how forces, momenta, and positions are adjusted during simulation steps, enabling the study of systems under specific physical conditions. For example, [`FixSymmetry`](https://github.com/torchsim/torch-sim/torch_sim/constraints.py#L777) can be initialized from a [`SimState`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L121) to refine its symmetry using external tools, then used to symmetrize forces, positions, and stress tensors during optimization or dynamics. The system handles constraints in a batched manner and includes utilities like [`merge_constraints`](https://github.com/torchsim/torch-sim/torch_sim/constraints.py#L403) for combining constraints from multiple states and [`validate_constraints`](https://github.com/torchsim/torch-sim/torch_sim/constraints.py#L714) for ensuring their proper configuration.

For interoperability with other atomistic software, the I/O module ([`/torchsim/torch-sim/torch_sim/io.py`](https://github.com/torchsim/torch-sim/torch_sim/io.py)) provides conversion functions between [`ts.SimState`](https://github.com/torchsim/torch-sim/torch_sim/io.py#L40) objects and representations from packages such as ASE ([`atoms_to_state`](https://github.com/torchsim/torch-sim/torch_sim/io.py#L259), [`state_to_atoms`](https://github.com/torchsim/torch-sim/torch_sim/io.py#L39)), Pymatgen ([`structures_to_state`](https://github.com/torchsim/torch-sim/torch_sim/io.py#L363), [`state_to_structures`](https://github.com/torchsim/torch-sim/torch_sim/io.py#L126)), and Phonopy ([`phonopy_to_state`](https://github.com/torchsim/torch-sim/torch_sim/io.py#L449), [`state_to_phonopy`](https://github.com/torchsim/torch-sim/torch_sim/io.py#L202)). These functions facilitate the import and export of structural data, including atomic positions, cell parameters, and periodic boundary conditions, often handling additional system- or atom-specific metadata. This ensures that [`torch-sim`](https://github.com/torchsim/torch-sim/README.md#L3) can easily integrate into existing computational workflows that rely on these established libraries.

Advanced mathematical utilities, particularly for matrix operations, are crucial for many physics-based calculations within the engine. The [`/torchsim/torch-sim/torch_sim/math.py`](https://github.com/torchsim/torch-sim/torch_sim/math.py) module offers specialized functions like [`expm_frechet`](https://github.com/torchsim/torch-sim/torch_sim/math.py#L30) for computing the Fréchet derivative of the matrix exponential, which is essential in certain optimization and integration schemes. It also includes [`matrix_log_33`](https://github.com/torchsim/torch-sim/torch_sim/math.py#L707) for calculating the matrix logarithm of 3x3 matrices, which is optimized for numerical stability by using analytical solutions based on eigenvalue cases. This module also provides a fallback to [`scipy.linalg.logm`](https://github.com/torchsim/torch-sim/torch_sim/math.py#L676) for more complex cases. These mathematical tools leverage PyTorch's tensor capabilities for GPU acceleration and efficient batched computation, supporting complex transformations and analyses within atomistic simulations.
