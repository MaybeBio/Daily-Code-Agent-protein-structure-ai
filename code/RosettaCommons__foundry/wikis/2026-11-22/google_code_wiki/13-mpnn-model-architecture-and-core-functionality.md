### MPNN Model Architecture and Core Functionality
The Foundry [`ProteinMPNN`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/mpnn.py#L21), [`LigandMPNN`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/mpnn.py#L2303), and [`SolubleMPNN`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/mpnn.py#L2173) models employ a graph neural network architecture to design biomolecular sequences based on three-dimensional structural information. The core functionality, primarily embodied by the [`ProteinMPNN`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/mpnn.py#L21) class located in [`/rosettacommons/foundry/models/mpnn/src/mpnn/model/mpnn.py`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/mpnn.py), centers on representing biological structures as graphs, processing these graphs through message passing, and then decoding them into amino acid or ligand sequences.

This architecture begins with **graph featurization**, where input structures are converted into numerical representations suitable for the neural network. This involves extracting a variety of features, including 3D coordinates of atoms, pairwise distances between residues or atoms, and radial basis function (RBF) embeddings that capture geometric relationships. These featurization methods are primarily defined in modules like [`/rosettacommons/foundry/models/mpnn/src/mpnn/model/layers/graph_embeddings.py`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/layers/graph_embeddings.py). Specialized feature extraction caters to different scenarios, such as incorporating membrane information, Position-Specific Scoring Matrix (PSSM) data, or detailed protein-ligand interaction features, by extending the base [`ProteinFeatures`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/layers/graph_embeddings.py#L11) class.

Following featurization, **message passing layers** propagate information across the graph. These layers, implemented as [`EncLayer`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/layers/message_passing.py#L114) (encoder) and [`DecLayer`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/layers/message_passing.py#L227) (decoder) in [`/rosettacommons/foundry/models/mpnn/src/mpnn/model/layers/message_passing.py`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/layers/message_passing.py), iteratively update the hidden states of both nodes (representing residues or atoms) and edges (representing interactions between them). These updates are facilitated by helper functions that gather and concatenate features from neighboring nodes and edges, allowing the model to integrate local structural context. Nonlinear transformations within these layers are typically performed by [`PositionWiseFeedForward`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/layers/position_wise_feed_forward.py#L5) networks, defined in [`/rosettacommons/foundry/models/mpnn/src/mpnn/model/layers/position_wise_feed_forward.py`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/layers/position_wise_feed_forward.py).

**Positional encoding** is crucial for providing the model with information about the relative positions of residues within and between polymer chains. The [`PositionalEncodings`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/layers/positional_encoding.py#L5) class in [`/rosettacommons/foundry/models/mpnn/src/mpnn/model/layers/positional_encoding.py`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/layers/positional_encoding.py) generates learned embeddings from pairwise residue offsets and chain identity masks. This enables the model to distinguish between interactions within the same chain versus those between different chains, a fundamental aspect of biomolecular structure.

Finally, the models employ **decoding strategies** to predict sequences. During training, a "teacher-forcing" approach can be used, where the model is guided by the true sequence. For inference, an "autoregressive" decoding strategy is often employed, where residues are predicted iteratively, building the sequence one by one. The [`ProteinMPNN`](https://github.com/rosettacommons/foundry/models/mpnn/src/mpnn/model/mpnn.py#L21) class orchestrates these steps, including managing causality masks that control the flow of information during the decoding process and converting raw model outputs into sampled sequences. The inference engine then handles loading these models and applying them to new structural inputs. See [MPNN Inference Engine and Evaluation Metrics](#protein-and-ligand-inverse-folding-mpnn-mpnn-inference-engine-and-evaluation-metrics) for more details.
