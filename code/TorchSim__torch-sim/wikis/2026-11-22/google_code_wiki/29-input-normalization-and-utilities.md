### Input Normalization and Utilities
The [`normalize_inputs`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/utils.py#L7) utility in [`/torchsim/torch-sim/torch_sim/neighbors/utils.py`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/utils.py) standardizes the format of simulation cell ([`cell`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L179)) and periodic boundary condition ([`pbc`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L180)) tensors. This function is essential for ensuring consistent input handling across different neighbor list implementations, especially when dealing with batched atomic systems. It prepares these tensors into a uniform [`[n_systems, 3, 3]`](https://github.com/torchsim/torch-sim/torch_sim/transforms.py#L27) shape for [`cell`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L179) and [`[n_systems, 3]`](https://github.com/torchsim/torch-sim/torch_sim/transforms.py#L27) for [`pbc`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L180), regardless of their initial input dimensions (e.g., single-system [`[3, 3]`](https://github.com/torchsim/torch-sim/torch_sim/state.py#L141) or [`[3]`](https://github.com/torchsim/torch-sim/torch_sim/elastic.py#L790) inputs, or flattened [`[n_systems*3, 3]`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/utils.py#L13) inputs). This normalization step is critical for robust operations within various neighbor list algorithms, ensuring that they receive data in an expected and efficient structure. The function is decorated with [`@torch.jit.script`](https://github.com/torchsim/torch-sim/torch_sim/math.py#L12) for potential performance benefits and TorchScript compatibility.
