# All crates

There are more *hoomd-rs* crates not highlighted in this user guide.
Here are links to the documentation for every *hoomd-rs* crate:

- [hoomd-bevy](https://github.com/glotzerlab/hoomd-rs/blob/HEAD/doc/src/api/hoomd_bevy/index.html): Facilitate visual, interactive simulations.
- [hoomd-gsd](https://github.com/glotzerlab/hoomd-rs/blob/HEAD/doc/src/api/hoomd_gsd/index.html): Read and write GSD files.
- [hoomd-geometry](https://github.com/glotzerlab/hoomd-rs/blob/HEAD/doc/src/api/hoomd_geometry/index.html): Define geometric shapes and operate on them.
- [hoomd-interaction](https://github.com/glotzerlab/hoomd-rs/blob/HEAD/doc/src/api/hoomd_interaction/index.html): Define interaction models and apply them to the system's microstate.
- [hoomd-linear-algebra](https://github.com/glotzerlab/hoomd-rs/blob/HEAD/doc/src/api/hoomd_linear_algebra/index.html): Linear algebra methods used by other *hoomd-rs* crates.
- [hoomd-manifold](https://github.com/glotzerlab/hoomd-rs/blob/HEAD/doc/src/api/hoomd_manifold/index.html): Define points in curved space and operate on them.
- [hoomd-mc](https://github.com/glotzerlab/hoomd-rs/blob/HEAD/doc/src/api/hoomd_mc/index.html): Perform Monte Carlo simulations.
- [hoomd-md](https://github.com/glotzerlab/hoomd-rs/blob/HEAD/doc/src/api/hoomd_md/index.html): Perform molecular dynamics simulations.
- [hoomd-microstate](https://github.com/glotzerlab/hoomd-rs/blob/HEAD/doc/src/api/hoomd_microstate/index.html): Represent the degrees of freedom in your simulation model.
- [hoomd-order](https://github.com/glotzerlab/hoomd-rs/blob/HEAD/doc/src/api/hoomd_order/index.html): Compute order parameters on the microstate.
- [hoomd-rand](https://github.com/glotzerlab/hoomd-rs/blob/HEAD/doc/src/api/hoomd_rand/index.html): Pseudorandom number generation methods used by other *hoomd-rs* crates.
- [hoomd-simulation](https://github.com/glotzerlab/hoomd-rs/blob/HEAD/doc/src/api/hoomd_simulation/index.html): Traits that define the macrostate and the simulation model as a whole.
- [hoomd-spatial](https://github.com/glotzerlab/hoomd-rs/blob/HEAD/doc/src/api/hoomd_spatial/index.html): Spatial data structures for efficient site-site interaction computations.
- [hoomd-utility](https://github.com/glotzerlab/hoomd-rs/blob/HEAD/doc/src/api/hoomd_utility/index.html): Miscellaneous data types used throughout *hoomd-rs*.
- [hoomd-vector](https://github.com/glotzerlab/hoomd-rs/blob/HEAD/doc/src/api/hoomd_vector/index.html): Vector and rotation data types and operations.
- [hoomd-workspace](https://github.com/glotzerlab/hoomd-rs/blob/HEAD/doc/src/api/hoomd_workspace/index.html): Operate on *signac* workspaces in Rust.
