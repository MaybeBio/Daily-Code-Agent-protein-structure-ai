## Experimentation and Model Evaluation
The OpenFold framework includes a dedicated component within [`/aqlaboratory/openfold/experiments`](https://github.com/aqlaboratory/openfold/experiments) for evaluating protein structure prediction models. This framework facilitates the assessment of prediction accuracy by comparing generated protein structures (decoys) against known native structures. This involves processing input PDB files as templates for the OpenFold model, calculating structural similarity metrics, and systematically storing the experimental results.

At its core, the evaluation process leverages the [`/aqlaboratory/openfold/experiments/test_templates_openfold.py`](https://github.com/aqlaboratory/openfold/experiments/test_templates_openfold.py) script to manage the workflow. This script orchestrates the generation of protein structure predictions using the OpenFold model, often employing existing decoy structures as templates. Following prediction, the script performs a comparative analysis of the predicted structures against native structures to quantify their accuracy.

A key aspect of this evaluation is the generation of features from protein data. When structural templates are not available, placeholder features are generated by [`empty_placeholder_template_features`](https://github.com/aqlaboratory/openfold/experiments/test_templates_openfold.py#L123). If ESM1b embeddings are utilized, [`make_embedding_features`](https://github.com/aqlaboratory/openfold/experiments/test_templates_openfold.py#L137) loads these from a specified directory. All these components are integrated by [`make_processed_feature_dict`](https://github.com/aqlaboratory/openfold/experiments/test_templates_openfold.py#L155), which combines sequence, Multiple Sequence Alignment (MSA), and template features to prepare the comprehensive feature dictionary required by OpenFold. The [`score_decoy`](https://github.com/aqlaboratory/openfold/experiments/test_templates_openfold.py#L217) function is central to this process, as it prepares template features from a given decoy, executes the OpenFold model for prediction, and subsequently parses the results.

To quantify the similarity between predicted and native structures, the framework employs specific metrics. [`jnp_rmsd`](https://github.com/aqlaboratory/openfold/experiments/test_templates_openfold.py#L89) calculates the Root Mean Square Deviation (RMSD), a measure of the average distance between the atoms of superimposed proteins, utilizing the [`kabsch`](https://github.com/aqlaboratory/openfold/experiments/test_templates_openfold.py#L90) algorithm for optimal alignment. For more advanced structural comparisons, [`compute_tmscore`](https://github.com/aqlaboratory/openfold/experiments/test_templates_openfold.py#L303) integrates an external TM-score program to evaluate and parse the TM-score, which assesses the topological similarity of protein structures. The results of these evaluations, including predicted PDBs and various metrics, are organized and persistently stored in CSV files using [`write_results`](https://github.com/aqlaboratory/openfold/experiments/test_templates_openfold.py#L332). This systematic storage also includes mechanisms to track [`finished_decoys`](https://github.com/aqlaboratory/openfold/experiments/test_templates_openfold.py#L382) and [`finished_targets`](https://github.com/aqlaboratory/openfold/experiments/test_templates_openfold.py#L390), enabling the resumption of interrupted evaluation runs.
