### Checkpoint Management: Listing and Cleanup
The Foundry CLI provides utilities for managing model checkpoints, including commands to inspect available and installed models and to clean up downloaded files.

The [`list_available`](https://github.com/rosettacommons/foundry/src/foundry_cli/download_checkpoints.py#L189) command in [`/rosettacommons/foundry/src/foundry_cli/download_checkpoints.py`](https://github.com/rosettacommons/foundry/src/foundry_cli/download_checkpoints.py) displays information about models that can be installed. This command queries a central registry of known models, [`REGISTERED_CHECKPOINTS`](https://github.com/rosettacommons/foundry/src/foundry/inference_engines/checkpoint_registry.py#L80), which contains metadata such as model names and descriptions. This allows users to see what models are supported and potentially download them.

For models already on the system, the [`list_installed`](https://github.com/rosettacommons/foundry/src/foundry_cli/download_checkpoints.py#L197) command, also within [`/rosettacommons/foundry/src/foundry_cli/download_checkpoints.py`](https://github.com/rosettacommons/foundry/src/foundry_cli/download_checkpoints.py), scans configured directories to identify and list [`.ckpt`](https://github.com/rosettacommons/foundry/src/foundry/trainers/fabric.py#L832) and [`.pt`](https://github.com/rosettacommons/foundry/src/foundry_cli/download_checkpoints.py#L205) files. It provides an overview of the checkpoints present, including their file names and total disk space consumed.

To free up storage, the [`clean`](https://github.com/rosettacommons/foundry/src/foundry_cli/download_checkpoints.py#L226) command, located in [`/rosettacommons/foundry/src/foundry_cli/download_checkpoints.py`](https://github.com/rosettacommons/foundry/src/foundry_cli/download_checkpoints.py), facilitates the removal of all downloaded checkpoint files. Before deletion, it provides a summary of the files to be removed and their cumulative size, requiring user confirmation to prevent accidental data loss. This functionality helps maintain a tidy local environment by purging unnecessary model files.
