### Higher-Order Interaction Indices (Triplets and Quadruplets)
The [`torch-sim`](https://github.com/torchsim/torch-sim/README.md#L3) repository provides pure-PyTorch implementations for constructing higher-order interaction indices, which are crucial for modeling multi-body interactions in atomic systems, particularly within machine learning interatomic potentials. These functions are located in [`/torchsim/torch-sim/torch_sim/neighbors/nbody.py`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/nbody.py) and are compatible with [`torch.jit.script`](https://github.com/torchsim/torch-sim/torch_sim/math.py#L12), ensuring they can be optimized and deployed efficiently.

The foundation for these operations is the [`_inner_idx`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/nbody.py#L41) utility function, which efficiently computes local enumerations within contiguous segments of a sorted tensor. This mechanism is critical for accurately mapping and aggregating data when constructing multi-body interactions.

Three primary functions are available for building these interaction indices:

*   [`build_triplets`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/nbody.py#L60) identifies all ordered pairs of edges that share a common target atom, creating a representation of three-body interactions. This is achieved by sorting edges based on their target atom and then using [`_inner_idx`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/nbody.py#L41) to generate unique combinations of incoming and outgoing edges for each central atom.
*   [`build_mixed_triplets`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/nbody.py#L157) extends this concept by allowing the construction of triplets from two distinct sets of edges. This is useful when different cutoffs or connectivity rules apply to different types of interactions. The function handles filtering of self-loops and incorporates periodic boundary conditions through [`cell_offsets_in`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/nbody.py#L162) and [`cell_offsets_out`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/nbody.py#L163).
*   [`build_quadruplets`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/nbody.py#L243) constructs four-body interaction indices, often visualized as [`d→b→a←c`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/nbody.py#L15). This function leverages [`build_mixed_triplets`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/nbody.py#L157) to identify initial three-body components and then combines them to form quadruplets. A key aspect of this function is the filtering of degenerate interactions where two atoms might be the same or in the same periodic image, which could represent invalid physical configurations.

These functions provide the means to define and analyze complex atomic environments, supporting advanced potential energy surface representations and graph-based machine learning models. The emphasis on pure-PyTorch implementations ensures flexibility, broad compatibility, and potential for GPU acceleration without relying on external libraries like [`torch_scatter`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/nbody.py#L4) or [`torch_sparse`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/nbody.py#L5). The utility function [`normalize_inputs`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/utils.py#L7) in [`/torchsim/torch-sim/torch_sim/neighbors/utils.py`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/utils.py) plays a role in standardizing input tensor formats for neighbor list calculations, ensuring consistency across different implementations including those that might feed into these higher-order index builders. For a broader understanding of how neighbor lists are generally managed and prioritized, refer to [Automatic Fallback and Prioritization](#neighbor-list-algorithms-automatic-fallback-and-prioritization).
