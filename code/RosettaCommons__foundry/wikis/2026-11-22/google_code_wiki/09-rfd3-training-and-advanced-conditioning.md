### RFD3 Training and Advanced Conditioning
RFD3's training methodology employs a robust framework leveraging [`hydra`](https://github.com/rosettacommons/foundry/pyproject.toml#L27) for flexible configuration and [`lightning.fabric`](https://github.com/rosettacommons/foundry/examples/all.ipynb#L84) for scalable distributed training. The core training execution is managed by the [`train`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/train.py#L26) function in [`/rosettacommons/foundry/models/rfd3/src/rfd3/train.py`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/train.py), which orchestrates the entire lifecycle, from loading configurations and setting up the environment to instantiating models, optimizers, and schedulers. This setup also handles distributed data loading, ensuring efficient data distribution across multiple training processes.

Central to RFD3's training is the [`AADesignTrainer`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/trainer/rfd3.py#L33) class, found in [`/rosettacommons/foundry/models/rfd3/src/rfd3/trainer/rfd3.py`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/trainer/rfd3.py). This class specializes in protein design-specific training logic, including the preparation of network inputs, calculation of the total loss, and evaluation of various design metrics during validation. It uses a [`recycle_schedule`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/trainers/rf3.py#L65) to determine the number of recycling steps for each training batch, which is crucial for iterative refinement of structural predictions. Furthermore, the trainer incorporates a [`DumpValidationStructuresCallback`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/trainer/dump_validation_structures.py#L19) to save predicted structures and associated metadata during validation, facilitating detailed analysis of training progress.

A key aspect of RFD3's training involves sophisticated conditioning strategies designed to create diverse and challenging design problems. These strategies are implemented using a class-based system defined in [`/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/training_conditions.py`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/training_conditions.py). The [`TrainingCondition`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/training_conditions.py#L31) abstract base class provides a common interface for different conditioning approaches. Concrete implementations like [`IslandCondition`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/training_conditions.py#L56) allow for selecting "islands" of residues as motifs, controlling which atoms or tokens are fixed in terms of coordinates or sequence. [`PPICondition`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/training_conditions.py#L176), on the other hand, is tailored for protein-protein interaction training, defining motifs based on binder and target proteins to fix the target's sequence and coordinates. [`SubtypeCondition`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/training_conditions.py#L272) focuses on selecting specific atom subtypes (e.g., protein, ligand, DNA) as motifs for conditioning. These conditions dynamically set conditioning annotations on [`AtomArray`](https://github.com/rosettacommons/foundry/examples/all.ipynb#L20) objects (e.g., [`is_motif_atom_with_fixed_coord`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/constants.py#L10), [`is_motif_atom_with_fixed_seq`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/constants.py#L9), [`is_motif_atom_unindexed`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/constants.py#L11)), allowing the model to learn to generate structures under various constraints.

The application of these conditioning strategies is managed by transforms within [`/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/conditioning_base.py`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/conditioning_base.py). [`SampleConditioningType`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/conditioning_base.py#L213) and [`SampleConditioningFlags`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/conditioning_base.py#L292) are used during training to probabilistically select and apply different conditioning strategies, while [`UnindexFlaggedTokens`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/transforms/conditioning_base.py#L315) handles the expansion of unindexed motifs, a critical step for preventing positional leakage in relative positional encoding when dealing with designed regions. These mechanisms collectively enable RFD3 to be trained on a wide array of design problems, improving its ability to generate novel biomolecular structures under diverse design specifications.
