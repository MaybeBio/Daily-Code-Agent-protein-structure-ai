### Structural Similarity Metrics and External Tool Integration
Protein structure prediction models are quantitatively evaluated using structural similarity metrics to compare predicted protein structures (decoys) against known native structures. Key metrics include Root Mean Square Deviation (RMSD) and TM-score.

RMSD quantifies the average distance between the backbone atoms of superimposed protein structures. The [`jnp_rmsd`](https://github.com/aqlaboratory/openfold/experiments/test_templates_openfold.py#L89) function, found in [`/aqlaboratory/openfold/experiments/test_templates_openfold.py`](https://github.com/aqlaboratory/openfold/experiments/test_templates_openfold.py), calculates this metric using the Kabsch algorithm, which optimally superimposes one structure onto another to minimize the atomic distances.

TM-score (Template Modeling score) is another metric that assesses the topological similarity between two protein structures, with a score between 0 and 1, where 1 indicates a perfect match. Unlike RMSD, TM-score is less sensitive to local structural variations and more indicative of overall fold similarity. The calculation of TM-score is integrated through an external program. The [`compute_tmscore`](https://github.com/aqlaboratory/openfold/experiments/test_templates_openfold.py#L303) function in [`/aqlaboratory/openfold/experiments/test_templates_openfold.py`](https://github.com/aqlaboratory/openfold/experiments/test_templates_openfold.py) executes an external [`TMscore`](https://github.com/aqlaboratory/openfold/experiments/test_templates_openfold.py#L50) executable, parses its output, and performs validation checks on sequence length and common residues.

The overall workflow for evaluating models and utilizing these metrics is detailed in [Workflow for Decoy Scoring and Evaluation](#experimentation-and-model-evaluation-workflow-for-decoy-scoring-and-evaluation). The [`write_results`](https://github.com/aqlaboratory/openfold/experiments/test_templates_openfold.py#L332) function within [`/aqlaboratory/openfold/experiments/test_templates_openfold.py`](https://github.com/aqlaboratory/openfold/experiments/test_templates_openfold.py) consolidates these calculated metrics, along with predicted PDBs, into CSV files for persistent storage and analysis.
