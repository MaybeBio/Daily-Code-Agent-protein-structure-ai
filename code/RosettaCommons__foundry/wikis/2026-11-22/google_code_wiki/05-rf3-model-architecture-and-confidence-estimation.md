### RF3 Model Architecture and Confidence Estimation
The RoseTTAFold3 (RF3) model, implemented primarily in [`/rosettacommons/foundry/models/rf3/src/rf3/model/RF3.py`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/model/RF3.py), provides a framework for biomolecular structure prediction, employing a diffusion-based generative approach. The core [`RF3`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/model/RF3.py#L56) class integrates several key components to achieve this. A [`FeatureInitializer`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/model/layers/pairformer_layers.py#L401) sets up the initial token-level representations, which are then refined through a [`Recycler`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/model/RF3_structure.py#L257) mechanism. This [`Recycler`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/model/RF3_structure.py#L257) iteratively processes sequence and pair representations, contributing to the model's ability to refine its understanding of the molecular context over multiple passes. The central generative aspect is handled by the [`DiffusionModule`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/model/RF3_structure.py#L70), which takes noisy atomic coordinates and other features to iteratively predict an update, essentially denoising the structure. Finally, a [`DistogramHead`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/model/RF3_structure.py#L233) predicts inter-residue distance distributions, providing a probabilistic representation of pairwise distances. During inference, an [`inference_sampler`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/engine.py#L54) orchestrates the full diffusion rollout, generating a complete predicted structure.

The architecture of [`RF3`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/model/RF3.py#L56) allows for flexible prediction modes within the [`DiffusionModule`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/model/RF3_structure.py#L70) to predict either the original clean data, the noise, or a correction based on the input noisy coordinates, offering versatility in how the diffusion process is controlled. The model processes information at both fine-grained atom-level and coarse-grained token-level. An [`AtomAttentionDecoder`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/model/RF3_structure.py#L33) translates higher-level token features into atom-level updates for positions, while [`DiffusionConditioning`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/model/RF3_structure.py#L174) prepares dynamic features for the [`DiffusionModule`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/model/RF3_structure.py#L70) by incorporating diffusion time and input features.

For assessing the reliability of its predictions, the RF3 framework includes [`RF3WithConfidence`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/model/RF3.py#L334), an extension that adds explicit confidence estimation capabilities. This class integrates a [`ConfidenceHead`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/model/layers/af3_auxiliary_heads.py#L25) (defined in [`/rosettacommons/foundry/models/rf3/src/rf3/model/layers/af3_auxiliary_heads.py`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/model/layers/af3_auxiliary_heads.py)) to predict quality metrics such as predicted Local Distance Difference Test (pLDDT) and Predicted Aligned Error (PAE). These metrics offer insights into the accuracy of the predicted local structure and the relative alignment of domains, respectively. [`RF3WithConfidence`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/model/RF3.py#L334) also incorporates a [`mini_rollout_sampler`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/model/RF3.py#L340) for faster diffusion rollouts, primarily used during training to estimate confidence without the computational cost of a full inference run. Critically, it supports an early stopping mechanism, which can halt the iterative recycling process during inference if confidence metrics reach a sufficient threshold, optimizing computational resources. The [`ConfidenceHead`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/model/layers/af3_auxiliary_heads.py#L25) calculates these metrics by processing latent representations, predicted atom coordinates, and sequence information, using techniques like distance discretization and optionally incorporating Cb distances for enhanced feature representation.
