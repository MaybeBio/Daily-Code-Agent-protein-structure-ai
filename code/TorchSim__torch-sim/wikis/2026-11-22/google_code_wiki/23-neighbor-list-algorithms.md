## Neighbor List Algorithms
Neighbor lists are fundamental to atomistic simulations, enabling efficient calculation of interatomic interactions by identifying atoms within a specified cutoff distance. The [`torch-sim`](https://github.com/torchsim/torch-sim/README.md#L3) repository provides multiple implementations for this task, supporting both single and batched system calculations and incorporating an automatic fallback mechanism to leverage the most performant option available.

The system prioritizes accelerated external libraries. If NVIDIA's [`nvalchemiops`](https://github.com/torchsim/torch-sim/torch_sim/autobatching.py#L42) library is installed, the system uses its GPU-accelerated N² or cell-list algorithms for neighbor searches through the functions in [`/torchsim/torch-sim/torch_sim/neighbors/alchemiops.py`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/alchemiops.py). This option offers optimized performance on compatible hardware. If [`nvalchemiops`](https://github.com/torchsim/torch-sim/torch_sim/autobatching.py#L42) is not available, the system then attempts to use the [`vesin`](https://github.com/torchsim/torch-sim/pyproject.toml#L50) library. Implementations in [`/torchsim/torch-sim/torch_sim/neighbors/vesin.py`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/vesin.py) provide both a standard Python version ([`vesin_nl`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/vesin.py#L36)) and a TorchScript-optimized version ([`vesin_nl_ts`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/vesin.py#L184)) for efficient neighbor list generation. Both Alchemiops and Vesin implementations handle periodic boundary conditions and support batched processing.

As a final fallback, if neither of these external libraries is present, [`torch-sim`](https://github.com/torchsim/torch-sim/README.md#L3) includes pure PyTorch implementations in [`/torchsim/torch-sim/torch_sim/neighbors/torch_nl.py`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/torch_nl.py). These include an O(N²) brute-force approach ([`torch_nl_n2`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/torch_nl.py#L94)) suitable for smaller systems and a more efficient O(N) linked-cell algorithm ([`torch_nl_linked_cell`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/torch_nl.py#L156)). All neighbor list functions are accessible via a unified entry point, [`torchsim_nl`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/__init__.py#L46), which automatically selects the most suitable implementation based on environmental availability. This automatic fallback ensures robust functionality across diverse deployment environments.

Beyond simple pairwise interactions, the system also supports the generation of higher-order interaction indices for molecular graphs. Functions within [`/torchsim/torch-sim/torch_sim/neighbors/nbody.py`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/nbody.py) provide pure-PyTorch methods to construct triplets (three-body interactions) and quadruplets (four-body interactions). These are crucial for advanced interatomic potentials and machine learning models that consider angular or dihedral relationships between atoms.

To ensure consistency across these varied implementations, the [`normalize_inputs`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/utils.py#L7) utility in [`/torchsim/torch-sim/torch_sim/neighbors/utils.py`](https://github.com/torchsim/torch-sim/torch_sim/neighbors/utils.py) standardizes the format of cell and periodic boundary condition tensors. This function ensures that inputs are correctly shaped and contiguous, which is vital for efficient processing by the different neighbor list algorithms.
