## RoseTTAFold3 (RF3) for Structure Prediction
RoseTTAFold3 (RF3) is a biomolecular structure prediction model designed to determine the 3D atomic coordinates of proteins and other biomolecules. It supports a wide range of inputs, including sequences, multiple sequence alignments (MSAs), small molecules, DNA, and RNA, and can handle covalent modifications and complex topologies.

Users can install RF3 and download model checkpoints, including [`Latest`](https://github.com/rosettacommons/foundry/models/rf3/README.md#L39), [`Preprint`](https://github.com/rosettacommons/foundry/models/rf3/README.md#L40), and [`Benchmark`](https://github.com/rosettacommons/foundry/models/rf3/README.md#L41) versions. The model supports inference for various biomolecular systems. Predictions are executed via a command-line interface, which allows specifying inputs, output directories, and checkpoint paths. Input formats are versatile, accommodating JSON, CIF, PDB, SMILES, and SDF files. For efficient processing, RF3 supports batching multiple inputs, automatically distributing jobs across available GPUs.

Beyond basic prediction, RF3 incorporates advanced features for controlling the folding process. Templating capabilities enable guiding predictions using known structural elements, applicable to both polymers and non-polymers. Users can specify [`template_selection`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/utils/inference.py#L68) for token-level guidance and [`ground_truth_conformer_selection`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/utils/inference.py#L69) to enforce specific residue conformations, particularly useful for small molecules. Performance parameters like [`early_stopping_plddt_threshold`](https://github.com/rosettacommons/foundry/models/rf3/README.md#L138), [`n_recycles`](https://github.com/rosettacommons/foundry/models/rf3/README.md#L582), [`diffusion_batch_size`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/engine.py#L48), [`num_steps`](https://github.com/rosettacommons/foundry/models/rf3/README.md#L586), and [`seed`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/engine.py#L81) can be configured to optimize computational resources and prediction quality. The model provides comprehensive outputs, including confidence metrics (pLDDT, PAE), [`.cif`](https://github.com/rosettacommons/foundry/models/rf3/README.md#L119) structure files, and options to dump trajectories or annotate B-factors with pLDDT values.

The RF3 model's architecture is centered around a [`FeatureInitializer`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/model/layers/pairformer_layers.py#L401), [`Recycler`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/model/RF3_structure.py#L257), [`DiffusionModule`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/model/RF3_structure.py#L70), and [`DistogramHead`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/model/RF3_structure.py#L233) (defined in [`/rosettacommons/foundry/models/rf3/src/rf3/model/RF3.py`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/model/RF3.py) and [`/rosettacommons/foundry/models/rf3/src/rf3/model/RF3_structure.py`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/model/RF3_structure.py)). The [`DiffusionModule`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/model/RF3_structure.py#L70) manages the iterative denoising process during training and diffusion rollouts during inference, guided by an [`inference_sampler`](https://github.com/rosettacommons/foundry/models/rfd3/src/rfd3/engine.py#L54). For enhanced confidence estimation, [`RF3WithConfidence`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/model/RF3.py#L334) extends the base model by incorporating a [`ConfidenceHead`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/model/layers/af3_auxiliary_heads.py#L25) (from [`/rosettacommons/foundry/models/rf3/src/rf3/model/layers/af3_auxiliary_heads.py`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/model/layers/af3_auxiliary_heads.py)) to predict [`pLDDT`](https://github.com/rosettacommons/foundry/examples/all.ipynb#L231) and [`PAE`](https://github.com/rosettacommons/foundry/examples/all.ipynb#L231) metrics, which can be used for early stopping to save computational time.

Training and validation workflows for RF3 are orchestrated by specialized trainers (e.g., [`RF3Trainer`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/trainers/rf3.py#L35) in [`/rosettacommons/foundry/models/rf3/src/rf3/trainers/rf3.py`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/trainers/rf3.py)), which handle loss calculation, metric evaluation, and molecular symmetry resolution. Data preparation involves sophisticated pipelines that process raw structural data and generate features suitable for model input. These pipelines include transformations for handling cyclic bonds, generating noised ground truth distogram features, and assembling AF3-like data processing streams (see [`/rosettacommons/foundry/models/rf3/src/rf3/data/pipelines.py`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/data/pipelines.py) and other modules within [`/rosettacommons/foundry/models/rf3/src/rf3/data`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/data)).

RF3 leverages a comprehensive suite of loss functions and evaluation metrics to guide training and assess prediction quality. Loss functions such as [`ConfidenceLoss`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/loss/af3_confidence_loss.py#L18), [`DiffusionLoss`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/loss/af3_losses.py#L416), and [`DistogramLoss`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/loss/af3_losses.py#L628) (found in [`/rosettacommons/foundry/models/rf3/src/rf3/loss/af3_confidence_loss.py`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/loss/af3_confidence_loss.py) and [`/rosettacommons/foundry/models/rf3/src/rf3/loss/af3_losses.py`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/loss/af3_losses.py)) are critical for model optimization. Evaluation metrics cover various aspects of structural accuracy, including chirality, atom clashing, lDDT scores (e.g., [`AllAtomLDDT`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/metrics/lddt.py#L205), [`InterfaceLDDTByType`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/metrics/lddt.py#L268)), and predicted error metrics ([`ComputePTM`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/metrics/predicted_error.py#L43), [`ComputeIPTM`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/metrics/predicted_error.py#L73)) located within submodules of [`/rosettacommons/foundry/models/rf3/src/rf3/metrics`](https://github.com/rosettacommons/foundry/models/rf3/src/rf3/metrics). These metrics help ensure that the generated structures are chemically plausible and structurally accurate.
