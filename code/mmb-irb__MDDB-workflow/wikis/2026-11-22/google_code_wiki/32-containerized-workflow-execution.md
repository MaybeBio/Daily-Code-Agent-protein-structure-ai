## Containerized Workflow Execution
The [`MDDB-workflow`](https://github.com/mmb-irb/mddb-workflow/README.md#L4) is distributed as a Docker image, which encapsulates the entire runtime environment, including a Miniconda3 installation, all necessary dependencies, and the workflow software itself. This containerization ensures that the workflow executes consistently and reproducibly across diverse computing environments. The Docker build process, defined in [`/mmb-irb/mddb-workflow/docker/Dockerfile`](https://github.com/mmb-irb/mddb-workflow/docker/Dockerfile), creates a self-contained image ready for execution.

The Docker image builds upon a [`miniconda3:latest`](https://github.com/mmb-irb/mddb-workflow/docker/Dockerfile#L2) base. It installs system-level dependencies like [`libgl1`](https://github.com/mmb-irb/mddb-workflow/docker/Dockerfile#L10) to support graphical applications like VMD and then clones the [`MDDB-workflow`](https://github.com/mmb-irb/mddb-workflow/README.md#L4) repository. A dedicated [`conda`](https://github.com/mmb-irb/mddb-workflow/README.md#L41) environment, [`mwf_env`](https://github.com/mmb-irb/mddb-workflow/README.md#L28), is created based on the [`environment.yml`](https://github.com/mmb-irb/mddb-workflow/README.md#L17) file within the repository, and the [`MDDB-workflow`](https://github.com/mmb-irb/mddb-workflow/README.md#L4) Python package is installed into this environment. To ensure that the Python interpreter within the container can locate all necessary modules, the [`PYTHONPATH`](https://github.com/mmb-irb/mddb-workflow/docker/Dockerfile#L31) is extended. An [`entrypoint.sh`](https://github.com/mmb-irb/mddb-workflow/docker/Dockerfile#L34) script is generated and set as the container's entrypoint; this script uses [`conda run`](https://github.com/mmb-irb/mddb-workflow/README.md#L41) to activate [`mwf_env`](https://github.com/mmb-irb/mddb-workflow/README.md#L28) and execute any commands passed to the Docker container, thereby isolating the workflow's execution within its defined environment.
